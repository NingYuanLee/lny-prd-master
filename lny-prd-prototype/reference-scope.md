# 根目录范围页（`scope.html`）

⑥ 生成或覆盖刷新 PRD 根 `scope.html`。给人看的**整个项目当前现状**一页，不是规格，编码 Agent 不靠它实现。

- **唯一文件**：PRD 根 `scope.html`。不写 `scope.md`。不放 `prototypes/`，不按端分份，不拷进 `versions/`。
- **从规格抽取**：`main_spec`（项目名、当前版本、终端、成功怎么算、明确不做）+ `ui_manifest` 页面全量 + `feature_spec` / 明细目标各一句话。禁止编造；禁止只写本轮增量。
- 未填「成功怎么算」写「未填写」；未声明「明确不做」写「未声明」。
- 链到各端 `prototypes/{终端}/index.html`。
- ① 立项不落本文件；②③④⑤ 本轮若无 ⑥ 则下次出原型再刷。

## 页内结构

1. 项目名、当前工作版本号、终端
2. 成功怎么算 / 明确不做
3. 页面清单（人话名称，按终端）
4. FEATURE 各一句话
5. 各端演示入口

观感对齐套件主色 `#1976d2`；根目录文件用少量内联 CSS，不依赖某一端 `assets/`（避免只装了 MP 或只装了 AD 时裂图）。UTF-8 无 BOM。

原型顶栏「范围说明」是**当前页**人话短说明（`PROTO_SHELL.pages[].brief`），**不**链到本文件。
