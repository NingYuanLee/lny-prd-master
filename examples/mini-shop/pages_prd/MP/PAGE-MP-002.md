## 3. 页面模块详述

```
┌────────────────────────────┐
│ 状态栏（标准）             │
│ 「在售商品」居中标题栏     │
│ 「搜索」框 + 筛选图标行    │
│ 页签 + 横卡（仅此区滚动）  │
├────────────────────────────┤
│ TabBar 贴底：首页 | 商品   │
└────────────────────────────┘
```

### │ L0 系统层
- **结构与控件**：顶栏 **标准**（状态栏不透明）固定顶、不随滚；左右下及四角安全距；胶囊避让；TabBar 贴底固定
- **交互与跳转**：Tab「首页」切到 PAGE-MP-001
- **涉及接口**：无

### │ L1 固定导航层
- **结构与控件**：L2 居中标题栏「在售商品」贴顶固定；搜索框行贴顶固定，右侧 **筛选图标**（改条件后高亮）；页签贴顶
- **交互与跳转**：提交搜索刷新本页列表；筛选图标开右半屏
- **涉及接口**：API-MP-001

### │ L2 主体滚动层
- **结构与控件**：列表；上拉加载更多
- **交互与跳转**：点击卡片进 PAGE-MP-003
- **涉及接口**：API-MP-001

### │ L3 模块容器层
- **结构与控件**：**商品卡片（详见 ui/COMP-001.md）** 横卡 1:1
- **交互与跳转**：点击进 PAGE-MP-003
- **涉及接口**：API-MP-001

### │ L5 浮层与反馈层（如有）
- **结构与控件**：右半屏「筛选」；「有货」「缺货」；确认「清空」；Toast
- **交互与跳转**：点遮罩关闭半屏
- **涉及接口**：无
