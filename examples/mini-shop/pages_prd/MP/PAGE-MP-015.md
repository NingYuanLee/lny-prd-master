## 3. 页面模块详述

```
┌────────────────────────────┐
│ 状态栏（标准）             │
│ 返回 「章节目录」          │
│ 父子章节列表（可收起）     │
└────────────────────────────┘
```

### │ L0 系统层
- **结构与控件**：标准顶栏；无 TabBar
- **交互与跳转**：无
- **涉及接口**：无

### │ L1 固定导航层
- **结构与控件**：返回；标题「章节目录」
- **交互与跳转**：返回 PAGE-MP-010
- **涉及接口**：无

### │ L2 主体滚动层
- **结构与控件**：`md-chapter-list` 滚动
- **交互与跳转**：父章 toggle 展开/收起子章；点父/子标题跳转锚点或详情
- **涉及接口**：无

### │ L3 模块容器层
- **结构与控件**：`__group` + `__head`（toggle + 父章）+ `__body`（子章）
- **交互与跳转**：默认首组展开；收起后只留父章行
- **涉及接口**：无
