## 3. 页面模块详述

```
┌────────────────────────────┐
│ 状态栏（标准）             │
│ 返回 「表单」              │
│ 文本：单行/数字/电话/多行/只读/禁用 │
│ 选择：单选/多选/开关/少下拉/多下拉 │
│ 滑动条：五档位 / 无极      │
│ 日期：单日 / 日期段 / 省市区 │
│ 上传：单图 / 多图 / 文件   │
├────────────────────────────┤
│ 贴底「取消」「提交」       │
└────────────────────────────┘
```

### │ L0 系统层
- **结构与控件**：顶栏 **标准**（状态栏不透明）固定顶、不随滚；左右下及四角安全距；胶囊避让；无 TabBar
- **交互与跳转**：无
- **涉及接口**：无

### │ L1 固定导航层
- **结构与控件**：返回；标题「表单」；主操作条「取消」「提交」贴底固定
- **交互与跳转**：返回或「取消」回 PAGE-MP-001
- **涉及接口**：无

### │ L2 主体滚动层
- **结构与控件**：分区模块与表单字段；输入框右侧留安全距
- **交互与跳转**：无出页
- **涉及接口**：无

### │ L3 模块容器层
- **结构与控件**：单行/数字/电话/多行/只读/禁用；单选标签、多选标签、开关、少选项中间弹窗、多选项底半屏；五档位/无极滑动条；单日、日期段、省市区；单图更换、多图可删、文件+上传进度。每项独立成行
- **交互与跳转**：提交仅 Toast
- **涉及接口**：无

### │ L5 浮层与反馈层（如有）
- **结构与控件**：少选项中间弹窗；多选项/日期/地区底半屏；校验与成功 Toast
- **交互与跳转**：点遮罩关闭半屏
- **涉及接口**：无
