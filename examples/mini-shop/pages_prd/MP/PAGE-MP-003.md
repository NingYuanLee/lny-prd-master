## 3. 页面模块详述

```
┌────────────────────────────┐
│ 沉浸式状态栏 + 返回        │
│ 下沉 16:9 商品图           │
│ 名称 / 售价 / 库存         │
│ 「商品说明」图文混排       │
│ 「评论」列表               │
├────────────────────────────┤
│ 贴底「收藏」               │
└────────────────────────────┘
```

### │ L0 系统层
- **结构与控件**：顶栏 **沉浸式**（状态栏透明）固定顶、不随滚；左右下及四角安全距；胶囊避让；无 TabBar
- **交互与跳转**：无
- **涉及接口**：无

### │ L1 固定导航层
- **结构与控件**：返回叠在下沉图上；标题「商品详情」；主操作条「收藏」贴底固定
- **交互与跳转**：返回 PAGE-MP-002；「收藏」Toast「本页只展示，不下单」，无出页
- **涉及接口**：无

### │ L2 主体滚动层
- **结构与控件**：下沉 16:9 图集；信息块；图文「商品说明」；「评论」列表
- **交互与跳转**：无出页（评论只读）
- **涉及接口**：API-MP-002

### │ L3 模块容器层
- **结构与控件**：图集 **16:9**；信息块；介绍配图 **16:9**；评论含时间行；附图 **1:1** 一排最多五张、超出换行
- **交互与跳转**：无
- **涉及接口**：API-MP-002

### │ L5 浮层与反馈层（如有）
- **结构与控件**：失败 Toast；点图片放大阅览，同页图片为一组，可按顺序翻页查看，到头不循环
- **交互与跳转**：点任意图片进入预览；可按顺序翻页，到头不循环；点遮罩或关闭退出
- **涉及接口**：无
