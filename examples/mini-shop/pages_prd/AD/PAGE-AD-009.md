## 3. 页面模块详述

```
┌──────────────────────────────────────────┐
│ 面包屑：套件 / 表单（无页内大标题）        │
├──────────────────────────────────────────┤
│ 「文本」单行 / 数字 / 电话 / 只读/禁用 / 多行 │
│ 「选择」单选 / 多选 / 开关 / 少选项 / 多选项│
│ 「滑动条」五档位 / 无极                    │
│ 「日期与地区」单日 / 时间 / 日期段 / 省市区 │
│ 「上传」单图更换 / 多图可删 / 文件上传     │
│ [取消] [提交]                              │
└──────────────────────────────────────────┘
```

### │ D1-2 表单内容区
- **结构与控件**：顶部面包屑，无页内大标题；「单行文本」「数字」「电话」「多行文本」「只读/禁用」；「单选」「多选」「开关」「下拉（少选项）」「下拉（多选项）」；「五档位」「无极滑动条」；「单日」「时间」「日期段」「省市区」三级下拉；「单图更换」「多图可删」「文件上传」
- **交互与跳转**：「提交」缺「单行文本」或「电话」Toast「请填写单行文本与电话」，成功 Toast「已提交」；「取消」Toast「已取消」；无出页
- **涉及接口**：无

### │ D5 浮层与反馈层
- **结构与控件**：无弹窗；Toast；单日月历、日期段点选
- **交互与跳转**：无
- **涉及接口**：无
