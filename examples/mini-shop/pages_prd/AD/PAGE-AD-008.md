## 3. 页面模块详述

```
┌──────────────────────────────────────────┐
│ 面包屑：商品 / 商品列表 / 商品详情         │
│ （无页内大标题）                           │
├────────────────────┬─────────────────────┤
│ 16:9 图集          │ 名称 / 售价 / 库存   │
│                    │ 「收藏」「返回列表」 │
├────────────────────┴─────────────────────┤
│ 「商品说明」图文混排                       │
│ 「评论」列表（时间行；附图 1:1 最多五张）  │
└──────────────────────────────────────────┘
```

### │ D1-3 自定义内容区
- **结构与控件**：顶部面包屑，无页内大标题；主图 **16:9**；信息块；图文「商品说明」；「评论」列表含时间行，附图 **1:1** 一排最多五张
- **交互与跳转**：「收藏」Toast「本页只展示，不下单」，无出页；「返回列表」回 PAGE-AD-001
- **涉及接口**：API-AD-002

### │ D5 浮层与反馈层
- **结构与控件**：无弹窗；失败 Toast；点图片放大阅览，同页图片为一组，可按顺序翻页查看，到头不循环
- **交互与跳转**：点任意图片进入预览；可按顺序翻页，到头不循环；点遮罩或关闭退出
- **涉及接口**：无
