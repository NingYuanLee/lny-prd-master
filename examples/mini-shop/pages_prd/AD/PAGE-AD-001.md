## 3. 页面模块详述

```
┌──────────────────────────────────────────┐
│ 面包屑（无页内大标题）                   │
│ 签：全部 / 有货 / 缺货（在筛选上方）     │
├──────────────────────────────────────────┤
│ 搜索：[名称][库存状态][上架日期][仅看上架][查询][重置] │
├──────────────────────────────────────────┤
│ 功能：[新增]                             │
├──────────────────────────────────────────┤
│ 勾选(左冻) | 名称(宽) | 售价(窄) | 库存(窄) | 日期 | 操作(右冻定宽) │
│ 列宽按语义，禁止均分；整页紧凑多看行                     │
│ 操作：「查看」；「更多」下拉「快捷编辑」「选择关联」 │
├──────────────────────────────────────────┤
│ 汇总靠左 + 分页靠右（贴底；表横条贴表底）│
└──────────────────────────────────────────┘
弹窗：商品详情(展示) / 快捷编辑(表单) / 选择关联商品(列表)
```

### │ D1-1 标准内容区
- **结构与控件**：顶部面包屑，无页内大标题

#### ││ 页内签（如有）
- **结构与控件**：全部 / 有货 / 缺货，位于搜索栏上方
- **交互与跳转**：点签整块切换搜索栏、功能栏、列表区、汇总分页
- **涉及接口**：API-AD-001

#### ││ 搜索栏
- **结构与控件**：商品名称输入；库存状态下拉；上架日期（日期选择）；「仅看上架」开关；「查询」「重置」按钮组
- **交互与跳转**：查询刷新本签表格；重置清空本签条件
- **涉及接口**：API-AD-001

#### ││ 功能栏
- **结构与控件**：「新增」
- **交互与跳转**：「新增」进入 PAGE-AD-002
- **涉及接口**：无

#### ││ 列表区（含操作列）
- **结构与控件**：勾选列左冻；列：商品名称（吃剩余宽）、售价（窄）、库存状态（窄）、上架日期（日期宽）；操作列右冻定宽：「查看」在列内，「快捷编辑」「选择关联」收进「更多」下拉；整页控件紧凑，一屏多看几行
- **交互与跳转**：「查看」展示弹窗；「更多」打开下拉后再点「快捷编辑」表单弹窗、「选择关联」列表弹窗
- **涉及接口**：API-AD-001；API-AD-002；API-AD-003

#### ││ 汇总栏 + 分页栏
- **结构与控件**：统计信息靠左；每页条数与页码靠右；贴内容区底部
- **交互与跳转**：翻页仍在本页
- **涉及接口**：API-AD-001

### │ D5 浮层与反馈层
- **结构与控件**：展示弹窗「商品详情」；表单弹窗「快捷编辑」（库存状态下拉、上架日期、上架时间、「上架」开关、配送「包邮」/「到店自提」单选、「小程序」/「后台展示」多选）；列表弹窗「选择关联商品」；保存成功 Toast
- **交互与跳转**：弹窗内确定/取消不离开本页
- **涉及接口**：API-AD-001；API-AD-002；API-AD-003
