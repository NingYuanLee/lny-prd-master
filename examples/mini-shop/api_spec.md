## 3. 响应形态约定

### 3.1 基础对象
返回单个业务对象或操作结果。

### 3.2 无分页列表
返回完整列表，数据量可控。

### 3.3 分页列表
返回列表数据及分页信息。请求须含当前页码、每页条数；响应须含列表项字段及总条数。
