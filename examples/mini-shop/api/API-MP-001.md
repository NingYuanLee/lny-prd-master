# API-MP-001 查询在售商品

## 1. 基本信息

| 项目 | 内容 |
|------|------|
| 接口编号 | API-MP-001 |
| 接口用途 | 分页查询在售商品，供首页推荐与商品列表 |
| 涉及页面 | PAGE-MP-001 首页；PAGE-MP-002 商品列表 |
| 服务层级 | PAGE |
| 服务对象 | 前端视图 |
| 数据操作形态 | 多对象关联查询（普通） |
| API是否涉及第三方联动 | 否 |
| API是否涉及特殊通道 | 否 |
| 响应形态 | 分页列表 |
| 外部依赖 | 无 |

## 2. 关联 Feature 清单

| Feature编号 | Feature名称 | 关联说明 | 来源路径 |
|-------------|-------------|----------|----------|
| FEATURE-001 | 浏览在售商品 | 提供列表查询 | feature/FEATURE-001.md |

## 3. 触发与场景

- **触发时机**：进入首页或商品列表；列表上拉下一页、提交搜索、应用筛选
- **成功表现**：展示商品卡片
- **失败表现**：Toast 失败并允许重试

## 4. 请求需求

| 业务字段 | 类型语义 | 必要 | 说明 |
|----------|----------|:--:|------|
| 当前页码 | 数值 | 是 | 从 1 起 |
| 每页条数 | 数值 | 是 | 首页固定 4；列表页与 UI 一致 |
| 仅推荐 | 布尔 | 否 | 首页传是；列表与详情不传 |
| 关键词 | 文本 | 否 | 列表搜索框；空则不过滤名称 |
| 库存状态 | 文本 | 否 | 列表筛选；有货或缺货，可多选语义 |

## 5. 响应需求

| 业务字段 | 类型语义 | 必要 | 说明 |
|----------|----------|:--:|------|
| 商品列表 | 数组（元素为对象） | 是 | 每项含：商品名称、商品图片、售价 |
| 总条数 | 数值 | 是 | 与列表同级 |

## 6. 业务规则与异常

- 仅返回在售商品
- 失败时用户可见「加载失败，请重试」

## 7. 页面固定参数等特殊说明（按页面）

- **PAGE-MP-001 / 首页**：仅推荐=是；每页条数=4
- **PAGE-MP-002 / 商品列表**：不传仅推荐；可带关键词与库存状态
