# API-MP-002 查询商品详情

## 1. 基本信息

| 项目 | 内容 |
|------|------|
| 接口编号 | API-MP-002 |
| 接口用途 | 查询单个在售商品的展示信息，供商品详情页 |
| 涉及页面 | PAGE-MP-003 商品详情 |
| 服务层级 | PAGE |
| 服务对象 | 前端视图 |
| 数据操作形态 | 单对象查询 |
| API是否涉及第三方联动 | 否 |
| API是否涉及特殊通道 | 否 |
| 响应形态 | 基础对象 |
| 外部依赖 | 无 |

## 2. 关联 Feature 清单

| Feature编号 | Feature名称 | 关联说明 | 来源路径 |
|-------------|-------------|----------|----------|
| FEATURE-001 | 浏览在售商品 | 提供详情查询 | feature/FEATURE-001.md |

## 3. 触发与场景

- **触发时机**：进入商品详情
- **成功表现**：展示图、名称、售价、库存、图文介绍与评论
- **失败表现**：Toast 失败并允许返回列表

## 4. 请求需求

| 业务字段 | 类型语义 | 必要 | 说明 |
|----------|----------|:--:|------|
| 商品编号 | 文本 | 是 | 从列表或推荐带入 |

## 5. 响应需求

| 业务字段 | 类型语义 | 必要 | 说明 |
|----------|----------|:--:|------|
| 商品编号 | 文本 | 是 | 与请求一致 |
| 商品名称 | 文本 | 是 | 展示用 |
| 商品图片 | 文本 | 是 | 可多图，至少一张；详情主图 16:9 |
| 售价 | 数值 | 是 | 展示用 |
| 库存状态 | 文本 | 是 | 有货或缺货 |
| 商品简介 | 文本 | 是 | 说明导语 |
| 介绍图文 | 数组（元素为对象） | 是 | 每项含：段落文案、配图（可选，16:9） |
| 评论列表 | 数组（元素为对象） | 是 | 每项含：评论人、评论时间、评论文案、评论图片（可多张，1:1，一排最多五张） |

## 6. 业务规则与异常

- 仅返回在售商品；非在售视为失败
- 失败时用户可见「加载失败，请重试」

## 7. 页面固定参数等特殊说明（按页面）

- **PAGE-MP-003 / 商品详情**：按进页商品编号查询
