# API-AD-001 查询商品（后台）

## 1. 基本信息

| 项目 | 内容 |
|------|------|
| 接口编号 | API-AD-001 |
| 接口用途 | 后台分页查询商品列表 |
| 涉及页面 | PAGE-AD-001 商品列表 |
| 服务层级 | PAGE |
| 服务对象 | 资源管理 |
| 数据操作形态 | 多对象关联查询（普通） |
| API是否涉及第三方联动 | 否 |
| API是否涉及特殊通道 | 否 |
| 响应形态 | 分页列表 |
| 外部依赖 | 无 |

## 2. 关联 Feature 清单

| Feature编号 | Feature名称 | 关联说明 | 来源路径 |
|-------------|-------------|----------|----------|
| FEATURE-001 | 浏览在售商品 | 后台核对商品 | feature/FEATURE-001.md |
| FEATURE-002 | 维护后台商品 | 列表查询与关联商品弹窗 | feature/FEATURE-002.md |

## 3. 触发与场景

- **触发时机**：进入列表页、点击查询、翻页、页内签、打开选择关联弹窗
- **成功表现**：表格刷新
- **失败表现**：页内错误提示

## 4. 请求需求

| 业务字段 | 类型语义 | 必要 | 说明 |
|----------|----------|:--:|------|
| 当前页码 | 数值 | 是 | 从 1 起 |
| 每页条数 | 数值 | 是 | 与分页栏一致 |
| 商品名称 | 字符串 | 否 | 模糊搜索 |
| 库存状态 | 枚举 | 否 | 全部 / 有货 / 缺货 |
| 上架日期 | 日期 | 否 | 不早于该日 |
| 是否上架 | 布尔 | 否 | 勾选「仅看上架」时只返回已上架 |

## 5. 响应需求

| 业务字段 | 类型语义 | 必要 | 说明 |
|----------|----------|:--:|------|
| 商品列表 | 数组（元素为对象） | 是 | 每项含：商品名称、售价、库存状态、上架日期 |
| 总条数 | 数值 | 是 | 分页用 |

## 6. 业务规则与异常

- 后台可见全部商品状态，不仅在售

## 7. 页面固定参数等特殊说明（按页面）

- **PAGE-AD-001 / 商品列表**：无额外固定入参
