## 3. 触发与场景

- **触发时机**：到货提醒页点击提交
- **成功表现**：Toast 已登记，可返回详情
- **失败表现**：Toast 失败并允许重试

## 6. 业务规则与异常

- 联系人、联系电话必填，否则不可提交
- 本夹具不做下单与支付
- 失败时用户可见「提交失败，请重试」
