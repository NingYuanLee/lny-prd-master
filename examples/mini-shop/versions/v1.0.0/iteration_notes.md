# 迭代摘要 - v1.0.0

## 版本名称
首版夹具

## 版本目标
技能包回归夹具：首页推荐 + 商品列表（MP）+ 后台商品列表与整页表单（AD，含展示/表单/列表弹窗及日期、下拉）。

## 变更统计
- 页面：新增 4 / 修改 0 / 废弃 0
- 接口：新增 4 / 修改 0 / 废弃 0
- 功能：新增 2 / 修改 0 / 废弃 0

## 业务流水
- 夹具补齐后台示例：PAGE-AD-002 表单页；PAGE-AD-001 三类弹窗、筛选日期与下拉。
- 表单与筛选补开关、单选、多选。
- 触屏端：TabBar 页去掉顶栏；首页下沉轮播与金刚区；列表 1:1 横卡；左/底/右半屏与确认、Toast。
- UI 规格补交互体验设计：每页写观感、动效、微反馈与收纳（折叠/半屏/弹窗），不再只列控件。
- 触屏端补圆角/曲面屏：左右下及四角留安全距，可点控件不贴边贴角；真机预览状态栏固定顶、不随滚、自身不套安全距。
- 移动页分沉浸式（状态栏透明）与标准（状态栏不透明）；首页沉浸式，列表标准。
- 触屏 Toast 改居中：半透明黑底圆角、白图标加白字。
- 带图标方形按钮：图标与文字上下排在同一底容器内，容器留内边距，禁止图标单独成块。
- 触屏输入独立成行防误触；表单单选/多选用标签+右上对号角标；列表仍用左侧圆圈/方块。
- 原生状态栏电量/信号靠右，不为微信胶囊把它们往里挤；胶囊避让只约束页内可点按钮。
- 列表页搜索行与筛选行贴顶固定；补展示类 PAGE-MP-003 商品详情、表单类 PAGE-MP-004 到货提醒（非下单）。
- 后台 D1-1：页内签放在筛选上方并整区切换筛选/功能/列表/分页；分页与表横向滚动条默认贴底；勾选列左冻、操作列右冻，冻结列内侧浮层阴影。
- 详情非列表图默认 16:9，列表卡仍 1:1；商品详情改为图文混排介绍与评论列表（评论附图 1:1 横向换行）；表单输入右侧留安全距。
- 后台标准页内容区顶部只留面包屑、去掉页内大标题；操作列定宽，多余操作收进「更多」下拉；汇总靠左、分页靠右。
- 评论加时间行，附图一排最多五张；到货提醒表单补五步/无极滑动条、下拉、底半屏日期与省市区三级联动、单图更换/多图可删/文件上传。
- 后台 D1-1 列表列宽按字段语义（名称吃剩余，售价/状态/日期窄）；列表页控件紧凑，一屏多看几行。夹具页型约定写入 UI / PAGE / PROTOTYPE 技能速查。
- 关系图页面块按真机 375×812 比例完整预览；拖动位置写入浏览器缓存；可导出画布为 PNG。
