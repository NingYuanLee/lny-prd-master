## 3. 页面模块详述

```
┌────────────────────────────┐
│ 状态栏（标准）             │
│ 返回 「时间轴」            │
│ 左竖轨 + 右图文            │
│ 已提交 / 审核中 / 待发布 / 已完成 │
└────────────────────────────┘
```

### │ L0 系统层
- **结构与控件**：顶栏 **标准**（状态栏不透明）固定顶、不随滚；左右下及四角安全距；胶囊避让；无 TabBar
- **交互与跳转**：无
- **涉及接口**：无

### │ L1 固定导航层
- **结构与控件**：返回；标题「时间轴」
- **交互与跳转**：返回回 PAGE-MP-001
- **涉及接口**：无

### │ L2 主体滚动层
- **结构与控件**：时间轴列表
- **交互与跳转**：无出页
- **涉及接口**：无

### │ L3 模块容器层
- **结构与控件**：左侧竖状结构、右侧图文；节点「已提交」「审核中」「待发布」「已完成」
- **交互与跳转**：点节点切换当前高亮
- **涉及接口**：无
