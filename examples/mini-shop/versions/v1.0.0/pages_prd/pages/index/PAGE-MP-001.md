## 3. 页面模块详述

```
┌────────────────────────────┐
│ 下沉 Banner「季节鲜选」    │
├────────────────────────────┤
│ 金刚区 5 列                │
│ 推荐 [商品卡片 1:1]        │
├────────────────────────────┤
│ TabBar 贴底：首页 | 商品   │
└────────────────────────────┘
```

### │ L0 系统层
- **结构与控件**：顶栏 **沉浸式**（状态栏透明）固定顶、不随滚；下沉 Banner；左右下及四角安全距；胶囊避让；TabBar 贴底固定
- **交互与跳转**：Tab「商品」切到 PAGE-MP-002
- **涉及接口**：无

### │ L1 固定导航层
- **结构与控件**：无页内顶栏
- **交互与跳转**：无
- **涉及接口**：无

### │ L2 主体滚动层
- **结构与控件**：下沉 Banner；金刚区；推荐区
- **交互与跳转**：无
- **涉及接口**：API-MP-001

### │ L3 模块容器层
- **结构与控件**：**商品卡片（详见 ui/COMP-001.md）** 1:1 封面
- **交互与跳转**：本夹具点击无跳转
- **涉及接口**：API-MP-001

### │ L5 浮层与反馈层（如有）
- **结构与控件**：底半屏「分类」；按钮「去商品列表」；Toast
- **交互与跳转**：金刚项打开半屏；主按钮进 PAGE-MP-002
- **涉及接口**：无
