## 3. 页面模块详述

```
┌────────────────────────────┐
│ 状态栏（标准）             │
│ 返回 + 搜索框              │
│ 下划线页签 + 筛选          │
│ 订单横卡列表（仅此区滚动） │
└────────────────────────────┘
```

### │ L0 系统层
- **结构与控件**：标准顶栏固定；安全距；无 TabBar
- **交互与跳转**：无
- **涉及接口**：无

### │ L1 固定导航层
- **结构与控件**：`md-appbar--with-search` 返回+搜索；`md-list-toolbar` 下划线页签+筛选
- **交互与跳转**：返回 PAGE-MP-001；搜索提交刷新；筛选开右半屏
- **涉及接口**：API-MP-003

### │ L2 主体滚动层
- **结构与控件**：页签面板内 `md-stack` 订单横卡；上拉加载
- **交互与跳转**：切换页签换面板
- **涉及接口**：API-MP-003

### │ L3 模块容器层
- **结构与控件**：`md-card--order`（推广条/店头/商品行/实付款/操作条；更多菜单）
- **交互与跳转**：店头/推广/商品行 → PAGE-MP-003；查看物流 → PAGE-MP-009
- **涉及接口**：API-MP-003

### │ L5 浮层与反馈层（如有）
- **结构与控件**：筛选右半屏+遮罩；更多局部菜单
- **交互与跳转**：遮罩关闭筛选
- **涉及接口**：无
