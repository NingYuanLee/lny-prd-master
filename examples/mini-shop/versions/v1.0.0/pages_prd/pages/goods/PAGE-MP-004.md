## 3. 页面模块详述

```
┌────────────────────────────┐
│ 状态栏（标准）             │
│ 返回 「到货提醒」          │
│ 「填写资料」               │
│ 「联系人」                 │
│ 「联系电话」               │
│ 「通知方式」标签           │
│ 「提醒优先级」五步滑动     │
│ 「可接受溢价」无极滑动     │
│ 「期望规格」下拉           │
│ 「期望到货日期」底半屏     │
│ 「收货地区」底半屏         │
│ 「包装参考」单图更换       │
│ 「现场照片」多图可删       │
│ 「到货凭证」文件           │
│ 允许店铺联系我             │
│ 「备注」                   │
├────────────────────────────┤
│ 贴底「取消」「提交」       │
└────────────────────────────┘
```

### │ L0 系统层
- **结构与控件**：顶栏 **标准**（状态栏不透明）固定顶、不随滚；左右下及四角安全距；胶囊避让；无 TabBar
- **交互与跳转**：无
- **涉及接口**：无

### │ L1 固定导航层
- **结构与控件**：返回；标题「到货提醒」；主操作条「取消」「提交」贴底固定
- **交互与跳转**：返回或「取消」回 PAGE-MP-003
- **涉及接口**：无

### │ L2 主体滚动层
- **结构与控件**：分区「填写资料」与表单字段；输入框右侧留安全距
- **交互与跳转**：无出页
- **涉及接口**：无

### │ L3 模块容器层
- **结构与控件**：「联系人」「联系电话」「通知方式」（「微信通知」「短信」）、「提醒优先级」五步滑动条、「可接受溢价」无极滑动条、「期望规格」下拉、「期望到货日期」底半屏年-月-日三级联动、「收货地区」底半屏省-市-区三级联动、「包装参考」单图/视频可「更换」、「现场照片」可「添加」可「删除」、「到货凭证」文件、「备注」；开关允许店铺联系我；每项独立成行
- **交互与跳转**：提交调用 API-MP-003
- **涉及接口**：API-MP-003

### │ L5 浮层与反馈层（如有）
- **结构与控件**：日期/地区底半屏；校验与成功/失败 Toast
- **交互与跳转**：点遮罩关闭半屏
- **涉及接口**：无
