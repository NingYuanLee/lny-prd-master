## 3. 页面模块详述

```
┌────────────────────────────┐
│ 状态栏（标准）             │
│ 返回 「步骤向导」          │
│ 【三选一】数字步骤 或 分段进步 或 无极进度 │
│ 当前步表单                 │
├────────────────────────────┤
│ 贴底「上一步」「下一步」   │
└────────────────────────────┘
```

### │ L0 系统层
- **结构与控件**：顶栏 **标准**（状态栏不透明）固定顶、不随滚；左右下及四角安全距；胶囊避让；无 TabBar
- **交互与跳转**：无
- **涉及接口**：无

### │ L1 固定导航层
- **结构与控件**：返回；标题「步骤向导」；主操作条「上一步」「下一步」贴底固定；最后一步主按钮为「提交」
- **交互与跳转**：返回回 PAGE-MP-001
- **涉及接口**：无

### │ L2 主体滚动层
- **结构与控件**：一种导览 + 当前步表单（金样用签对照三种写法）
- **交互与跳转**：无出页
- **涉及接口**：无

### │ L3 模块容器层
- **结构与控件**：**三选一**：横向数字步骤 **或** 分段进步条 **或** 无极进度条；当前步表单（名称/说明、选项/开关、确认）。禁止同页叠加多种导览
- **交互与跳转**：**仅数字步骤可点跳步**；分段/无极只展示；上一步/下一步切换步骤；「提交」仅 Toast「已提交」
- **涉及接口**：无

### │ L5 浮层与反馈层（如有）
- **结构与控件**：提交 Toast
- **交互与跳转**：无
- **涉及接口**：无
