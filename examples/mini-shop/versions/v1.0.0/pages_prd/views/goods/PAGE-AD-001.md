## 3. 页面模块详述

```
┌──────────────────────────────────────────┐
│  搜索栏：[商品名称] [查询]               │
├──────────────────────────────────────────┤
│  功能栏：无新增                          │
├──────────────────────────────────────────┤
│  列表：名称 | 售价 | 库存状态 | 操作     │
│  （操作列无按钮）                        │
├──────────────────────────────────────────┤
│  汇总 + 分页                             │
└──────────────────────────────────────────┘
```

### │ D1-1 标准内容区

#### ││ 搜索栏
- **结构与控件**：商品名称输入；查询按钮
- **交互与跳转**：无出页
- **涉及接口**：API-AD-001

#### ││ 功能栏
- **结构与控件**：无新增按钮（本夹具只读列表）
- **交互与跳转**：无
- **涉及接口**：无

#### ││ 列表区（含操作列）
- **结构与控件**：列：商品名称、售价、库存状态；操作列无按钮
- **交互与跳转**：无出页
- **涉及接口**：API-AD-001

#### ││ 汇总栏 + 分页栏
- **结构与控件**：总条数；当前页码、每页条数
- **交互与跳转**：翻页仍在本页
- **涉及接口**：API-AD-001

### │ D5 浮层与反馈层
- **结构与控件**：无弹窗
- **交互与跳转**：无
- **涉及接口**：无
