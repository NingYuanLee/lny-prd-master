## 3. 页面模块详述

```
┌──────────────────────────────────────────┐
│ 面包屑：商品 / 商品表单（无页内大标题）  │
├──────────────────────────────────────────┤
│ 名称 / 售价 / 库存状态                     │
│ 上架日期 / 上架时间 / 上架开关             │
│ 配送：包邮 / 到店自提                      │
│ 渠道：小程序 / 后台展示                    │
│ 商品简介                                   │
│ [取消] [保存]                              │
└──────────────────────────────────────────┘
```

### │ D1-2 表单内容区
- **结构与控件**：顶部面包屑，无页内大标题；商品名称、售价、库存状态下拉、上架日期、上架时间、「上架」开关、配送方式单选「包邮」「到店自提」、适用渠道多选「小程序」「后台展示」、商品简介；「保存」「取消」
- **交互与跳转**：「保存」提交后回 PAGE-AD-001；「取消」直接回列表；校验失败页内 Alert
- **涉及接口**：API-AD-003

### │ D5 浮层与反馈层
- **结构与控件**：无弹窗；校验失败 Alert
- **交互与跳转**：无
- **涉及接口**：无
