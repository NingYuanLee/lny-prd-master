## 2. 壳层结构

- **顶栏**：站点名 Mini Shop；用户区沿用框架
- **侧栏**：一级模块「商品」；二级「商品列表」对应 PAGE-AD-001；二级「商品详情」对应 PAGE-AD-008；二级「商品表单」对应 PAGE-AD-002。一级模块「套件」；二级「表单」对应 PAGE-AD-009；二级「时间轴」对应 PAGE-AD-007
- **面包屑**：模块 / 页面名称；业务页内容区顶部即为面包屑，不再重复页内大标题
- **主内容区**：承载 `PAGE-AD-*` 业务页
