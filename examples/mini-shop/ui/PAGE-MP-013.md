## 2. 页面层级及布局描述

### 2.1 移动端结构（操控形态=移动端时填写）

#### │ L0 系统层
- 顶栏模式 **标准**；状态栏固定顶；正文左右下及四角留安全距；无 TabBar。

#### │ L1 固定导航层
- 返回按钮与标题「分类导航」固定在顶部。

#### │ 步骤区（有序向导 / 引导分步页必填；其它页写无）
- 无。

#### │ L2 主体内容层
- `md-locator-page` 左侧一级分组，右侧为按分组排列的商品横卡；左右区域独立滚动。

#### │ L3 模块容器层
- 左栏使用 `md-locator--outline`；右栏每组包含产品文案标题与至少四条横卡。

#### │ L4 内容元素层
- 点左侧分组滚动到右侧锚点；滚动右侧内容时同步高亮当前分组。

#### │ L5 浮层与反馈层（如有）
- 轻量失败使用 Toast；列表加载失败在右区展示可重试 Alert。

### 2.3 交互体验设计（必填，移动/桌面都写）

- **观感与舒适**：左侧分组保持紧凑，右侧横卡突出商品名称和辅助信息；首屏直接展示当前分组内容。
- **加载 / 空 / 失败**：右区先展示骨架；无内容时给出空态文案；失败时提供页内重试。
- **键盘与焦点**：触屏不依赖 hover；所有分组与横卡均有可见按下态。
- **首次进入**：默认选中第一个分组并定位到第一组内容。
- **动效与过渡**：锚点滚动使用平滑过渡；高亮切换不造成布局位移。
- **微反馈**：点击分组和横卡均有按下反馈；无额外模态提示。
- **收纳与浮层**：主路径全部在左右联动区内完成，不增加弹窗或半屏。
