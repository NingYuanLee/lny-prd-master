## 2. 页面层级及布局描述

### 2.1 移动端结构（操控形态=移动端时填写）

#### │ L0 系统层
- 顶栏模式 **标准**；无 TabBar

#### │ L1 固定导航层
- 返回 + 标题「章节目录」

#### │ L2 主体滚动层
- `md-chapter-list` 父子章节列表滚动

#### │ L3 模块容器层
- 每组 `md-chapter-list__group`：父章行 + 可收起 `__body` 子章列表

#### │ L4 内容元素层
- 父章 `__parent` 加粗；子章 `__child` 缩进+圆点；左 chevron 展开/收起

#### │ L5 浮层与反馈层（如有）
- 无

### 2.3 交互体验设计（必填）

- **观感与舒适**：父章一行可点标题跳转；左侧 toggle 只负责展开/收起子章，不跳转。
- **加载 / 空 / 失败**：列表骨架；空态引导；失败 Toast。
- **收纳与浮层**：整页列表直出；不是 split 左栏、不是横卡、不是可维护树。
