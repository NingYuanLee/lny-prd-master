## 2. 页面层级及布局描述

### 2.2 桌面端结构（操控形态=桌面端时填写）

#### │ D1-2 表单内容区（如使用）
- 内容区顶部为面包屑（商品 / 商品表单），无页内大标题
- 录入态：商品名称、售价、库存状态下拉、上架日期、上架时间、「上架」开关、配送方式单选（包邮 / 到店自提）、适用渠道多选（小程序 / 后台展示）、商品简介
- 「保存」提交 API-AD-003 后回 PAGE-AD-001；「取消」直接回列表
- 校验失败页内 Alert，不弹窗

#### │ D5 浮层与反馈层（如有）

| 弹窗名称 | 类型（表单/列表/展示） | 触发入口 |
|----------|------------------------|----------|
| 无 | 无 | 无 |

- 保存成功 Toast 在返回列表后展示（本页不单开弹窗）

### 2.3 交互体验设计（必填）

- **观感与舒适**：内容区顶只有面包屑；整页表单，字段用紧凑输入（与按钮同高），两列栅格减少一屏过长；主按钮在表单底，取消为文字按钮降低误触权重。
- **动效与过渡**：本页无弹窗；回列表后 Toast 滑入（快）。
- **微反馈**：保存中可禁用按钮；校验失败页内 Alert（不打断成模态）；成功回列表 Toast。
- **收纳与浮层**：完整录入用整页（字段多于快捷编辑）；不把整表塞进弹窗；取消直接回列表，不二次确认（未提交、可再进）。
