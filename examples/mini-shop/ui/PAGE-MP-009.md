## 2. 页面层级及布局描述

### 2.1 移动端结构（操控形态=移动端时填写）

#### │ L0 系统层
- 顶栏模式 **标准**；无 TabBar

#### │ L1 固定导航层
- 返回 + 标题「物流时间轴」

#### │ L2 主体滚动层
- 整页滚动物流轨迹节点

#### │ L3 模块容器层
- **`md-timeline md-timeline--static`**（只读，不可点节点切态）
- 左竖轨 + 右 **横卡文本**（`md-card--row` 无左图；标题 + 说明 + 时间/地点；正文可 `__photos` 多小图）
- **仅展示已发生节点**；倒序（最新在上、起点在下）
- 竖轨节点态：`is-active` 当前最新（实心+外圈）；`is-path` 途经（小圆点）；`is-origin` 起点（空心圆）；**禁止** `is-future` 灰色占位未发生节点
- 竖线全程主色

#### │ L4 内容元素层
- 模块标题「物流轨迹」+ 订单号 caption

#### │ L5 浮层与反馈层（如有）
- 无

### 2.3 交互体验设计（必填）

- **观感与舒适**：当前节点一眼可辨；起点空心与途经小圆点层级清晰；竖轨连续主色无灰段。
- **加载 / 空 / 失败**：进页骨架或加载态；无轨迹空态文案；失败可重试。
- **键盘与焦点**：只读页，无输入。
- **首次进入**：展示接口返回的已发生节点，最新在上。
- **动效与过渡**：无节点切换动效（只读）。
- **微反馈**：无点按切态；返回按下反馈。
- **收纳与浮层**：主路径整页直出。
