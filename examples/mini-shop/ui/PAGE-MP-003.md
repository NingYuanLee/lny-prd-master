## 2. 页面层级及布局描述

### 2.1 移动端结构（操控形态=移动端时填写）

#### │ L0 系统层
- 顶栏模式 **沉浸式**（状态栏背景透明）；真机预览状态栏固定顶、不随页滚，电量/信号靠右；页内可点控件避让右上胶囊，禁止在胶囊区放按钮；圆角/曲面屏左右下及四角留安全距；无 TabBar

#### │ L1 固定导航层
- 无 TabBar；返回叠在下沉图左上，贴顶固定、不随滚，右侧留空避让胶囊
- 主操作条「收藏」贴底固定、不随 L2 滚动；点击 Toast「本页只展示，不下单」，无出页

#### │ L2 主体滚动层
- 首模块商品图为 **下沉式** **16:9** 轮播（从屏幕顶铺起，状态栏与返回叠在图上）；其下名称/价格/库存、图文混排「商品说明」、评论列表

#### │ L3 模块容器层
- 图集：指示点、自动轮播，主图 **16:9**
- 信息块：名称、售价、库存标签
- 「商品说明」图文混排：段落文案与 **16:9** 配图交替
- 「评论」列表：每条含评论人、**评论时间行**、评论文案、评论图片；图片 **1:1**、圆角，横向排布一排最多五张、超出换行，上下左右有间距

#### │ L4 内容元素层
- 标题「商品详情」给读屏/身份，不另做实心顶栏；可点元素无下划线，按下有反馈，热区 ≥44px

#### │ L5 浮层与反馈层（如有）
- 请求失败 Toast；点图片放大阅览，同页图片为一组，可按顺序翻页查看，到头不循环；本页只读，无编辑弹窗

### 2.3 交互体验设计（必填）

- **观感与舒适**：沉浸式 16:9 大图做主视觉，图文说明次之，评论在下；返回叠在图上不挡主体；无 TabBar，用贴底「收藏」收次要动作（Toast，不出页）；一屏先看清图和价。
- **动效与过渡**：图集自动轮播（中）；点图放大阅览过渡；返回出页可瞬切。
- **微反馈**：返回、主按钮按下缩放；失败居中 Toast（半透明黑底、白图标白字）。
- **收纳与浮层**：详情主路径页内直出；点任意图片进入放大阅览，同页图片按文档顺序为一组，可上一张下一张且到头不循环；点遮罩或关闭退出；不下单；不跳转到表单样例页。
