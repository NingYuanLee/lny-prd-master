## 2. 页面层级及布局描述

### 2.1 移动端结构（操控形态=移动端时填写）

#### │ L0 系统层
- 顶栏模式 **标准**（状态栏背景不透明）；真机预览状态栏固定顶、不随页滚；页内可点控件避让右上胶囊；圆角/曲面屏留安全距；**无 TabBar**

#### │ L1 固定导航层
- **返回 + 搜索**顶栏（`md-appbar--with-search`）：左侧返回；右侧搜索框占位「搜索商品名/订单号/快递单号」
- **页签 + 筛选**行贴顶固定（`md-list-toolbar`，在 body 外）：下划线可滚动页签（全部 / 待支付 / 待发货 / 待收货/使用 / 评价角标）；右侧筛选图标
- 无贴底主操作条

#### │ L2 主体滚动层
- 仅订单横卡列表滚动；可按页签切换面板；上拉加载更多

#### │ L3 模块容器层
- **`md-card--order` 订单横卡**（可选推广条 / 店头+状态 / 多行商品价量 / 实付款 / 浅底操作条）
- 操作区：「更多」靠左；其余 `md-btn--soft` 靠右；操作多则「更多」开局部菜单

#### │ L4 内容元素层
- 店名后 `chevron-right` 进店铺；商品行进详情；可点元素无下划线，按下有反馈

#### │ L5 浮层与反馈层（如有）
- 筛选：右半屏抽屉 + 遮罩（`orderFilterSheetBackdrop`）；订单类型等筛选项
- 「更多」：局部菜单（删除订单等）
- 搜索提交 Toast；请求失败 Toast

### 2.3 交互体验设计（必填）

- **观感与舒适**：返回+搜索一行够宽；页签选中短横条；评价 Tab 角标右上角；订单卡推广条/店头/商品行间分割清晰；实付款与操作条浅底分隔。
- **加载 / 空 / 失败**：列表骨架；空态「暂无 xx 订单」+ 引导；失败页内可重试或 Toast。
- **键盘与焦点**：触屏不靠 hover；搜索键盘 enter 提交。
- **首次进入**：默认「全部」页签；无订单时面板内空态文案。
- **动效与过渡**：筛选右半屏滑入（中）；页签切换快切面板。
- **微反馈**：卡片/按钮/页签按下反馈；搜索、筛选应用 Toast。
- **收纳与浮层**：筛选收右半屏；破坏性操作（删除）经菜单确认或 Toast。
