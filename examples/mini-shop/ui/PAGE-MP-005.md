## 2. 页面层级及布局描述

### 2.1 移动端结构（操控形态=移动端时填写）

#### │ L0 系统层
- 顶栏模式 **标准**（状态栏背景不透明）；真机预览状态栏固定顶、不随页滚，电量/信号靠右；页内可点控件避让右上胶囊，禁止在胶囊区放按钮；圆角/曲面屏左右下及四角留安全距；无 TabBar

#### │ L1 固定导航层
- 无 TabBar；页内顶栏左侧返回、标题「步骤向导」，右侧避让胶囊
- 主操作条「上一步」「下一步」贴底固定、不随 L2 滚动；最后一步主按钮改为「提交」

#### │ L2 主体滚动层
- 横向步骤、分段进步条、无极进度条始终可见；其下为当前步表单，其它步隐藏

#### │ L3 模块容器层
- 横向步骤：`md-stepper`（第一步 / 第二步 / 第三步）；已完成步连线点亮，当前步高亮；可点步骤跳转
- 分段进步条：`md-advance md-advance--lg`，三段与步骤同步
- 无极进度条：`md-progress md-progress--lg`，连续轨道随步骤更新百分比
- 当前步表单：第一步名称/说明；第二步选项/开关；第三步确认文案。物流轨迹见 PAGE-MP-009（订单模块）

#### │ L4 内容元素层
- 可点元素无下划线，按下有反馈，热区 ≥44px；触屏不靠 hover

#### │ L5 浮层与反馈层（如有）
- 最后一步点「提交」：居中 Toast「已提交」

### 2.3 交互体验设计（必填）

- **观感与舒适**：标准顶栏标明「步骤向导」；步骤与两条进度始终在表单上方，当前步清楚；主按钮贴底。
- **加载 / 空 / 失败**：本页为套件样例、进页即展示，无列表请求；无骨架。提交只用 Toast，不白屏。
- **键盘与焦点**：触屏不靠 hover；第一步禁用「上一步」。
- **首次进入**：无首次引导；打开即见第一步与两条进度。
- **动效与过渡**：进步条/进度条宽度过渡（快）；Toast 淡入（快）。
- **微反馈**：步骤、贴底按钮按下有反馈；提交 Toast「已提交」。
- **收纳与浮层**：主路径整页直出；只露当前步表单，不把时间轴塞进向导。
