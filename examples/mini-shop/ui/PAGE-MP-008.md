## 2. 页面层级及布局描述

### 2.1 移动端结构（操控形态=移动端时填写）

#### │ L0 系统层
- 顶栏模式 **标准**（状态栏背景不透明）；真机预览状态栏固定顶、不随页滚，电量/信号靠右；页内可点控件避让右上胶囊；左右下及四角留安全距；无 TabBar

#### │ L1 固定导航层
- 无 TabBar；页内顶栏左侧返回、标题「分类」，右侧避让胶囊

#### │ L2 主体滚动层
- 左树右内容铺满剩余高度；点节点只换右区

#### │ L3 模块容器层
- `md-tree-page` + `md-split`；左侧 `md-tree` 箭头展开收起；右侧随选中分类切换商品

#### │ L4 内容元素层
- 可点元素无下划线，按下有反馈，热区 ≥44px；触屏不靠 hover

#### │ L5 浮层与反馈层（如有）

### 2.3 交互体验设计（必填）

- **观感与舒适**：标准顶栏标明「分类」；左树右内容对齐，当前节点高亮。
