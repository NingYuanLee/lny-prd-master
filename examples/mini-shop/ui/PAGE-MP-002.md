## 2. 页面层级及布局描述

### 2.1 移动端结构（操控形态=移动端时填写）

#### │ L0 系统层
- 顶栏模式 **标准**（状态栏背景不透明）；真机预览状态栏固定顶、不随页滚，电量/信号靠右；页内可点控件避让右上胶囊，禁止在胶囊区放按钮；圆角/曲面屏左右下及四角留安全距；壳层 TabBar 贴底固定

#### │ L1 固定导航层
- L2 **居中标题栏**「在售商品」贴顶固定；TabBar 贴底固定、不随滚动消失
- **搜索框行**贴顶固定、不随 L2 滚动；搜索与 **筛选图标**同一行（筛选改条件后图标高亮）

#### │ L2 主体滚动层
- 仅横卡列表滚动；上拉加载更多

#### │ L3 模块容器层
- **商品卡片（详见 ui/COMP-001.md）** 纵向横卡，封面 **1:1**

#### │ L4 内容元素层
- 搜索框占位「搜索在售商品」；左侧仅搜索图标，无「搜索」文案、无右侧搜索按钮；卡片内名称与价格；可点元素无下划线，按下有反馈

#### │ L5 浮层与反馈层（如有）
- 「筛选」打开右侧半屏（过渡）；选项用标签（选中右上对号角标）；「清空」先弹出确认框，确定后 Toast「已清空筛选」
- 搜索提交 Toast「已搜索」；请求失败 Toast

### 2.3 交互体验设计（必填）

- **观感与舒适**：顶栏 **标准**（状态栏不透明）；居中标题 + 搜索与筛选图标贴顶固定，一伸手就能改条件，列表在下方单独滚；横卡 1:1 封面+名称价格，一屏约 3 条；Tab 与半屏把手不贴屏角。
- **动效与过渡**：右半屏筛选过渡滑入（中）；确认框缩放淡入；禁止抽屉瞬切。
- **微反馈**：筛选/卡片/Tab/搜索按下缩放；应用筛选、已搜索居中 Toast（半透明黑底、白图标白字）；清空须确认后再 Toast「已清空筛选」；失败 Toast。
- **收纳与浮层**：列表主路径直出；筛选收右半屏；清空是破坏性操作用确认框，不用 Toast 代替确认。
