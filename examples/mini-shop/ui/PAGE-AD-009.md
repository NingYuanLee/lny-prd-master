## 2. 页面层级及布局描述

### 2.2 桌面端结构（操控形态=桌面端时填写）

#### │ D1-2 表单内容区（如使用）

- 内容区顶部为面包屑（套件 / 表单），无页内大标题
- 本页是桌面表单控件样例，下列形态须全部出现，禁止只画两三个输入框：
- 文本：单行、数字、电话、多行、只读（灰底淡字）
- 选择：单选、多选（左侧圆/方，不要触屏标签角标）、开关、下拉少选项、下拉多选项（桌面原生下拉，不要底半屏）
- 滑动条：五步 `--steps`、无极 `--fluid`（显示当前值）
- 日期与地区：单日月历 `md-field--date`、时间 `md-field--time`、日期段 `md-field--daterange`、省市区三级下拉
- 上传：单图可更换、多图可删可添加、文件上传 + 上传进度条
- 「取消」「提交」在表单底；进度条不要再铺一条填写进度（见步骤向导）

#### │ D5 浮层与反馈层（如有）

| 弹窗名称 | 类型（表单/列表/展示） | 触发入口 |
|----------|------------------------|----------|
| 无 | 无 | 无 |

- 缺必填、提交成功、取消：Toast；单日月历、日期段点选，不要触屏底半屏

### 2.3 交互体验设计（必填）

- **观感与舒适**：顶只有面包屑；控件按模块分组，两列栅格；字段用 `md-field--sm`，不要 56px 大框；只读灰底淡字。
- **加载 / 空 / 失败**：套件样例、进页即展示，无骨架。提交失败 Toast，不白屏。
- **键盘与焦点**：Tab 顺序随字段；主按钮回车提交；焦点可见。
- **首次进入**：无首次引导；打开即见全套控件。
- **动效与过渡**：月历/日期段显隐过渡（中）；Toast 淡入（快）。
- **微反馈**：缺「单行文本」或「电话」Toast「请填写单行文本与电话」；成功 Toast「已提交」；取消 Toast「已取消」。
- **收纳与浮层**：主路径整页直出；日期用月历点选，不要底半屏滚轮。
