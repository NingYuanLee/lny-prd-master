## 2. 页面层级及布局描述

### 2.1 移动端结构（操控形态=移动端时填写）

#### │ L0 系统层
- 顶栏模式 **沉浸式**（状态栏背景透明）；真机预览状态栏固定顶、不随页滚，电量/信号靠右；页内可点控件避让右上胶囊，禁止在胶囊区放按钮；圆角/曲面屏左右下及四角留安全距；壳层 TabBar：首页、商品，贴底固定

#### │ L1 固定导航层
- 无页内顶栏；TabBar 贴底固定、不随滚动消失

#### │ L2 主体滚动层
- 首模块 Banner 轮播为下沉式（从屏幕顶铺起，状态栏叠在图上）；其下金刚区、推荐商品

#### │ L3 模块容器层
- Banner：指示点、自动轮播，slogan「季节鲜选」
- 金刚区五列：全部 / 水果 / 饮品 / 烘焙 / 坚果；每项图标与文字上下排在同一块方形底内
- **商品卡片（详见 ui/COMP-001.md）** 双列宫格，封面 1:1

#### │ L4 内容元素层
- 分区标题「推荐」；可点元素无下划线，按下有反馈，热区 ≥44px

#### │ L5 浮层与反馈层（如有）
- 点击金刚项打开底半屏「分类」（过渡滑入）；主按钮「去商品列表」进 PAGE-MP-002
- Toast「已选择分类」

### 2.3 交互体验设计（必填）

- **观感与舒适**：顶栏 **沉浸式**（状态栏透明叠在 Banner 上）；首屏下沉 Banner 做主视觉，金刚区次之，推荐商品在下；金刚项图标与文字上下排在同一块方形底内、有内边距；无页内顶栏，避免和胶囊、Tab 抢身份；封面 1:1，一屏能看完 Banner+金刚+两行卡；Tab/金刚首尾项/slogan 不贴屏角。
- **动效与过渡**：Banner 自动轮播（中）；底半屏「分类」过渡滑入（中）；禁止半屏瞬切。
- **微反馈**：金刚项、卡片、Tab 按下缩放；选分类后居中 Toast「已选择分类」（半透明黑底、白图标白字）；热区 ≥44px，无下划线。
- **收纳与浮层**：主路径（推荐商品）页内直出；分类用底半屏收纳，主按钮再去列表；不用弹窗挡首屏。
