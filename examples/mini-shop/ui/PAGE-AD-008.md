## 2. 页面层级及布局描述

### 2.2 桌面端结构（操控形态=桌面端时填写）

#### │ D1-3 自定义内容区（如使用）

- 内容区顶部为面包屑（商品 / 商品列表 / 商品详情），无页内大标题
- 首屏左 16:9 图集、右名称/售价/库存；其下「商品说明」图文混排、「评论」列表
- 次要操作「收藏」Toast「本页只展示，不下单」；「返回列表」回 PAGE-AD-001
- 不要沉浸式叠层，不要做成可编辑表单，不要套 D1-1 商品表

##### ││ 图集与信息

- 图集指示点、自动轮播，主图 **16:9**
- 信息块：名称、售价、库存标签

##### ││ 商品说明

- 段落文案与 **16:9** 配图交替

##### ││ 评论

- 每条含评论人、**评论时间行**、评论文案、评论图片
- 图片 **1:1**、圆角，横向排布一排最多五张、超出换行

#### │ D5 浮层与反馈层（如有）

| 弹窗名称 | 类型（表单/列表/展示） | 触发入口 |
|----------|------------------------|----------|
| 无 | 无 | 无 |

- 请求失败 Toast；点图片放大阅览，同页图片为一组，可按顺序翻页查看，到头不循环；本页只读，无编辑弹窗

### 2.3 交互体验设计（必填）

- **观感与舒适**：顶只有面包屑；一屏先看清 16:9 图和价，图文说明与评论在下；评论附图 1:1、一排最多五张。
- **加载 / 空 / 失败**：进页请求详情；失败 Toast 可重试。无评论时仅文案。夹具进页即展示，无骨架。
- **键盘与焦点**：收藏、返回列表可 Tab；焦点可见。放大阅览可用方向键翻页、Esc 关闭。
- **首次进入**：无首次引导。
- **动效与过渡**：图集自动轮播（中）；点图放大阅览过渡；返回列表可瞬切。
- **微反馈**：按钮按下；失败 Toast。
- **收纳与浮层**：详情主路径整页直出；点任意图片进入放大阅览，同页图片按文档顺序为一组，可上一张下一张且到头不循环；点遮罩或关闭退出；列表「查看」仍走展示弹窗（PAGE-AD-001），本页是整页核对夹具；不下单。
