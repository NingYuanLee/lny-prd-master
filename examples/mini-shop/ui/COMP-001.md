# COMP-001 商品卡片 组件详述

## 1. 基本信息

| 属性 | 内容 |
|------|------|
| 组件名称 | 商品卡片 |
| 组件编号 | COMP-001 |
| 设计前提 | 多页复用 |
| 独立视觉状态机 | 是 |
| 适用终端 | MP |
| 覆盖页面 | ui/PAGE-MP-001.md, ui/PAGE-MP-002.md |
| 来源 | 新建 |

## 2. 用途与范围

- **用途**：展示单个在售商品的封面、名称与价格
- **判定依据**：首页推荐与列表页重复出现
- **适用场景**：L3 商品栅格或横卡
- **边界与排除项**：后台表格行不使用本组件；详情主图不是本组件
- **单职责**：卡片自洽管理默认态、加载态及不可用反馈

## 3. 结构与交互

- **结构分层**：封面图（**1:1**）、标题、价格
- **交互表现**：整卡按上游既定动作响应；按下时先缩放反馈，再由所在页面完成后续动作
- **动效与微反馈**：按下整卡轻微缩放；loading 用骨架脉冲
- **状态机与区块联动（如有）**：无
- **状态切换入口**：无（单态为主；空/错由壳层或列表编排）

## 4. UI 状态矩阵（必填）

| 状态 | 触发条件 | 展示要点 | 可执行操作 |
|------|----------|----------|------------|
| loading | 列表请求中 | 骨架块 | 禁用点击 |
| empty | 上游返回空结果 | 不渲染卡片 | 无 |
| error | 上游加载失败 | 不渲染卡片 | 无 |
| default | 有商品数据 | 1:1 封面+名称+价格 | 点击（所在页定义出页） |

- **默认态 / 交互态**：按下缩放；loading/empty/error 时禁用点击
