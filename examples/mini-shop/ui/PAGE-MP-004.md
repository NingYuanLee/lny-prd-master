## 2. 页面层级及布局描述

### 2.1 移动端结构（操控形态=移动端时填写）

#### │ L0 系统层
- 顶栏模式 **标准**（状态栏背景不透明）；真机预览状态栏固定顶、不随页滚，电量/信号靠右；页内可点控件避让右上胶囊，禁止在胶囊区放按钮；圆角/曲面屏左右下及四角留安全距；无 TabBar

#### │ L1 固定导航层
- 无 TabBar；页内顶栏左侧返回、标题「表单」，右侧避让胶囊
- 主操作条「取消」「提交」贴底固定、不随 L2 滚动

#### │ L2 主体滚动层
- 按模块滚动：文本、选择、滑动条、日期与地区、上传；输入独立成行，右侧留安全距

#### │ L3 模块容器层
本页是触屏表单控件样例，下列形态须全部出现，禁止只画两三个输入框：
- 文本：单行、数字、电话、多行、只读/禁用（视觉一致）
- 选择：单选标签、多选标签（选中右上对号角标）、开关、下拉少选项（≤6，中间弹窗）、下拉多选项（≥7，底半屏）
- 滑动条：五档位 `--steps`、无极 `--fluid`（显示当前值）
- 日期与地区：单日 `data-wheel="date"`、日期段 `data-wheel="daterange"`（开始/结束两个签）、省市区 `data-wheel="region"`（无开始/结束签）
- 上传：单图可更换、多图可删可添加、文件上传 + 上传进度条

#### │ L4 内容元素层
- 可点元素无下划线，按下有反馈，热区 ≥44px；触屏不靠 hover

#### │ L5 浮层与反馈层（如有）
- 少选项下拉：中间弹窗，过渡缩放淡入
- 多选项下拉、单日、日期段、省市区：底半屏，自下向上滑入，点遮罩关闭
- 缺必填、提交成功：居中 Toast

### 2.3 交互体验设计（必填）

- **观感与舒适**：标准顶栏标明「表单」；控件按模块分组，组间留空防误触；输入框右侧留安全距；主按钮贴底，避免滑到页尾才找提交。
- **加载 / 空 / 失败**：本页为套件样例、进页即展示控件，无列表请求；无骨架。提交失败用 Toast，不白屏。
- **键盘与焦点**：触屏不靠 hover；提交中可禁用主按钮。
- **首次进入**：无首次引导；打开即见全套控件。
- **动效与过渡**：中间弹窗缩放淡入（中）；底半屏自下向上滑入（中），遮罩淡入；Toast 淡入（快）；禁止选择器/半屏瞬切。
- **微反馈**：字段、开关、标签、滑动条、上传按下有反馈；缺单行文本或电话 Toast「请填写单行文本与电话」；成功 Toast「已提交」。
- **收纳与浮层**：主路径整页直出；选项少进中间弹窗、选项多与日期/地区进底半屏，避免页内堆原生选择器。
