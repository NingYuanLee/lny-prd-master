## 页型速查（写单页前扫一眼）

线框 **只定分区顺序**；顺序以 `ui/PAGE` §2.3 与下表为准，⑥ 视觉以 `gold/` 为准（对标下限，禁止照搬演示功能，也禁止忽略金样）。体验细则见 `lny-prd-ui` **§1.3.3 / §1.4.3**。本步不依赖仓库示例。

**移动端 ASCII 自上而下**

| 页型 | 回归标识（无需读取示例） | 线框顺序 | 「结构与控件」须带到的词 |
|------|------|----------|--------------------------|
| TabBar 宫格 | PAGE-MP-001 | 下沉 Banner → 金刚 → 双列卡 → TabBar | 沉浸式；无页内顶栏；叠字/瓷砖可横可竖或定宽随图 |
| 列表 | PAGE-MP-002 | 搜索行+筛选行贴顶 → 页签按钮组 → 列表区横卡多行和/或单行 | 按共享 `PT-MOBILE-LIST` 标出滚动边界、卡型选择、字段层级与操作位置；另写半屏方向和图片比例 |
| 详情 | PAGE-MP-003 | 返回叠 16:9 → 浅灰底上白底区块（标题 → 图文 → 评论）→ 贴底次要操作；右下目录+回顶 | 整页浅灰；短段不缩进、大段 `__body`、多项目 `__list`；单/双图；图注居中；表格可横滑；**评论列表卡** |
| 字段详情 | PAGE-MP-012 | 返回+标题 → 浅灰底上白底分组（字段名+字段值）→ 可多组；右下目录+回顶 | 只读；`md-desc`；长文案上下排；**不要**沉浸式大图、**不要**当表单 |
| 表单（套件样例） | PAGE-MP-004 | 返回顶栏 → 浅灰底白底分组 → 全套表单控件分区 → 贴底提交 | **样例才铺齐**；`md-form-page`；业务表单按规格裁并同样分组；右侧安全距；少选项中间弹窗、多选项/日期/地区底半屏；进度条不在本页 |
| 步骤向导 | PAGE-MP-005 | 返回顶栏 → `md-form-page` 分组 → 横向步骤 → 分段进步条 → 无极进度条 → 当前步表单 → 贴底上一步/下一步 | 最后一步才提交 |
| 时间轴 | PAGE-MP-009 | 返回顶栏 → 时间轴（左竖轨右图文） | 点节点切高亮 |
| 设置 | PAGE-MP-006 | 封面顶栏 → 设置项通栏（当页当行直接操作） | `md-set-page` 浅灰底；两倍标题栏高度；左图标可有可无；开关/无极/横向勾选/本行下拉；不要整行只跳转 |
| 我的 / 服务 | PAGE-MP-010 | 返回顶栏 → 功能入口通栏和/或一行两个和/或金刚（信息多用双卡） | `md-set-page` 浅灰底、组间距漏底；只跳转或开半屏/弹窗；常带右箭头；分组标题可无；金刚不限首页 |
| 树+内容 | PAGE-MP-008 | 返回顶栏 → 左树右内容 | 箭头展开收起；点树只换右区 |
| 按钮（套件样例） | PAGE-MP-007 | 返回顶栏 → 三档按钮分区 → 通栏整行 | 一行一钮用通栏；不要当业务页线框模板 |
| 悬浮胶囊（套件样例） | PAGE-MP-011 | 角上标位置（无标题栏） | 规格点名才画；不要每个项目都写本页 |

规格点名悬浮胶囊/按钮时按共享 `PT-FLOAT` 在线框标角位、避让和展开态；本步不另存位置阈值。

**桌面端 ASCII 自上而下**

| 页型 | 回归标识（无需读取示例） | 线框顺序 | 「结构与控件」须带到的词 |
|------|------|----------|--------------------------|
| D1-1 | PAGE-AD-001 | 面包屑 → 签 → 筛 → 功能 → 表 → 汇总左+分页右贴底 | 点名列表六型；将 `PT-DESKTOP-LIST` 的冻结、操作列按钮数定宽、语义列宽、`md-cell-stack`、紧凑密度写进「结构与控件」 |
| D1-2 | PAGE-AD-002 | 面包屑 → 字段分区 → 保存/取消 | 无页内大标题；表单栅格有上下行距；不要写 D1-1 紧凑行高；不要用窄双列冒充页面分栏 |
| 表单（套件样例） | PAGE-AD-009 | 面包屑 → 全套表单控件分区 → 保存/取消 | **样例才铺齐**；业务表单用 AD-002 按规格裁；日期用月历不是底半屏 |
| 详情 | PAGE-AD-008 | 面包屑 → 浅灰底上白底区块（16:9+标题 → 图文 → 评论）；右下目录+回顶 | 整页浅灰；短段不缩进、大段 `__body`、多项目 `__list`；单/双图；图注居中；**评论列表卡**；金样 `desktop-detail` 图文签 |
| 字段详情 | PAGE-AD-012 | 面包屑 → 浅灰底上白底分组（字段名+字段值，可双列） | 只读；`md-desc--cols-2`；**一条对象**；**不要**卡片壳、沉浸式、D1-1、可编辑表单、lists 分组字段；金样 `desktop-detail` 字段签 |
| 向导 | PAGE-AD-003 | 面包屑 → 步骤条+进步条 → 当前步表单 | 与页签同属状态导览；数字步骤可点跳步；最后一步才提交；当前步字段疏密与整页表单相同 |
| 工作台 | PAGE-AD-004 | 面包屑 → 指标卡 → 趋势 → 待办短表 | 禁止写成 D1-1 商品表 |
| 树+内容 | PAGE-AD-005 | 面包屑 → 左树右表 | 不分页树；总控展开/收起/增根；节点增子/重命名/删除；拖到上/中/下。表内嵌套另写；分类/大纲用定位导航 |
| 页面分栏 | （D1-3） | 面包屑 → 通栏/双列/三列/品字 | `PT-DESKTOP-LAYOUT`；禁止表单窄双列 |
| 设置 | PAGE-AD-006 | 面包屑 → 设置项通栏（当页当行直接操作） → 保存 | `md-set-page` 浅灰底；左图标可有可无；开关/无极/横向勾选/本行下拉；不要整行只跳转 |
| 我的 / 服务 | PAGE-AD-010 | 面包屑 → 功能入口通栏和/或一行两个 | `md-set-page` 浅灰底、组间距漏底；只跳转或开抽屉/弹窗；分组标题可无；常带右箭头 |
| 时间轴 | PAGE-AD-007 | 面包屑 → 通栏竖轨右图文 | 点节点切高亮；不要左右分栏 |
| 章节大纲 | （套件） | 面包屑 → 左可收缩大纲 / 右悬浮大纲 | 两种择一；点选滚锚点；不要做成树 |
| 悬浮按钮（套件样例） | PAGE-AD-011 | 面包屑 → 正文；按共享 `PT-FLOAT` 标悬浮钮 | 只写本页功能与状态，不复述位置阈值 |

禁止：ASCII 漏掉「贴顶/贴底/左冻/右冻/语义列宽/操作列跟钮数/紧凑/表单行距」，把这些留给 ⑥ 去猜；页面分栏写成窄双列表单。

## 开笔前

Read `lny-prd-master/framework-exclusions.md`。不为已排除项生成单页 PRD。Read `main_spec` §1.5「明确不做」（若有）：**禁止**为清单中的能力写单页 PRD。落盘前 **完整 Read [`reference.md`](reference.md)**。

## 职责与禁止

- **负责**：按页生成 `pages_prd`；**项目含 PC 或 AD 时必须**落盘 `pages_prd/_shell/{终端编码}-shell.md`；成功自检后推进本次 `ui_changes.md` 对应行状态。
- **禁止**：抄 `api/` 字段表；编造未立项 PAGE；把约束说明写入产物；单页罗列壳层换页。仅当 PM 已说出点位才写埋点；**禁止自拟埋点方案**。

## 前置条件

已执行 ①②③④；目标 `PAGE-*` 已在 `ui/` 登记。⑧ 委派时以 `ui_changes.md` 的 `pages_prd目标路径` 为准。

## 输入

```yaml
版本号: v1.0.0
页面编号: PAGE-MP-001
页面名称: 首页
接口编号列表: [API-MP-001]
```

未指定版本号时按 master §1.1。

## 执行步骤

1. 校验版本目录与页面编号；有台账则核对目标路径。
2. Read `ui/PAGE-*` + 引用 COMP、`api/API-*`、`feature/`、`main_spec` §1.2（仅作背景）。
3. 按 [`reference.md`](reference.md) 模板落盘；§1 表后写根规格依赖引用块；§3 顶 ASCII 线框默认必填（页型顺序见上方页型速查）。交互、动效、收纳从 `ui/PAGE-*` **§2.3** 带入，禁止降级成「有个按钮」。桌面 D1-1 须写列宽语义与紧凑密度。
4. 路径：`pages/{m}` → `pages_prd/pages/{m}/`；`subpackages/{m}` → `pages_prd/subpackages/{m}/`；`views/{m}` → `pages_prd/views/{m}/`。
5. 若终端含 PC/AD：按壳模板写 `_shell/{编码}-shell.md`（尚无则创建）。
6. 单页 PRD 与桌面壳自检通过后，将本次 `ui_changes.md` 条目由 `待⑤` 改为 `已完成`；有缺口或失败则保留 `待⑤`。
7. 若改了根四规范：`iteration_notes` 文末追加；否则省略。
8. 提示下一步：**⑥ `/lny-prd-prototype`**。⑦ 须用户明确要求检查，不自动跑。
