# 产出单页 PRD `/lny-prd-page`

## Additional resources

- 产出具约束、单页模板、桌面壳模板：[`reference.md`](reference.md)

## 三步对照（防错用）

同一套页型，②⑤⑥ 各看一层，**禁止串用、禁止按编号左右对齐**。

| 步 | 看 | 用来 | 禁止 |
|----|----|------|------|
| ② | 夹具页型 + `ui/PAGE` §2.3 | 体验与结构 | 把金样类名写进规格 |
| ⑤ 本步 | 下方 ASCII 顺序 | 定分区上下 | 当视觉稿；让 ⑥ 按线框画空盒子 |
| ⑥ | `lny-prd-prototype/gold/*.html` | 密度/类名下限 | 整页搬样例；按号猜金样 |

**编号不对齐**（`PAGE-MP-00x` ≠ `PAGE-AD-00x`）：详情 MP-003 / AD-008；向导 MP-005 / AD-003；树 MP-008 / AD-005；时间轴 MP-009 / AD-007；表单铺齐 MP-004 / AD-009；业务表单按规格裁（AD-002）。设置碰巧都是 006，我的碰巧都是 010。

**套件样例 ≠ 业务必有页**：MP-004 / MP-007 / MP-011 / AD-009 / AD-011 的线框只证明控件能铺全。业务表单 ASCII 按规格裁字段。胶囊/悬浮按钮规格点名才在线框角上标，不要为每个项目都写 PAGE-MP-011 / PAGE-AD-011。

**列表页**线框是搜索+筛选工具条，不是返回标题栏。

## 夹具速查（写单页前扫一眼）

夹具 `examples/mini-shop/` 的 ASCII / 分区措辞模板。线框 **只定分区顺序**；⑥ 视觉以 `gold/` 为准（对标下限，禁止照搬演示功能，也禁止忽略金样）。体验细则见 `lny-prd-ui` **§1.3.3 / §1.4.3**。编号与金样以上方对照为准。

**移动端 ASCII 自上而下**

| 页型 | 夹具 | 线框顺序 | 「结构与控件」须带到的词 |
|------|------|----------|--------------------------|
| TabBar 宫格 | PAGE-MP-001 | 下沉 Banner → 金刚 → 双列卡 → TabBar | 沉浸式；无页内顶栏；叠字/瓷砖可横可竖或定宽随图 |
| 列表 | PAGE-MP-002 | 搜索行+筛选行贴顶 → 页签按钮组 → 列表区横卡多行和/或单行 | 搜索/筛选/页签不进滚动区；半屏方向；列表区点名；横卡多行：字段多或值长（字段少因值长：字号略大、高度随内容）；价格/距离右上、按钮右下或底栏；横卡单行：仅字段≤3 且值都短，每行独立有缝（不要连成通栏）；非分组、数据可无限（分页无页边界视觉）；卡轻阴影 |
| 详情 | PAGE-MP-003 | 返回叠 16:9 → 图文介绍 → 评论 → 贴底次要操作 | 时间行；附图约 40px、1:1、一排最多五张；本页图片默认可点预览 |
| 表单（套件样例） | PAGE-MP-004 | 返回顶栏 → 全套表单控件分区 → 贴底提交 | **样例才铺齐**；业务表单按规格裁；右侧安全距；少选项中间弹窗、多选项/日期/地区底半屏；进度条不在本页 |
| 步骤向导 | PAGE-MP-005 | 返回顶栏 → 横向步骤 → 分段进步条 → 无极进度条 → 当前步表单 → 贴底上一步/下一步 | 最后一步才提交 |
| 时间轴 | PAGE-MP-009 | 返回顶栏 → 时间轴（左竖轨右图文） | 点节点切高亮 |
| 设置 | PAGE-MP-006 | 封面顶栏 → 设置项通栏（当页当行直接操作） | 两倍标题栏高度；左图标可有可无；开关/无极/横向勾选/本行下拉；不要整行只跳转 |
| 我的 / 服务 | PAGE-MP-010 | 返回顶栏 → 功能入口通栏和/或一行两个 | 只跳转或开半屏/弹窗；常带右箭头；分组标题可无 |
| 树+内容 | PAGE-MP-008 | 返回顶栏 → 左树右内容 | 箭头展开收起；点树只换右区 |
| 按钮（套件样例） | PAGE-MP-007 | 返回顶栏 → 三档按钮分区 | 不要当业务页线框模板 |
| 悬浮胶囊（套件样例） | PAGE-MP-011 | 角上标位置（无标题栏） | 规格点名才画；不要每个项目都写本页 |

规格点名悬浮胶囊/按钮时，线框角上标位置：
- 触屏：钉在页框；左上横向且与标题栏互斥；左下/右下竖向并避开底栏；单个圆、多个成组细线分；不要右上。
- 桌面：只标右下；独立圆钮竖排；满 4 个写成「收成一颗，可展开，有弹出」。功能钮写成「按下有反馈」。不要左上/左下/右上。

**桌面端 ASCII 自上而下**

| 页型 | 夹具 | 线框顺序 | 「结构与控件」须带到的词 |
|------|------|----------|--------------------------|
| D1-1 | PAGE-AD-001 | 面包屑 → 签 → 筛 → 功能 → 表 → 汇总左+分页右贴底 | 无页内大标题；勾选左冻/操作右冻「更多」；**列宽按语义**（名称吃剩余，售价/状态/日期窄）；**紧凑多看行** |
| D1-2 | PAGE-AD-002 | 面包屑 → 字段分区 → 保存/取消 | 无页内大标题；不要写 D1-1 紧凑行高 |
| 表单（套件样例） | PAGE-AD-009 | 面包屑 → 全套表单控件分区 → 保存/取消 | **样例才铺齐**；业务表单用 AD-002 按规格裁；日期用月历不是底半屏 |
| 详情 | PAGE-AD-008 | 面包屑 → 16:9 图集 → 图文介绍 → 评论 → 次要操作 | 无页内大标题；时间行；附图约 40px、1:1、一排最多五张；本页图片默认可点预览 |
| 向导 | PAGE-AD-003 | 面包屑 → 步骤条+进步条 → 当前步表单 | 数字步骤可点跳步；最后一步才提交；当前步字段疏密与整页表单相同 |
| 工作台 | PAGE-AD-004 | 面包屑 → 指标卡 → 趋势 → 待办短表 | 禁止写成 D1-1 商品表 |
| 树+内容 | PAGE-AD-005 | 面包屑 → 左树右表 | 箭头展开收起；点树只换右区 |
| 设置 | PAGE-AD-006 | 面包屑 → 设置项通栏（当页当行直接操作） → 保存 | 左图标可有可无；开关/无极/横向勾选/本行下拉；不要整行只跳转 |
| 我的 / 服务 | PAGE-AD-010 | 面包屑 → 功能入口通栏和/或一行两个 | 只跳转或开抽屉/弹窗；分组标题可无；常带右箭头 |
| 时间轴 | PAGE-AD-007 | 面包屑 → 时间轴（左竖轨右图文） | 点节点切高亮 |
| 悬浮按钮（套件样例） | PAGE-AD-011 | 面包屑 → 正文；右下角标悬浮钮 | 只右下；独立圆；满 4 个可展开有弹出；功能钮按下有反馈 |

禁止：ASCII 漏掉「贴顶/贴底/左冻/右冻/语义列宽/紧凑」，把这些留给 ⑥ 去猜。

## 开笔前

Read `lny-prd-master/framework-exclusions.md`。不为已排除项生成单页 PRD。Read `main_spec` §1.5「明确不做」（若有）：**禁止**为清单中的能力写单页 PRD。落盘前 **完整 Read [`reference.md`](reference.md)**。

## 职责与禁止

- **负责**：按页生成 `pages_prd`；**项目含 PC 或 AD 时必须**落盘 `pages_prd/_shell/{终端编码}-shell.md`。
- **禁止**：抄 `api/` 字段表；编造未立项 PAGE；把约束说明写入产物；单页罗列壳层换页。仅当 PM 已说出点位才写埋点；**禁止自拟埋点方案**。

## 前置条件

已执行 ①②③；目标 `PAGE-*` 已在 `ui/` 登记。⑧ 委派时以 `ui_changes.md` 的 `pages_prd目标路径` 为准。

## 输入

```yaml
版本号: v1.0.0
页面编号: PAGE-MP-001
页面名称: 首页
接口编号列表: [API-MP-001]
```

未指定版本号时按 master §1.1。

## 执行步骤

1. 校验版本目录与页面编号；有台账则核对目标路径。
2. Read `ui/PAGE-*` + 引用 COMP、`api/API-*`、`feature/`、`main_spec` §1.2（仅作背景）。
3. 按 [`reference.md`](reference.md) 模板落盘；§1 表后写根规格依赖引用块；§3 顶 ASCII 线框默认必填（页型顺序见上方夹具速查）。交互、动效、收纳从 `ui/PAGE-*` **§2.3** 带入，禁止降级成「有个按钮」。桌面 D1-1 须写列宽语义与紧凑密度。
4. 路径：`pages/{m}` → `pages_prd/pages/{m}/`；`subpackages/{m}` → `pages_prd/subpackages/{m}/`；`views/{m}` → `pages_prd/views/{m}/`。
5. 若终端含 PC/AD：按壳模板写 `_shell/{编码}-shell.md`（尚无则创建）。
6. 若改了根四规范：`iteration_notes` 文末追加；否则省略。
7. 提示下一步：**⑥ `/lny-prd-prototype`**。⑦ 须用户明确要求检查，不自动跑。
