# 自动设计决策协议

本协议用于让技能包在没有完整视觉规范时，自动完成页面设计判断，并把必要的实现约束交给原型步骤。它服务于产品原型，不要求用户先提供概念图或完整设计稿。

## 默认原则

- **默认自动决策**：页面任务、信息层级、页面骨架、视觉方向、素材策略和响应式取舍由技能根据已有 PRD、页面规格、组件、品牌事实与终端设计词典自动判断。
- **设计决策优先**：概念图片是可选的探索工具，不是原型前置条件，也不是正式页面来源。
- **HTML 为最终验证对象**：正式原型以浏览器真实渲染的 HTML 为准，整页生图只能作为方向参考，不得替代结构、文字、交互和状态实现。
- **记录默认假设**：技能作出没有上游明文规定、但不改变业务事实的设计判断时，记录假设、依据和可替换点，不因常规视觉选择停下来询问。
- **保持责任边界**：技能可以决定视觉和交互表现，不能自行新增业务目标、字段、权限、接口契约、跳转条件或产品状态。

## 自动决策顺序

1. 读取项目事实、终端、页面类型、上游字段与既有视觉事实。
2. 确定页面首要任务、第二视觉重点和首屏内容边界。
3. 选择匹配的页面骨架，确定固定区、滚动区、分区顺序和内容收纳。
4. 确定色彩语义、层级节奏、组件语言、状态语言和签名元素。
5. 盘点字体、图片、图标、纹理、边框和装饰的来源。
6. 为每个关键视觉元素确定实现路径：项目现有素材、可新增独立素材、CSS、SVG 或可替换占位。
7. 生成 HTML，完成真实渲染检查并修正明显问题。

## 允许询问的情况

仅当以下问题会实质改变页面目标、范围或品牌方向时询问使用者：

### 产品目标冲突

首页或首屏存在多个同等优先的业务目标，且不同选择会产生不同骨架或主操作。

### 品牌事实冲突

已有多套品牌色、字体、图标或视觉规范，无法依据来源和当前页面判断应继承哪一套。

### 关键资产不可替代

最终交付明确要求使用指定 Logo、授权字体、企业图片或既有插画，但当前工作区没有可用来源。

### 不可逆范围变化

需要新增业务入口、删除既有导航、改变页面职责、增加未定义流程或修改上游产品事实。

询问应一次只呈现造成分歧的选项，并说明每个选项对页面结构的影响。常规字体层级、间距、边框、阴影、按钮主次、装饰收纳和素材替代不询问。

## 概念图的使用边界

- 视觉方向不明确且页面需要品牌探索时，可生成一至两张方向参考图，再把结论写入设计决策。
- 页面需要主视觉、插画、纹理、建筑或场景素材时，可生成独立图片资产。
- 页面结构、文字、表单、列表、工作台、多页面流程和状态演示默认直接生成 HTML。
- 不把整页生图作为正式设计稿，不把生图中的字体、文字、间距和装饰自动视为可交付资产。
