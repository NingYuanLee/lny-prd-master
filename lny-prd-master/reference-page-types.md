# 页型职责与跨步骤不变量

② UI、⑤ Page、⑥ Prototype 在处理页面前均 Read 本文件。这里是页型名称、编号映射和跨步骤不变量的单一事实源；各技能自己的速查表只维护该步骤专属规则。

## 三步职责

| 步骤 | 事实来源 | 用途 | 禁止 |
|------|----------|------|------|
| ② UI | 业务目标、默认体验规范、共享页型 | 决定 L/D 结构、视觉层级、交互与 §2.3 | 写实现类名；把样例形态当业务需求 |
| ⑤ Page | `ui/PAGE` §2.3、API、Feature | 用 ASCII 表达分区顺序并形成单页 PRD | 把 ASCII 当视觉稿；让 ⑥ 画空盒子 |
| ⑥ Prototype | `pages_prd`、`ui/PAGE` §2.3、项目既有视觉事实 | 按规格实现页面，满足 ②⑤ 的结构与交互契约 | 编造规格；整页搬入规格外功能 |

ASCII 只定分区顺序；业务功能始终以规格为准。页面视觉以**项目自身事实**为准（PRD 正文、`ui/` 规格、项目既有设计稿/品牌 CSS/真实素材）；没有这些事实时按 PRD 自行设计。

## 跨步骤不变量

下列规则 ID 是 ②⑤⑥⑦ 的单一事实源。各技能只补本步骤的规格措辞或 ASCII，不得复制后另改阈值。

| ID | 规则 |
|----|------|
| `PT-MOBILE-LIST` | 搜索、筛选和页签固定在列表滚动区外；字段多或值长用横卡多行，字段不多但值长时字号略大且高度随内容；仅字段 ≤3 且值都短时可用横卡单行。多行卡文本靠左，价格/距离在右上，单操作在右下、多操作在底栏靠右；单行每条独立留缝。列表不是分组设置项，分页不制造页边界视觉。**触屏列表卡高度随内容**，禁止给卡片或卡片内容区设固定最小高度（左图/图标位仍固定尺寸）。**横卡列表**属本子型。**不分页分组字段**（MP-012，多条记录按组）与桌面 D1-1 第三型同页型，亦属列表族，禁止套用本子型搜索筛选与横卡。 |
| `PT-MOBILE-FUNC` | 触屏**功能入口**形态选型（**不限首页**；② 点名、⑤ ASCII 标形态、⑥ 实现对应形态）。**宫格**：入口 **≥5**，或只需图标+极短标签（≤4 字）、强调一行扫视；列数 **4 或 5**，与个数对齐（5 个→5 列，4 个且仅极短标签→4 列）。**双卡**：须**标题+说明**，或滚动区**仅有成组入口、无列表**、需填实视口/做模式教育；通常 2～4 项、一排两张。**宫格+双卡**：多种入口层级并存时使用。**通栏** / **一行两个**：2～4 个轻入口、接近设置/服务页气质；信息少（图标+短标题）→ 一行两个；菜单式逐项→通栏。**禁止**：仅因「是首页」默认宫格；仅因「有 4 个入口」机械 4 列宫格（4 个且要说明→双卡 2×2 或一行两个×2）。**规格砍掉列表区时**：须回退改功能区形态（倾向双卡或宫格+双卡），勿留稀疏单列宫格空荡页。 |
| `PT-GROUP-FIELDS` | **列表族 · 无分页 · 多条记录按组（字段列表）**：只读字段名+字段值；组间浅线左右内缩、不贴边，不在字段之间再画分割线。触屏 MP-012 与桌面 D1-1 **不分页分组字段** / AD-012 同属本页型。与 MP-003 图文详情、MP-002 横卡列表、可编辑表单分离。详情页内单组字段排版仅作参考，**不是** MP-012 页型。 |
| `PT-DESKTOP-LIST` | 顶部只保留面包屑。先点名六型之一：**分页标准列表**（筛+功能+表+汇总分页）、**分页树形列表**（表内父子嵌套行+分页；子行缩进，展开收起用 +/−）、**不分页分组字段展示**（多条记录按组堆叠字段名+值，无分页；记录间浅线左右内缩、不贴边，不要每字段再画分割线）、**不分页树形展示**（只读可展开，无增删改）、**分页无图卡片列表**、**分页有图卡片列表**（卡片栅格 + 底栏统计分页；同一行卡片等高，放不下换行；无图卡右上角或表列可放开关；卡右下角可放操作钮）。列表页顶部是筛区与功能栏，**不是**返回标题栏；筛区/功能栏按本页规格另加，不照抄别页。工作台嵌入短表仍可只用表格、无完整筛功能条。分页型：勾选列左冻、操作列右冻；操作列宽按直出按钮**形态与数量**收紧（图标 1/2/3 档；文字钮按文案加宽），表头与单元格同宽，禁止挤没导致右冻失效。常规操作：≤2 全直出禁「更多」；≥3 直出 1～2 其余进「更多」。列宽按字段语义；长值省略且不得溢出叠邻列；同一单元格多字段用多行栈且行高够、禁止上下叠字。紧凑密度；汇总左、分页右贴底。 |
| `PT-DESKTOP-LAYOUT` | 内容区默认 **标准通栏**（一块内容铺满，不再切开）。有规格时再点名均分双列 / **左定右填** / **左填右定** / 三列 / 品字形（上通栏+下左右等）。品字顶条不是整页通栏。**禁止**把 D1-2 表单「窄双列栅格」错套成页面左右布局。表单双列只用于字段并排。 |
| `PT-STATE-FLOW` | 页内签、数字步骤、分段进步条、无极进度条同属「状态导览」：用当前状态控制展示哪块内容。签切并列面板。**有序向导**须 **三选一**（数字步骤 / 分段进步 / 无极进度），禁止同页叠加。**仅数字步骤可点跳步**；分段进步条、无极进度条在向导中**只展示**、不可点击切换，步进靠上一步/下一步。禁止用无极冒充分段，或把签写成与进步条无关的两套故事。**步骤向导语义 checklist**见下文「步骤向导语义」。 |
| `PT-LOCATOR` | 分类按钮、章节大纲（及详情目录）同属定位导航：可点时滚到锚点。**滚动内容区时大纲当前章高亮联动**。章节大纲两种：① 左侧占栏可收缩；② 右侧悬浮可收起。详情右下「目录」同属本族。与树分离。触屏 **MP-013 分类导航**（左一级分组 + 右分组横卡）亦属本族；**不是** MP-008 多级树。触屏另增 **父子章节列表**（父章 + 缩进子章垂直列表，**父章可展开/收起**；可跳转/滚锚点；**不是**维护树、**不是**横卡；MP-015）。左栏大纲子项按二级层级展示（对标桌面 outline）。桌面时间轴不是本族分栏，与触屏同为竖轨右**横卡文本**（无左图，正文可内嵌多小图）。 |
| `PT-DESKTOP-TREE` | 树分两种：① 不分页左树右内容；② 分页列表内父子嵌套行。触屏 **MP-008 分类树**为左多级树右**图文介绍**（点节点换右区，不滚动联动）；桌面 AD-005 为维护树+右区列表。不分页树默认带维护交互：总控全部展开/收起与新增根节点；节点可增子、重命名、删除；拖到节点**上**=同级紧前、**中**=成为其最后一个子节点、**下**=同级紧后。末级可否增子由规格决定。只读树须显式声明为只读，不得提供节点增删改。禁止用分类定位冒充树。 |
| `PT-FLOAT` | 仅规格点名时加入。触屏钉在页框：左上横向且与标题栏互斥，左下/右下竖向并避开底栏，禁止右上；单个为圆钮，多个为带分隔的组。桌面只在右下：多个独立圆钮竖排，满 4 个收成一颗可展开按钮并错开弹出，按下有反馈，禁止合成触屏式细线胶囊。 |
| `PT-DENSITY` | 默认态的明确列表、宫格、时间轴和 D1-1 数据表至少 4 条，除非规格或 API 明确给出更小数量。详情附属区、摘要短表、字段列表和其它非列表重复块不套用 4 条门槛。 |

## 树 vs 章节列表选型

**单一事实源**：②⑤⑥ 遇到「可展开层级列表」时必须先按本表分流，**禁止**用树画章节目录，**禁止**用父子章节列表画分类/组织树。

| 维度 | 树（层级数据） | 父子章节列表（章/节导航） |
|------|-----------------|-----------------------------------|
| **业务语义** | 层级**数据**的浏览或维护：商品分类、组织/权限、表内嵌套 | **章/节/大纲**导航：课程目录、帮助文档目录、阅读跳转 |
| **页型 ID** | `PT-DESKTOP-TREE`；触屏 **MP-008**；桌面 **AD-005** | `PT-LOCATOR` 触屏专形；**MP-015** |
| **典型布局** | **分栏**：左树 + 右内容/表单/图文介绍 | **整页垂直列表**（或模块内一块列表）；无左右分栏 |
| **层级深度** | **任意多级** | **固定两级**：父章 + 子章 |
| **展开控件** | 每节点一个展开/收起控件；维护树另有全部展开/收起的总控 | 每组父章行可**展开/收起该组子章** |
| **点父/节点后** | **换右区**内容（介绍、表单、列表）；**不**滚正文联动 | **跳转或滚锚点**到正文章节；可高亮当前章 |
| **维护能力** | 可增子/重命名/删除/拖拽（维护树）；只读树仅展示 | **只读导航**；无节点增删改 |

**三步决策（按顺序问）**

1. **是不是章/节/大纲，且要点进去读？** → 触屏用**整页父子章节列表**；桌面用**大纲**（左占栏或右悬浮，AD-013），**不是**树。
2. **是不是分类/组织/权限等层级数据，点节点换右区或要维护？** → 用**树**（分栏左树，或表内父子嵌套行），**不是**父子章节列表。
3. **是不是左一级分组 + 右横卡 + 滚正文联动？** → 用**分类定位导航**（MP-013），**既不是树也不是父子章节列表**。

**常见误套（禁止）**

| 错误 | 正确 |
|------|------|
| 课程目录页画成分栏左树右正文 | 触屏父子章节列表整页展示 |
| 商品分类维护画成父子章节列表 | 桌面左树 + 右区表单的分栏结构 |
| 章节目录画成左树右正文分栏 | 章节列表整页，或桌面大纲 |
| 分类导航（左分组右横卡）用树或章节列表 | 分类定位导航 + 分栏（MP-013） |

## 步骤向导语义（②⑤⑥ checklist）

凡业务页具备 **步骤向导 / 有序分步 / 多步提交** 语义（**不限** MP-005 / AD-003 编号）：

| 步骤 | 强制 |
|------|------|
| ② `ui/PAGE` | **步骤区**（PAGE 模板，`PT-STATE-FLOW` 有序向导必填）须 **逐字点名三选一之一**：数字步骤 | 分段进步 | 无极进度（桌面 AD 二选一：数字步骤 | 分段进步）；写 **共 N 步**。L3 **只写所选一种**控件。**禁止**「步骤条+进步条」「分段+无极」等组合措辞 |
| ⑤ `pages_prd` | ASCII **只画一种**导览；禁止并列多种进度条/步骤条 |
| ⑥ `prototypes` | 同页 **只允许一种**导览形态（数字步骤 / 分段进步 / 无极进度），不得叠加；**禁止**把与本页规格无关的导览对照结构搬进业务页。`verify-prototype-coverage.py` 自动拦截叠加 |
