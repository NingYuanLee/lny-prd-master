# 页型职责与金样映射

② UI、⑤ Page、⑥ Prototype 在处理页面前均 Read 本文件。这里是页型名称、编号映射和步骤边界的单一事实源；各技能自己的速查表只维护该步骤专属规则。

## 三步职责

| 步骤 | 事实来源 | 用途 | 禁止 |
|------|----------|------|------|
| ② UI | 业务目标、默认体验规范、共享页型 | 决定 L/D 结构、视觉层级、交互与 §2.3 | 写 `md-*` 类名；把金样功能当业务需求 |
| ⑤ Page | `ui/PAGE` §2.3、API、Feature | 用 ASCII 表达分区顺序并形成单页 PRD | 把 ASCII 当视觉稿；让 ⑥ 画空盒子 |
| ⑥ Prototype | `pages_prd`、`ui/PAGE` §2.3、对应金样 | 以套件类名达到视觉密度下限 | 按编号猜金样；整页搬入规格外功能 |

ASCII 只定分区顺序；金样只定视觉密度与套件用法；业务功能始终以规格为准。

## 金样 · 套件 · 夹具

编号与金样文件以本表为准；②⑤⑥ 速查表只补本步措辞，不得另写一套映射。

| 层 | 位置 | 职责 | 禁止误读 |
|----|------|------|----------|
| 金样 | `lny-prd-prototype/gold/` | 视觉下限与形态目录（密度、类名、控件骨架） | 不是业务功能清单；列表金样**只对标列表区** |
| 套件 | `lny-prd-prototype/kit/` | `md-*` 类名与脚本实现 | ② 规格不写类名；不要另起皮肤 |
| 夹具 | 项目 `prototypes/{终端}/PAGE-*.html` | 下表「回归标识」对应页面，用来对照金样是否画得出来 | 不是业务项目模板。套件样例夹具可整页对标金样；业务夹具按规格裁（如 AD-001 含筛+功能栏） |

## 金样边界

MP-004、MP-007、MP-011、MP-012、AD-003～AD-007、AD-009～AD-014 是套件/形态样例，不是每个业务项目的必有页面。业务表单按规格裁字段；悬浮胶囊或按钮仅在规格点名时加入业务页。列表页顶部是搜索与筛选工具条，不是返回标题栏。夹具 `PAGE-AD-001` 是**分页标准列表**且含筛+功能栏；六型总览与树表/卡片只在金样 `desktop-lists.html`（只对标列表区）。桌面字段详情金样在 `desktop-detail.html` 字段签，夹具可单独一页 `PAGE-AD-012`。表内嵌套无独立夹具 PAGE，见 `desktop-lists.html` 第二签（分页树形列表）。状态导览合览无独立夹具 PAGE，见 `PAGE-AD-003` 与 `desktop-state-flow.html`。

## 跨步骤不变量

下列规则 ID 是 ②⑤⑥⑦ 的单一事实源。各技能只补本步骤的规格措辞、ASCII 或套件类名，不得复制后另改阈值。

| ID | 规则 |
|----|------|
| `PT-MOBILE-LIST` | 搜索、筛选和页签固定在列表滚动区外；字段多或值长用横卡多行，字段不多但值长时字号略大且高度随内容；仅字段 ≤3 且值都短时可用横卡单行。多行卡文本靠左，价格/距离在右上，单操作在右下、多操作在底栏靠右；单行每条独立留缝。列表不是分组设置项，分页不制造页边界视觉。**横卡列表**属本子型。**不分页分组字段**（MP-012 / `mobile-fields` / `md-group-list`，**多条记录**按组、sheet safe）亦属列表族，与桌面 D1-1 第三型同页型，禁止套用本子型搜索筛选与横卡。 |
| `PT-GROUP-FIELDS` | **列表族 · 无分页 · 多条记录按组**：只读字段名+字段值；触屏 MP-012 / `mobile-fields`（`md-group-list` + **sheet safe**）；桌面 D1-1 **不分页分组字段** / `desktop-lists` 第三签 / `PAGE-AD-012`。与 MP-003 图文详情、MP-002 横卡列表、可编辑表单分离。`desktop-detail` 字段签仅作单组 `md-desc` 排版参考，**不是** MP-012 页型。 |
| `PT-DESKTOP-LIST` | 顶部只保留面包屑。先点名六型之一：**分页标准列表**（筛+功能+表+汇总分页）、**分页树形列表**（表内父子嵌套行+分页；子行缩进，展开收起用 +/−）、**不分页分组字段展示**（多条记录按组堆叠字段名+值，无分页；记录间浅线左右内缩、不贴边，不要每字段再画分割线）、**不分页树形展示**（只读可展开，无增删改）、**分页无图卡片列表**、**分页有图卡片列表**（卡片栅格 + 底栏统计分页；同一行卡片等高，放不下换行；无图卡右上角或表列 `md-col-switch` 可放开关；卡右下角可放操作钮）。金样合一 `desktop-lists.html`，**只对标列表区**；筛区/功能栏按规格另加，不要从金样抄成业务页不要筛。工作台嵌入短表仍可只用表格、无完整筛功能条。分页型：勾选列左冻、操作列右冻；操作列宽按直出按钮**形态与数量**收紧（图标 1/2/3 档；文字钮按文案加宽），表头与单元格同宽，禁止挤没导致右冻失效。常规操作：≤2 全直出禁「更多」；≥3 直出 1～2 其余进「更多」。列宽按字段语义；长值省略且不得溢出叠邻列；同一单元格多字段用多行栈且行高够、禁止上下叠字。紧凑密度；汇总左、分页右贴底。 |
| `PT-DESKTOP-LAYOUT` | 内容区默认 **标准通栏**（一块内容铺满，不再切开）。有规格时再点名均分双列 / **左定右填** / **左填右定** / 三列 / 品字形（上通栏+下左右等）。品字顶条不是整页通栏。**禁止**把 D1-2 表单「窄双列栅格」错套成页面左右布局。表单双列只用于字段并排。 |
| `PT-STATE-FLOW` | 页内签、数字步骤、分段进步条、无极进度条同属「状态导览」：用当前状态控制展示哪块内容。签切并列面板；步骤/进步条服务有序向导；进度条服务连续百分比。禁止用无极冒充分段，或把签写成与进步条无关的两套故事。 |
| `PT-LOCATOR` | 分类按钮、章节大纲（及详情目录）同属定位导航：可点时滚到锚点。**滚动内容区时大纲当前章高亮联动**。章节大纲两种：① 左侧占栏可收缩；② 右侧悬浮可收起。详情右下「目录」同属本族。与树分离。桌面时间轴不是本族分栏，与触屏同为竖轨右**横卡文本**（无左图，正文可内嵌多小图）。 |
| `PT-DESKTOP-TREE` | 树分两种：① 不分页左树右内容；② 分页列表内父子嵌套行。不分页树默认带维护交互：总控全部展开/收起与新增根节点；节点可增子、重命名、删除；拖到节点**上**=同级紧前、**中**=成为其最后一个子节点、**下**=同级紧后。末级可否增子由规格决定（`data-leaf` / `data-leaf-add=off`）。只读树写 `data-tree-edit=off`。禁止用分类定位冒充树。 |
| `PT-FLOAT` | 仅规格点名时加入。触屏钉在页框：左上横向且与标题栏互斥，左下/右下竖向并避开底栏，禁止右上；单个为圆钮，多个为带分隔的组。桌面只在右下：多个独立圆钮竖排，满 4 个收成一颗可展开按钮并错开弹出，按下有反馈，禁止合成触屏式细线胶囊。 |
| `PT-DENSITY` | 默认态的明确列表、宫格、时间轴和 D1-1 数据表至少 4 条，除非规格或 API 明确给出更小数量。详情附属区、摘要短表、字段详情和其它非列表重复块不套用 4 条门槛。 |
