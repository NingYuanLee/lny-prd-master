# Q-P 原型门禁

只检查原型页面覆盖、结构对照、跳转、状态、资源、浏览器行为和真实渲染质量。Q-P 不重新审查 API 或 Feature 语义，也不替产品决定品牌偏好。

## 视觉实现门槛

- PAGE 已提供页面任务、视觉锚点、素材策略和响应式取舍，或由原型步骤按自动设计决策协议补齐并记录。
- 关键视觉元素有项目资产、独立素材、CSS、SVG 或可替换占位的实现路径。
- `render-prototype.mjs` 能在宿主依赖可用时保留目标页截图。
- `score-visual-quality.mjs` 输出整体分数和逐页问题。整体达到 80 分且单页不低于 70 分，才视为通过视觉实现门槛。
- 评分脚本 exit 2 只表示宿主缺少依赖，必须披露未执行，不得伪报视觉通过。
