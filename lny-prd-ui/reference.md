## 1. 阅读说明与清单结构约定

> **导读**：本文件仅维护 §2～§4 索引与 §5 全局说明。页面/组件详述落在 `ui/PAGE-*.md`、`ui/COMP-*.md`，禁止在本文件重复正文。详规见 `lny-prd-ui/SKILL.md`。

### 1.1 操控形态定义（全文区分基准）

| 形态 | 判定依据 | 典型终端（以项目 `main_spec` → 第4章终端说明 为准） |
|------|----------|------------------------------------------|
| **移动端** | 以 **手指触控** 为主完成主要交互 | 小程序、App、触屏 H5 等 |
| **桌面端** | 以 **鼠标指针**（及键盘辅助）为主完成主要交互 | PC 网页、管理后台 Web 等 |

### 1.2 视觉描述规则（两端适用）

**自底至顶（层级优先）** → **自上而下（同层多模块）** → **自左至右（左右布局优先）** → **自外至内（父子结构由内向外展开）**。

分页面须在以上顺序之上，按操控形态分别落实 **§1.3**（移动）或 **§1.4**（桌面），不得以本条替代 **§1.3 / §1.4** 的结构约定。

### 1.3 移动端：层级与布局

#### 1.3.1 层级一览表（L0～L5）

| 序号 | 层级名称 | 简要描述 |
|------|----------|----------|
| L0 | 系统层 | 真机预览状态栏（固定顶演示，不随滚）；安全区（正文左右下+四角；标准顶栏左右贴边，不预留胶囊空）；系统手势、壳层 TabBar 等 |
| L1 | 固定导航层 | 页内顶栏、业务固定顶/底栏等 |
| L2 | **主体内容层** | 可选 **【下沉首屏】**（钉底不滚）+ **【滚动容器】**（统一基础内边距 + 统一基础背景色；内装 L3 模块） |
| L3 | 模块容器层 | 卡片、分区、列表、表单块；含 **普通模块**（随滚）与 **吸顶模块**（滚过某点后 sticky 贴顶） |
| L4 | 内容元素层 | 标题、文案、按钮、图、输入、标签 |
| L5 | 浮层与反馈层 | 弹窗、抽屉、Toast、遮罩、加载态 |

#### 1.3.2 布局偏好（书写要点）

- 优先采用 **自动弹性容器布局**（如弹性盒、自适应流式/栅格），避免过多写死像素分区。
- 与 **`L0`～`L5`** 叙述一致。
- **触屏硬规则**见 **§1.3.3**：必须写进 `ui/PAGE-*.md` 的 L0/L1/L5，禁止留给 ⑥ 去猜。

#### 1.3.3 触屏端体验硬规则（MP / H5 / APP 必守）

写移动端 `ui/PAGE-*` 时按本表落盘。⑥ 只负责用套件类名实现，**不得**在规格未写时自行发明，也**不得**因规格漏写而画成带顶栏的线框页。

| # | 规则 | 规格怎么写 | 禁止 |
|---|------|------------|------|
| 1 | **底栏固定** | 壳层 TabBar、页内主操作条（提交/购买/下一步）写在 **L1**，并写明「贴底固定、不随 L2 滚动」；有 Home Indicator 时底栏计入安全区 | 底栏画在滚动内容末尾、滑走消失 |
| 2 | **有 TabBar 则无页内顶栏** | L0 写 TabBar；L1 写 **「无页内顶栏」**。Tab 文案即当前页身份。仅 **无 TabBar 的二级页** 才写返回顶栏 | TabBar 页再写「顶栏标题「首页」」；顶栏+底栏重复显示同一页名 |
| 3 | **小程序胶囊避让** | L0 写明：沉浸式/封面顶栏上的可点按钮、搜索、更多 **不要顶到右上胶囊**。标准返回标题栏 **左右贴边**，不要为胶囊空出一整截。原生状态栏电量/信号 **靠右**，不要为胶囊把它们往里挤 | 标准顶栏右侧留出 96 空白；自定义顶栏汉堡/搜索/分享顶到胶囊上；把状态栏信号留出一大块空白 |
| 4 | **列表区 / 功能区点名** | 列表卡选择与字段/操作布局直接引用共享 `PT-MOBILE-LIST`；本页另点名封面叠字 / 双列瓷砖 / 横卡及图片比例，卡统一轻阴影。**功能区**形态选型直接引用共享 **`PT-MOBILE-FUNC`**（宫格 / 双卡 / 通栏 / 一行两个 / 宫格+双卡；成组、每组入口有限；分组标题可无）；功能区与页内签不要圆角阴影卡片壳 | 列表当入口、入口当商品卡；同一模块混多种不说明；未引用 `PT-MOBILE-LIST` / `PT-MOBILE-FUNC`；功能区/页内签套卡片圆角阴影；列表卡无阴影；仅因首页或 4 个入口机械选宫格 |
| 5 | **首屏背景/slogan 下沉** | 需要 Banner/背景 **钉底、白底滚过盖住** 时：L2 写 **【下沉首屏】**（背景图 / slogan / Banner / Hero），并配 L0 **沉浸式**（状态栏透明叠在图上）。**不要**把下沉写进 L3「第一个普通模块」——下沉是 L2 可选子层，不是模块类型 | 先实心状态栏再 Banner；把下沉 Banner 写成 L3 普通模块跟内容一起滚；或 Hero 与滚动容器 DOM 层级写反 |
| 6 | **常用浮层与动效** | 规格出现则必须点名形态：Banner 轮播、金刚区、左/底/右半屏、确认框、Toast；并写「显隐 **过渡** 而非瞬切」 | 用「弹出一层」含糊带过；不写方向（左/底/右） |
| 7 | **触控反馈** | L4 写可点元素「无默认下划线；按下有反馈；热区 ≥44px」 | 依赖 hover 当唯一反馈；链接带下划线当按钮 |
| 8 | **圆角 / 曲面屏安全距** | L0 写明：正文左右下及四角留安全距；标准顶栏左右贴边；可点控件、主文案、Tab、半屏把手 **不贴物理圆角/曲面**；**状态栏本身不套安全距**；装饰图可铺满但内容落在安全区内 | 按钮/文字顶到屏幕圆角；标准顶栏再叠一层 16 左右空 |
| 9 | **顶栏模式：沉浸式 / 标准** | L0 **必写其一**：**沉浸式**（状态栏背景透明，内容从屏幕顶铺起）或 **标准**（状态栏背景不透明，内容从状态栏下开始）。**沉浸式 ≠ 一定下沉**：仅 **L2【下沉首屏】** 才写滚过盖住；沉浸式也可只有 overlay 顶栏叠 16:9 主图（详情 L3），或 Banner 在 **L3 普通模块**里随滚 | 把「沉浸式」一律当成下沉滚过；标准页把内容顶到状态栏后面 |
| 10 | **触屏输入独立成行** | 每个输入/开关/选项组单独一行，组与组之间留空防误触；禁止两列并排输入；**输入框左右不贴屏，右侧须有安全距** | 触屏表单两列挤在一起；输入右边框贴死屏幕 |
| 11 | **表单单选/多选＝标签** | 表单、筛选里的选项写成 **标签**；选中时右上角 **对号角标**，未选中无角标 | 表单里用桌面那种左侧小圆圈/小方块当选项 |
| 12 | **列表单选/多选＝左侧圆/方** | 列表行、表格行仍用左侧圆圈（单选）/ 方块（多选） | 列表行做成标签角标 |
| 13 | **列表搜索行 + 筛选行贴顶** | 列表页 L1 写「搜索框行」与「筛选行」**贴顶固定、不随 L2【滚动容器】滚**（在 `md-mobile-body` **外**、与滚动区并列）。L2 只滚卡片。本页确无搜索或筛选须写明「无搜索」/「无筛选」。**勿与 L3 吸顶模块混淆**：吸顶在滚动容器**内**，滚过某段后才 sticky | 搜索、筛选跟列表一起滑走；把本属 L1 的工具条写成 L3 吸顶 |
| 14 | **展示类（详情/内容）** | 无 TabBar 的二级页：L1 返回（避让胶囊）；主内容只读。**图文详情**（MP-003）：首屏大图 immersive，正文模块+可选评论 | 展示页做成可编辑表单；把字段列表 MP-012 硬套 flush 浅灰壳或 MP-002 横卡 |
| 15 | **表单类** | 无 TabBar；L1 返回+标题；**页根 `md-form-page`**：浅灰底 `#f7f7f7`，字段按区分组进白底 `md-module`（有内边距，组间露灰）；输入独立成行且右侧留安全距；选项用标签角标；规格出现的滑动条/底半屏三级选择/上传须点名形态；**主操作条贴底固定**提交 | 整页白底无分组；提交按钮埋在滚动末尾；两列输入；输入贴右边；触屏用原生日期框 |
| 16 | **非列表图片默认 16:9** | 详情/内容页的主图、介绍配图等 **非列表卡片** 图片写「**16:9**」。列表卡走规则 4 的形态。评论附图等缩略图默认 **1:1**、约 **40px**，不要按正文宽五等分 | 详情主图、正文配图套用列表横卡 |

**补全（与上表一并执行）**：

- **二级页返回**：无 TabBar 时 L1 才写左侧返回。标准标题栏左右贴边；仅沉浸式/封面顶栏上的右侧可点按钮才避让胶囊。
- **主操作条 vs TabBar**：有 TabBar 时不要再叠一条「返回+标题」；无 TabBar 的展示次要操作、表单提交用贴底 `主操作条`。
- **悬浮胶囊 / 悬浮按钮**：规格点名才写，位置、成组、折叠阈值与反馈直接引用共享 `PT-FLOAT`；本层只补功能、避让对象和状态，不复制规则正文。
- **列表工具条**：搜索框单独一行，筛选（含打开半屏的「筛选」）单独一行，二者都在 L1，不进滚动区。触屏搜索框 **仅左侧搜索图标 + 输入占位**，不要框内「搜索」文案，不要右侧搜索按钮（回车提交即可）。
- **列表区**：同一模块只选一种（分区可各自点名），卡型选择、字段层级和操作位置遵守共享 `PT-MOBILE-LIST`。本层另定图片：封面叠字为大图+单行标题悬底；双列上图与标题最多两行；横卡多行左侧可为封面/图标/头像/无，图片只允许 1:1 或竖图且可附最多五张 1:1 小图；状态标签贴封面角。所有列表卡统一轻阴影；**高度随内容**，禁止卡片/`__body` `min-height`（左图/图标位仍固定尺寸）。
- **功能区**：形态选型见共享 **`PT-MOBILE-FUNC`** 与 **§1.3.6**。**设置与入口同属功能服务外壳**（`md-set-group` 成组通栏，左图标可有可无）。差别在行为：**设置项**在当前页当前行直接操作（开关 / 无极 / 横向勾选 / 本行下拉改值等）；**功能入口**只跳转或打开半屏/弹窗（常带右箭头）。通栏与一行两个的分组标题可有可无。**成组**，每组入口有限。列表单行是内容（独立有缝）。**功能区与页内签：不要圆角阴影卡片壳**（平铺）。触屏功能区 **跟正文同左右安全距**，组内分割线仍左右内缩。**我的 / 设置** 页根加 **`md-set-page`**：浅灰底同详情 `#f7f7f7`，靠组间距漏出背景。**金刚不限首页**——凡要成组入口区的页面都可点名。
- **L2 主体内容层**：分两块写——**【下沉首屏】**（可选；钉底不滚）与 **【滚动容器】**（必选；写分区顺序）。无下沉时只写滚动容器。
- **L2【滚动容器】**：**全页只在这一层**承担滚动区的基础内边距与基础背景色；L3 模块只写块内间距，**不要**每个模块各自叠页级左右 safe 或整页底色（浅灰壳页除外，见 §1.3.4「滚动容器底与边」）。
- **L3 模块**：滚动容器内每个分区包一层模块容器；兄弟间距靠父级 `--md-module-gap`，不要靠各自 margin 拉开。**普通模块**随滚；**吸顶模块**写清吸顶对象（如页内签、二级筛选）与顶距（须避开 L1 固定区高度）。列表搜索/筛选、TabBar、返回顶栏、贴底主操作条属 **L1 固定**，不是 L3 吸顶。
- **Banner 两种形态**：① **下沉式** → L2【下沉首屏】+ L0 沉浸式（行业常说 Hero；规格可写 Banner）。② **随内容滚** → L3 **普通模块**内 `md-swiper` 等，**不要**写下沉、**不要**页级 Hero 钉底。
- **分区「更多」**：查看更多 / 了解更多 / 查看全部 / 了解全部 用 **纯文字链接钮**（无线框、无背景），不要做成色块或线框主按钮。**纯文字型按钮**（`--text` / `--link`）字色必须与紧邻正文区分开（默认主色），禁止跟正文/次要正文同色，否则看不出可点。
- **浅底按钮**：无边框、浅色底 + 有色字，介于色块与文字钮之间。
- **通栏按钮（触屏）**：一行只有一个主按钮时占满整行——内容区加 `md-btn--block`，多个通栏竖叠用 `md-btn-row`；贴底主操作条 / 半屏底栏仅一钮时套件自动占满。多钮横排（如清空+确定）仍并排，不要硬拉满。
- **触屏页内签**：做成一组等宽按钮（未选中浅底色字、选中色块白字）。默认 **L1 固定**（贴搜索/筛选下、在滚动容器外，如列表页）。若规格写 **L3 吸顶模块**，则签在滚动容器内、滚过首段后 sticky——须与 L1 工具条分工，禁止同一签既写 L1 又写吸顶。
- **功能区 · 形态决策**：完整表见 **§1.3.6**；共享 **`PT-MOBILE-FUNC`**。宫格文字不超过四字；双卡须标题+说明；禁止图标单独成色块；点击写清跳转或开哪一侧半屏。
- **Banner**：有指示点；自动轮播；点击若无详情页则写「无出页」。首页/运营 Banner 默认 **2:1**（与套件 `md-swiper` 一致），不要写成列表卡。
- **半屏**：左/右为侧滑（宽约 80%）；**底面板高度随内容，最大约 70% 页高**，超出正文区滚动、内容少则不高撑；须有遮罩，点遮罩关闭；**关闭钮在底面板右上角**；**底半屏选项每项独占一行**（勿标签换行）。
- **弹窗**：须有 **半透明黑色遮罩**（`md-backdrop`，盖住整页）**拦截穿透点击**；**面板主体**白底、**统一圆角**（`--md-radius-dialog`）与 **统一阴影**（`--md-shadow-dialog`，与 `md-dialog` / 中间选项弹窗同 elevation）；禁止直角无阴影面板或页内自写阴影。
- **确认 vs Toast**：破坏性操作（清空/删除）用确认框；轻反馈（已筛选/已复制）用 Toast。
- **触屏 Toast**：屏幕中央；半透明黑底圆角；白图标 + 白字。禁止贴底长条、禁止彩色实心底。
- **带图标方形按钮**：图标与文字上下排在 **同一背景容器** 内，容器留安全内边距；禁止图标单独一块底、文字露在容器外。
- **触屏输入**：每个输入控件独立成行，上下留空防误触；输入框右侧留安全距，不贴屏边。
- **触屏单选/多选**：表单、筛选用标签（选中右上对号角标）；列表行仍用左侧圆圈/方块。
- **触屏滑动条**：五档位离散须有档位列与当前档高亮；无极连续须显示当前值。
- **触屏下拉**：选项少（≤6）中间弹窗，选项多底半屏；列表均可上下滚动。禁止系统原生 `select` 面板。
- **触屏日期 / 省市区**：底半屏、三级联动（年-月-日 / 省-市-区），点遮罩关闭、显隐过渡。禁止原生 `type=date`。禁止给省市区加「开始日期 / 结束日期」签。
- **触屏日期段**：底半屏；「开始日期 / 结束日期」两个签，各年-月-日。禁止两个原生日期框硬凑。
- **触屏上传**：单图/视频点选后可预览（点缩略放大）、可更换；多图可添加可删除、缩略默认可点预览；文件上传显示文件名（不进灯箱）。
- **不用 hover 当唯一态**：MP/H5/APP 的选中、按下必须有非 hover 视觉。
- **圆角 / 曲面屏**：正文左右下留边；四角避开圆角半径；标准顶栏左右贴边；**顶部状态栏是固定演示层，不套安全距、不随页滚**。禁止把 Tab、金刚首尾项、半屏贴死在角上。
- **顶栏模式**：每页 L0 点名沉浸式或标准；沉浸式状态栏透明，标准不透明。触屏顶栏四种择一：16:9+slogan（无页内顶栏）；16:9+返回标题；标准高度返回标题；两倍高度封面+标题（勿拉成 16:9）。

落盘口诀：L0 顶栏模式（沉浸式透明 / 标准不透明；**沉浸式≠必下沉**）+ 安全区与胶囊；L1 只放 **页级固定** 底/顶（列表=搜索+筛选；展示/表单=返回；提交贴底）；L2=可选【下沉首屏】+【滚动容器】；L3=普通/吸顶模块 + 列表区/功能区点名；L5 半屏方向与过渡。

#### 1.3.4 移动端 L2 / L3 结构（必读）

**L0 两个概念不要混**

| 概念 | 写什么 | 典型 |
|------|--------|------|
| **沉浸式** | L0：状态栏透明，内容可从屏幕顶铺起 | 首页 Banner 区、详情 overlay 顶栏叠 16:9 主图 |
| **下沉滚过** | L2【下沉首屏】+ L0 沉浸式：首屏视觉 **钉底**，白底 **滚动容器** 从上层盖住 | TabBar 首页运营 Banner（`PAGE-MP-001`） |

用户只说「沉浸式」时 **不必追问**：按页型模板落 L0；是否下沉看本页要不要滚过盖住 Banner。

**L2 主体内容层（两块，第二块必有）**

| 子层 | 何时写 | 规格语义 | ⑥ DOM（摘要） |
|------|--------|----------|----------------|
| **【下沉首屏】** | 可选 | 背景 / slogan / Banner / Hero **不随滚**；白底内容滚过盖住 | 页根 `md-immersive` 下 **并列** `md-hero` ∥ `md-mobile-body`；body 内 **必须** `md-mobile-sheet`。见 `gold/mobile-grid.html` |
| **【滚动容器】** | 必有 | 主内容分区顺序；L3 模块都在此内 | `md-mobile-body` > **`md-mobile-sheet`** > L3 模块（**禁止** body 直放 module） |

**何时有 `md-mobile-sheet`、何时没有**

| 判定 | 有没有 sheet | 说明 |
|------|-------------|------|
| **有 `md-mobile-body` 且要滚 L3 内容** | **必须有**（body 下 **唯一** 直接子层） | 列表/表单/详情/首页/树/按钮样例等 **全部**如此；sheet 承担浅灰底 + 统一内边距 |
| **L1 固定区**（顶栏/搜索筛选/TabBar/贴底操作条） | **没有** | 与 `md-mobile-body` **并列**，在 body **外** |
| **L2【下沉首屏】**（`md-hero`） | **没有** | 与 `md-mobile-body` **并列**在页根下；Hero **不进** sheet |
| **L5 浮层**（半屏/弹窗/Toast） | **没有** | 挂在页根或 `body`，不进滚动 sheet |
| **无滚动主内容**（纯壳/占位，极少见） | 可没有 body | 正常业务页 **不存在**此情形 |

**sheet 不是「可选装饰」**：v2.8.44 起 `md-mobile-body` 默认 **透明、无 padding**；**没有 sheet 就没有**滚动区浅灰底与统一 safe——**新页/金样/⑥ 禁止** `body` 直放 `md-module` / `md-tab-panels`。

**sheet 形态**（都有 sheet，差别在修饰类）：

| 形态 | 类名 | 左右 safe | 典型页 |
|------|------|-----------|--------|
| 默认 | `md-mobile-sheet` | ✅ 有 | 列表 002、按钮、时间轴、下沉首页 |
| 贴边 | `md-mobile-sheet--flush-x` 或页根 `md-detail-page` / `md-form-page` / `md-set-page` | ❌ 无 | 图文详情/表单/设置/树；白块在 `md-module` 块内 safe |
| 详情壳 | 上表 + `md-detail-content` | ❌ 无（语义别名） | `mobile-detail` / `mobile-fields` |

**Banner / Hero 放哪**

| 形态 | L2/L3 怎么写 | ⑥ 要点 |
|------|--------------|--------|
| **下沉式** | L2【下沉首屏】写 Banner/Hero；L0 沉浸式 | 页级 **`md-hero`** 与 **`md-mobile-body` 同级**，勿塞进 sheet 当第一个 module |
| **随内容滚** | L3 **普通模块** 写 Banner 轮播；**不写**下沉 | Banner 在 **`md-mobile-sheet` / body 内的 `md-module`**，`md-swiper` 等；**禁止**页级 `md-hero` |

**L1 固定 vs L2 下沉 vs L3 吸顶**

| 类型 | 相对滚动容器 | 规格层 | 例子 |
|------|--------------|--------|------|
| **L1 页级固定** | **在滚动容器外**（兄弟节点） | L1 | 列表 `md-list-toolbar`（搜索+筛选）；返回顶栏；TabBar；贴底提交条 |
| **L2 下沉首屏** | **钉在页底图位、不参与 sheet 滚动** | L2【下沉首屏】 | 首页运营 Banner（`md-hero`） |
| **L3 普通模块** | **在滚动容器内，全程随滚** | L3 | 金刚区、列表卡分区、随滚 Banner |
| **L3 吸顶模块** | **在滚动容器内，滚过锚点后 sticky** | L3（点名吸顶） | 详情内二级 Tab、长页章节签（须写顶距） |

判定：**一出滚动容器边界就应始终可见** → L1；**仅首屏钉底、被白底盖住** → L2 下沉；**随滚但滚过某段后要「粘」在视口顶** → L3 吸顶。

**滚动容器：统一底与边（L2【滚动容器】硬规则）**

滚动区 **只认一个**「基础内边距 + 基础背景色」承担层；L3 模块只管块内 content padding，**禁止**各模块自行决定页级左右 safe 或整页底色（除非规格点名浅灰壳页型）。

| 页型 / 场景 | 承担层（DOM） | 基础背景色 | 基础内边距（语义） | L3 模块 |
|-------------|---------------|------------|-------------------|---------|
| **通用 / 列表 / 无下沉** | `md-mobile-body` > **`md-mobile-sheet`** | 浅灰 `#f7f7f7` | sheet：**上 12、左右 safe 12、下 12+safe**；body **透明无 padding** | 列表卡/模块自带白底 |
| **下沉滚过** | 同上 | 浅灰 sheet | 同上 | Hero 与 body 同级 |
| **贴边浅灰壳**（详情 / 表单 / 设置 / 树） | sheet 加 **`--flush-x`** 或页根类自动 lr0 | 浅灰 | sheet **左右 0**；白 **`md-module` 块内 safe** | 组间 `gap` 露灰 |

**滚动区页型选型（列表型 vs 浅灰壳）**

② 定滚动区形态时，**先判产品族**，再选 sheet 模型；**不要**为了 safe 视觉把浅灰壳页改成横卡列表型，也不要把横卡列表改成通栏白分组。

**第一步：是否「列表族」**

| 产品族 | 用户怎么读 | 典型页 |
|--------|------------|--------|
| **列表族** | 按**行/条**扫数据（可对比、可核对） | 商品列表、**字段列表 MP-012**、时间轴、桌面 D1-1 六型 |
| **内容族** | 按**篇章/模块**读（图、文、介绍） | 图文详情 MP-003 |
| **表单族** | 按**组编辑**输入 | 表单、步骤向导 |
| **设置/入口族** | 当行操作或跳转 | 设置、我的服务 |

**列表族内再分（触屏）**

| 子型 | 分页 | 对象数 | 行形态 | 金样 | 滚动壳（sheet） |
|------|------|--------|--------|------|-----------------|
| **横卡列表** | 可有 | **多条**实体 | 独立横卡、行间露灰 | `mobile-list` | **列表型**（sheet 有 safe） |
| **不分页分组字段（字段列表）** | **无** | **多条**记录 | 组标题 + 记录内字段行；`md-group-list` 白卡浮灰 | `mobile-fields` | **列表型**（sheet 有 safe；= 桌面 lists 第三签） |
| **时间轴** | 无 | 多条事件 | 竖轨 + 横卡文本 | `mobile-timeline` | **列表型**（sheet 有 safe） |

**字段列表 MP-012 = 桌面「不分页分组字段」**（同一页型）：**多条**记录按组堆叠字段名+值，无分页、无搜索筛选；触屏用 `md-group-list` + **sheet safe**（白底组卡浮浅灰，与横卡列表同滚动壳）。**不是** MP-003 图文详情，**不是** MP-002 横卡，**不是**可编辑表单。`desktop-detail` 字段签仅保留作单组 `md-desc` 排版示例，**不得**当作 MP-012 实现。

**第二步：sheet 模型（与上表「滚动壳」列一致）**

| 选型口诀 | 滚动区模型 | sheet 左右 safe | safe 落在哪 | 适用 |
|----------|------------|-----------------|-------------|------|
| **列表型** | sheet 默认（有 safe） | ✅ 有 | 整页滚动区外圈；L3 **独立白块**（横卡 / `md-group-list` 组卡）浮在灰底上 | 横卡列表、**字段列表 MP-012**、时间轴、首页卡片区 |
| **浅灰壳型** | sheet 贴边（`--flush-x` / 页根类） | ❌ 无 | **白底 `md-module` 块内**；组间 `gap` **通栏露灰** | 图文详情正文、表单、设置、树 |

**为何浅灰壳不在 sheet 上加 safe**（产品语义，⑥ 同理）：白分组要**左右贴边**；safe 已在白块内，sheet 再加会**双重内缩**；组间灰带须**顶到屏幕左右**，否则不像系统设置/详情分组。

**mini-shop / 金样默认选型（常规不必改页型）**

| 页 | 模型 | 页根 / sheet | 备注 |
|----|------|--------------|------|
| 商品列表 MP-002 | 列表型 | 默认 sheet | 横卡独立条目 |
| 首页宫格 MP-001 | 列表型 | 默认 sheet | 金刚/瓷砖/卡片，非通栏分组条 |
| 物流时间轴 MP-009 | 列表型 | 默认 sheet | 物流轨迹一条条横卡；**仅已发生节点**、倒序；竖轨全程主色，起点空心、当前高亮 |
| 订单列表 MP-014 | 列表型 | 默认 sheet | 搜索+下划线页签+筛选；订单横卡（推广条/店头徽标/商品行价量/实付款/操作条） |
| 商品详情 MP-003 | 浅灰壳 | `md-detail-page` + flush sheet | 主图 immersive；下为分组模块 |
| 字段列表 MP-012 | 列表型 | 默认 sheet + `md-group-list` | = 桌面 D1-1 不分页分组字段；多条记录按组 |
| 表单 / 步骤向导 MP-004/005 | 浅灰壳 | `md-form-page` | 分组填表；向导只多步骤，壳不变 |
| 设置 MP-006 / 我的 MP-010 | 浅灰壳 | `md-set-page` | 设置项 vs 功能入口见页型速查 |
| 分类树 MP-008 | 贴边 split | `md-tree-page` + flush sheet | 左多级树，右图文介绍 |
| 分类导航 MP-013 | 贴边 split | `md-locator-page` + flush sheet | 左一级分组，右分组横卡，滚动联动 |

**页内 hybrid（不改整页型）**：详情 **评论区**可写「该段透底、评论用列表卡浮灰」——大壳仍浅灰壳，仅 L3 一段用列表卡密度；**不要**因此把整页详情改成列表型。

**何时才改页型**（规格须显式重写 L2 与页根类）：

| 信号 | 方向 |
|------|------|
| 原列表页要展示**字段列表**、多条记录按组、无横卡 | → **MP-012** / `mobile-fields`（sheet safe + `md-group-list`） |
| 原浅灰壳页要**多条记录分页/下拉加载**、条目为独立实体横卡 | → 改 **横卡列表型**（或桌面 D1-1 六型） |
| 原列表页其实是**单对象可编辑分组** | → **表单/浅灰壳**（`md-form-page`），不是字段列表 |
| 全新形态（如问卷**卡片流**、一步一张卡） | 单独 PAGE 说明；**禁止**只在现有页上混加 sheet safe |

**规格怎么写**：L2【滚动容器】写「`body` > `sheet` > 模块顺序」；**列表型**写「sheet 带左右 safe、卡片/模块浮灰底」；**浅灰壳**写「sheet 左右贴边、白 module 块内 safe、组间露灰」；**不要**写「无 sheet」除非整页无滚动主内容。

**⑥ 禁止**：body 叠 padding/底色；body 直放 module 跳过 sheet；sheet 与 body 同时 safe；贴边页 sheet 未 `--flush-x` 却在 module 外留白；Hero/顶栏/TabBar 塞进 sheet。

#### 1.3.5 需求描述 ≠ 可见标题（②⑤⑥ 必守）

立项、用户故事、功能规格、`ui/PAGE` L3 里的**分区称呼**（如「功能入口区」「刷题入口」「金刚区」）仅帮助 AI 理解结构与顺序；**除非 PM 明确要求对用户可见**，否则：

| 层级 | 禁止 | 允许 |
|------|------|------|
| ② `ui/PAGE` | 把内部分区名写进 L4「模块标题」或暗示必须有可见区块头 | L3 写模块类型与行为；L4 只写**用户应看到的**文案（入口短标签、列表分区名如「精选」「评论」） |
| ⑤ ASCII 线框 | 在整页/分区内线框画「功能入口区」「刷题入口」等**可见大标题行** | 用 `[金刚宫格]`、`[通栏入口]` 等**结构标注**（方括号/注释语义），或只画图标+短标签网格，不画区块标题行 |
| ⑥ 原型 HTML | 把 US/Feature/规格分区名塞进 `md-section-head__title` | 对照金样 DOM：**金刚区/通栏/一行两个/服务条默认无 `md-section-head`**（见 `gold/mobile-grid.html` 金刚 module、`gold/mobile-menu.html`） |

**默认无区块标题**：金刚宫格、金刚双卡、自解释图标+短标签的功能入口区、通栏/一行两个成组入口（分组标题本就可无）。**需要标题时**：列表/详情等多模块页、且须区分内容分区时——写**产品文案**（如「精选」「推荐」「商品评论」「今日上架」），不要写规格结构词。

PM 明确要求「用户可见区块标题 = XXX」时，② 须在 L4 或 §2.3 点名，⑤ 线框与 ⑥ `md-section-head__title` 方可使用该文案。

#### 1.3.6 功能区形态决策（`PT-MOBILE-FUNC`）

写 L3 功能区前按本表选型；⑤ ASCII 标 `[宫格]` / `[双卡]` / `[通栏]` 等；⑥ 用对应 `md-*`。金样合览：`gold/mobile-grid.html`（宫格+双卡+列表）；服务/通栏：`gold/mobile-menu.html`。

**五种形态**

| 形态 | 何时用 | 入口数 / 列数 | ⑥ 类名 |
|------|--------|---------------|--------|
| **宫格** | 入口 **≥5**；或只需**图标+极短标签**（≤4 字）、强调**一行扫视** | **5 个→5 列**；**4 个且仅极短标签**→4 列 | `md-king` |
| **双卡** | 须**标题+说明**；或 L2 **仅有成组入口、无列表**，需**填实视口** / 做模式教育 | 通常 2～4 项，**一排两张**（2×2 填四格） | `md-king md-king--pair` |
| **宫格+双卡** | **多种入口层级**（快扫分类 + 专题深读） | 宫格 5 列 + 双卡 2×2 | 两个 `md-module` |
| **通栏** | 菜单式逐项；接近设置/服务气质；可带右箭头/右说明 | 成组有限，每组若干项 | `md-set-group` > `md-set-row` |
| **一行两个** | **2～4 个轻入口**；信息少（图标+短标题）；接近我的/服务页 | 一排两格，可叠多行 | `md-set-pair` |

**入口个数 × 信息密度 × 有无列表**

| 入口数 | 信息 | L2 还有列表区？ | 推荐 |
|--------|------|-----------------|------|
| ≥5 | 极短标签 | 可有可无 | **5 列宫格** |
| 4 | 极短标签 | **有** | 4 列宫格可接受 |
| 4 | 极短标签 | **无** | **双卡 2×2** 或 **宫格+双卡**（勿留空荡单列宫格） |
| 4 | 标题+说明 | — | **双卡 2×2**；**不要**机械 4 列宫格 |
| 2～3 | 极短 | — | **一行两个** 或 **通栏** |
| 2～4 | 标题+说明 | — | **双卡** |

**双卡 vs 一行两个**（都是一排两格）：要标题+说明 → **双卡**；只要图标+短标题（可带极短右说明/箭头）→ **一行两个**。**不要**按是否首页选型。

**规格变更：砍掉列表区时**

金样 MP-001 同时含宫格+双卡+列表。若业务页**去掉列表模块**（精选/推荐/横卡等），滚动区易空——② 须**回退改功能区形态**：倾向 **双卡** 或 **宫格+双卡** 填实视口，**禁止**只留稀疏 4 列宫格。

**禁止**

- 仅因「是首页」就默认宫格  
- 仅因「有 4 个入口」就机械 **4 列宫格**（4 个且要说明 → 双卡 2×2 或一行两个×2）  
- 列表砍掉后功能区形态不变、页面大面积留白  

### 1.4 桌面端：布局结构类型与内容区固定结构

> 与 §1.3 对齐，布局规则落盘于 `ui/PAGE-*.md`。

#### 1.4.1 布局与内容区一览表

| 序号 | 类型 | 简要说明 |
|------|------|----------|
| D0 | **空白布局** | 独立全页，无业务壳或极简顶栏。`ui/PAGE-*.md` 骨架码 **D0**（**勿**写 **D1**）。 |
| D1-1 | **标准内容区** | **须**「顶栏 + 侧栏 + **面包屑** + 内容区」壳内。内容区**顶部就是面包屑，不要页内大标题**。自上而下：**面包屑**→**页内签（如有，在筛选上方）**→**搜索栏**→**功能栏**（`md-d1__toolbar`：**平铺**无圆角阴影，保留内外距）→**列表区**（操作列宽跟钮数）→**汇总（左）+分页（右）**。先点名列表六型：**分页标准列表 / 分页树形列表 / 不分页分组字段 / 不分页只读树 / 分页无图卡片列表 / 分页有图卡片列表**。骨架码 **D1-1**（卡片两型也可用 D1-3 点名 `md-card-grid`）。 |

#### 1.4.3 桌面端列表硬规则（PC / AD 的 D1-1 必守）

写桌面列表页时按本表落盘。⑥ 只负责用套件类名实现。

| # | 规则 | 规格怎么写 | 禁止 |
|---|------|------------|------|
| 1 | **页内签在筛选上方、整区切换** | 有页内签时写在 **搜索栏之前**；点签时 **整块切换** 搜索栏、功能栏、列表区、汇总+分页，不是只换表格行 | 签放在筛选下方或工具栏里；点签只过滤表格、筛选区还留着上一签的条件 |
| 2 | **汇总分页贴底** | 汇总栏+分页栏 **贴在内容区底部固定**，不随表格行上下滚走。仅当本页写明「分页跟表一起滚」才例外 | 分页画在表格最后一行下面、被行撑出视窗外 |
| 3 | **表头横向滚动条贴底** | 列表左右溢出时，**横向滚动条贴在表格可视区底部**（紧挨分页上方）。无特殊说明不得把横向滚动条悬在表中间 | 宽表只在首屏中部出现横条，底部分页却看不到横条 |
| 4 | **操作列右侧冻结** | 操作列 **固定在表右**；列宽按直出按钮形态与数量收（图标 1/2/3 档，文字钮按文案），表头与单元格同宽，`min-width` 须盖住全部直出钮，避免挤没后右冻「失效」 | 操作列跟中间列一起横滑消失；定宽过窄把钮挤没 |
| 5 | **勾选列左侧冻结** | 有勾选/选择列时 **固定在表左**，左右滚时不跟着走。无勾选列则写「无勾选列」 | 勾选列跟中间列一起横滑消失 |
| 6 | **冻结列内侧浮层阴影** | 左冻结列的 **右侧**、右冻结列的 **左侧**（对着滚动区的那一侧）有轻微阴影，看起来压在中间列上 | 冻结列无内外之分、或把阴影画在贴边外侧 |
| 7 | **内容区顶部是面包屑** | D1-1 / D1-2 写「顶部 **面包屑**，**无页内大标题**」。当前页名只出现在面包屑末项 | 面包屑上方再写一遍「商品列表」大标题 |
| 8 | **操作列遵守 `PT-DESKTOP-LIST`** | 写明操作总数、直出项和「更多」内项目；常规动作使用熟悉图标并提供中文可访问名称，删除为危险态；非常规文案才使用文字钮。阈值以共享规则为准 | 未引用共享规则；未列出菜单归属；操作列被一排文字按钮撑宽 |
| 9 | **汇总左、分页右** | 汇总栏+分页栏同一行贴底：**统计信息靠左**（如共 N 条），**分页器靠右**（每页条数、页码） | 统计和页码挤成一堆或平均散开 |
| 10 | **列宽按字段语义** | 写清各列大致宽窄：**说明/备注**优先吃剩余；无则 **日期/时间**；再无则 **最后一列数据列**（操作列前一列）。**名称/昵称**硬锁定宽。金额/状态/短码/数量窄；勾选与操作列定宽。**列宽必须同时盖住字段标题与单元格内容**。**长值省略且不得溢出叠到邻列**。同一单元格多字段用多行栈（主行+次行），行高够、禁止上下叠字。**慎用 `width: auto`**。禁止所有列均分。**溢出省略**的表头/单元格：悬停看全文，点击复制 | 长文案撑破邻列；多行字段行高不够上下重叠；裸 `width:auto` 压成一字；名称列被拉空荡 |
| 11 | **列表页紧凑密度** | D1-1 写「控件 **上下高度、内外距紧凑**，一屏多看几行」。面包屑、签、搜索栏、功能栏、表头表行、分页都走紧凑，不要用 D1-2 表单那种大内边距 | 列表页行高/内边距按表单页来，一屏只能看见三四行 |
| 12 | **列表六型点名** | 写明本页是 **分页标准列表**、**分页树形列表**、**不分页分组字段**、**不分页只读树**、**分页无图卡片列表** 还是 **分页有图卡片列表** | 凡数据区一律硬套商品标准列表 |

#### 1.7.0 默认体验规范（用户未另给规范时必用）

用户不必自备 Apple / Ant / 公司设计体系。未明确另给时，本包用这一份 + [`reference-mobile-design.md`](reference-mobile-design.md)。**皮肤**仍是套件（Material 浅色 `md-*`），禁止另起品牌色/字体/圆角。**行为与层级**按本表与设计词典。用户另给规范时：只覆盖冲突句，其余仍用本表。禁止用「没有设计规范」或「规格不能写色值」为借口只抄控件名、不做视觉层级。

来源（只取行为，不取皮肤）：系统状态可见、主路径在页内、破坏性确认、轻反馈不打断——与常见可用性启发式及 Material 行为条款一致；触屏/桌面结构仍走 **§1.3.3 / §1.4.3**。

| # | 默认 | ② 怎么写 | ⑥ 落地 |
|---|------|----------|--------|
| 1 | 一屏一件主事 | 「首屏只打 {一件}；其余进半屏/折叠/更多」 | 首屏不堆第二个主任务 |
| 2 | 等待可见 | 「先骨架；空=插图+人话+一个动作；失败可重试」 | `md-skeleton` / `md-empty--illus` / Alert 或 Toast |
| 3 | 收纳分层 | 主路径页内；筛选次要半屏/抽屉；少数字段弹窗；多字段才整页 | 禁止主内容只活在弹窗里 |
| 4 | 一个主按钮 | 「主操作一个；超过 3 个次要进更多」 | 主按钮 `contained`；次要 `text`/`outlined` 或 `data-menu` |
| 5 | 说人话 | 按钮用动词；空态写下一步，禁止只写「暂无数据」交差 | 空态 `__title`+`__text`+可点动作 |
| 6 | 可退可停 | 返回/取消/上一步；提交中禁用防连点 | 向导可回上一步；提交按钮 loading/禁用 |
| 7 | 破坏性要确认、轻结果不打断 | 「删/清空=确认框；已保存/已复制=Toast」 | `ProtoPage.confirm` vs `snackbar` |
| 8 | 触屏不靠 hover；桌面焦点可见 | 触屏按下态；桌面 Tab/回车/焦点圈 | 套件按下态 + `:focus-visible` |
| 9 | 浮层过渡、禁止闪白 | 「半屏/弹窗/签过渡滑入或淡入」 | `openDrawer` / `openDialog` / 签 `data-panel` |
| 10 | 页型用对骨架 | 列表紧凑语义列；设置一行一项；向导最后才提交；工作台指标+趋势+待办 | 对金样，禁止拿 `desktop-lists` 硬套 |

#### 1.7.1 设计问题（写页前自问，答案写入 PAGE §2.3）

| 舒服 | 一屏几件事、热区、会不会挡视线（胶囊、底栏、弹窗、圆角/曲面四边四角） | 「筛选不占首屏；进右半屏；控件不贴屏角」 |

#### 1.7.2 收纳决策（默认选左列，例外写进 §2.3）

| 场景 | 默认 | 不要 |
|------|------|------|
| 主路径浏览/购买 | 页内直出 | 主内容只在弹窗里 |
| 筛选、次要设置、说明 | 半屏 / 抽屉 / 折叠 | 无必要就新开整页 |
| 查看少量字段 | 展示弹窗或半屏 | 为三五条字段开新页 |
| 编辑少量字段 | 表单弹窗（**一行一项**，勿双列） | 能弹窗却整页跳转（字段很多才整页）；弹窗里双列并排字段 |
| 破坏性（删/清空/不可逆） | 确认框 | 只 Toast 或直接做 |
| 轻结果（已复制/已筛选/已保存） | Toast | 模态打断 |
| 一排超过 3 个次要操作 | 更多菜单 / 滑动露出 | 工具栏堆满主按钮 |
| 长说明、规则、注释 | 折叠或气泡 | 首屏长文 |

#### 1.7.3 动效与反馈（写语义，不写 CSS 参数）

用 **快 / 中 / 慢** 或 **过渡滑入 / 淡入 / 缩放按下**，不要写 ms、`#hex`、阴影扩散半径。⑥ 用套件默认时长与 token 实现。**可以且必须**写清：谁主谁次、哪里紧哪里松、成功用 Toast 还是确认框。

- **必须过渡（禁止瞬切）**：半屏/抽屉/弹窗开闭；页内签切换的内容区；Banner 轮播。
- **浮层须遮罩**：弹窗/半屏/抽屉打开时须有 **半透明黑遮罩** 盖住底层并 **禁止穿透点击**；Toast/气泡除外。
- **必须微反馈**：可点控件的按下态；主按钮提交中的 loading/禁用；成功与失败分流（Toast vs Alert/确认）。
- **桌面**：悬停可作增强，**不能**当唯一可辨认态（仍要有按下或焦点态）。
