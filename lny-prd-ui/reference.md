## 1. 阅读说明与清单结构约定

> **导读**：本文件仅维护 §2～§4 索引与 §5 全局说明。页面/组件详述落在 `ui/PAGE-*.md`、`ui/COMP-*.md`，禁止在本文件重复正文。详规见 `lny-prd-ui/SKILL.md`。

### 1.1 操控形态定义（全文区分基准）

| 形态 | 判定依据 | 典型终端（以项目 `main_spec` → 第4章终端说明 为准） |
|------|----------|------------------------------------------|
| **移动端** | 以 **手指触控** 为主完成主要交互 | 小程序、App、触屏 H5 等 |
| **桌面端** | 以 **鼠标指针**（及键盘辅助）为主完成主要交互 | PC 网页、管理后台 Web 等 |

### 1.2 视觉描述规则（两端适用）

**自底至顶（层级优先）** → **自上而下（同层多模块）** → **自左至右（左右布局优先）** → **自外至内（父子结构由内向外展开）**。

分页面须在以上顺序之上，按操控形态分别落实 **§1.3**（移动）或 **§1.4**（桌面），不得以本条替代 **§1.3 / §1.4** 的结构约定。

### 1.3 移动端：层级与布局

#### 1.3.1 层级一览表（L0～L5）

| 序号 | 层级名称 | 简要描述 |
|------|----------|----------|
| L0 | 系统层 | 状态栏与安全区、系统手势、壳层 TabBar 等 |
| L1 | 固定导航层 | 页内顶栏、业务固定顶/底栏等 |
| L2 | 主体滚动层 | 主内容滚动容器 |
| L3 | 模块容器层 | 卡片、分区、列表、表单块 |
| L4 | 内容元素层 | 标题、文案、按钮、图、输入、标签 |
| L5 | 浮层与反馈层 | 弹窗、抽屉、Toast、遮罩、加载态 |

#### 1.3.2 布局偏好（书写要点）

- 优先采用 **自动弹性容器布局**（如弹性盒、自适应流式/栅格），避免过多写死像素分区。
- 与 **`L0`～`L5`** 叙述一致。

### 1.4 桌面端：布局结构类型与内容区固定结构

> 与 §1.3 对齐，布局规则落盘于 `ui/PAGE-*.md`。

#### 1.4.1 布局与内容区一览表

| 序号 | 类型 | 简要说明 |
|------|------|----------|
| D0 | **空白布局** | 独立全页，无业务壳或极简顶栏。`ui/PAGE-*.md` 骨架码 **D0**（**勿**写 **D1**）。 |
| D1-1 | **标准内容区** | **须**「顶栏 + 侧栏 + **面包屑** + 内容区」壳内。自上而下：**搜索栏**→**功能栏**→**列表区**（含**操作列**）→**汇总+分页**。骨架码 **D1-1**。 |
| D1-2 | **表单内容区** | **同上**壳。**数据展示** / **数据录入**；**编辑** / **保存** / **取消**。骨架码 **D1-2**。 |
| D1-3 | **自定义内容区** | **同上**壳；非标结构在 **`ui/PAGE-*.md`** 按模块写。骨架码 **D1-3**。 |
| D5 | **浮层与反馈层（桌面）** | 叠在 **D0 / D1-1 / D1-2 / D1-3** 之上；记 **D5**，**勿**用 **L5**。 |

#### 1.4.2 桌面端书写要点（硬约束与指针）

- **D1-1**：**`ui/PAGE-*.md`** 须写全 **（1）～（4）**（见 **`lny-prd-ui/SKILL.md`**）。
- **硬约束**：禁止在 `ui/PAGE-*.md` 中使用 `api/API-*.md` 未定义的业务字段。

## 立项落盘与 `ui/` 目录初始化

**`/lny-prd-master` 立项时**：创建空目录 **`ui/`**，按上文 **「ui_manifest.md 模板」** 生成根目录 **`ui_manifest.md`**（索引骨架；**§2 UI 框架** 按 `main_spec` 第4章预填终端行）。

**`/lny-prd-ui` 续跑时**：

1. 若 **`ui_manifest.md` 不存在**：按 **「ui_manifest.md 模板」** 在根目录创建；同步创建 **`ui/`**（若不存在）。
2. 若 **`ui/` 不存在**：创建空目录；旧版 manifest 内大段页面/组件正文须 **迁移** 至 `ui/PAGE-*.md`、`ui/COMP-*.md` 后 manifest **只留索引**。
3. 新增 **`PAGE-*`**：更新 **§3.2**（及 MP **§3.1** 若涉及）→ 按 **PAGE 模板** 创建 **`ui/PAGE-{终端}-{序号}.md`** → 更新 **`main_spec.md` §5** 有效页面数。
4. 新增 **`COMP-*`**：更新 **§4** → 按 **COMP 模板** 创建 **`ui/COMP-{序号}.md`** → 更新 **`main_spec.md` §5** 组件数。
5. **禁止**在 `ui/` 存放 API 字段表、Feature 流程正文、原型 HTML。
