# 移动端设计词典（② 主责）

写 `ui/PAGE-*.md` / `ui/COMP-*.md` 前扫一眼。目标：像完整移动端设计规范一样覆盖原则、视觉、组件、布局、交互，但**不把规格写成视觉稿参数表**。

视觉呈现（色板、字号、圆角、间距、素材）由 **⑥** 按项目自身设计事实落地：项目既有视觉规范/品牌 CSS/真实图片素材优先；项目未给时按 PRD 自行设计。**禁止把技能内置样例形态当默认设计**。用户另给品牌规范时：只覆盖冲突项，其余仍用本词典 + §1.7.0。

## 分工（防误读）

| 板块 | ② 规格写什么 | 规格里不要写 |
|------|--------------|--------------|
| 原则与目标 | 本页主事、清晰/一致/可反馈怎么落地 | — |
| 视觉 | 主次层级、图文比例、疏密节奏（语义） | `#hex`、`14px`、字号表、阴影参数表 |
| 组件 | 用哪类控件、状态、收纳 | 自造组件名当皮肤 |
| 布局与适配 | L0/L1/L2、贴顶贴底、安全区、弹性分区 | 自拟 750 稿尺寸当唯一真理 |
| 交互与反馈 | 手势结果、按下/加载/成功/失败、空失败 | ms、hover 当唯一态 |
| 文档元信息 | `ui_manifest` 索引 + PAGE 表头 | 工具包版本号 |

**正确理解**：「规格不写色值清单」≠「不用设计视觉」。② 必须写清**层级与节奏**；⑥ 必须把视觉做满，并满足本页 §2.3。

## 1. 设计原则与目标

| 原则 | 含义 | ② 落笔 |
|------|------|--------|
| 清晰 Clarity | 一屏一眼看懂主事 | 「首屏只打 {一件}」 |
| 一致 Consistency | 同类页同结构、同反馈 | 对共享页型规则；勿混顶栏形态 |
| 反馈 Feedback | 操作必有可见结果 | 按下 / Toast / 确认 / 骨架 |
| 效率 | 减少无必要的页面切换视觉打断、热区够大 | 不改变上游路径；筛选半屏；热区 ≥44px 语义 |

设计目标（写进本页或项目级）：统一视觉语言、降低误触、主路径不进弹窗。

## 2. 视觉规范（语义层）

② 用下表描述观感；禁止抄成 CSS 参数表。

| 维度 | ② 怎么写 |
|------|----------|
| 颜色 | 「主操作强调；错误价/危险红；次要灰字」 |
| 字体 | 「标题强于副文；元信息最小可读」 |
| 图标 | 「与文案同组；元信息用小图标」 |
| 列表卡高度 | 「横卡/封面/双列/订单卡随内容增高，不定最小高度」 |
| 图片 | 「列表区点名形态；叠字/瓷砖可横可竖或定宽随图；横卡左图 1:1 或竖图；详情主图 16:9；详情图、横卡多行图、上传缩略默认可点预览」 |

列表区的横卡多行/单行选择、字段层级和操作位置直接遵守共享页型规则 `PT-MOBILE-LIST`；本文件只补封面叠字、双列和轻阴影等移动视觉原则。功能区形态选型遵守共享 **`PT-MOBILE-FUNC`**（详表 `lny-prd-ui` **§1.3.6**）：成组、每组入口有限；宫格/双卡/通栏/一行两个/**宫格+双卡**；**不限首页**；**无列表时倾向双卡填实**。**设置项**＝当页当行直接操作；**功能入口**＝只跳转或开半屏/弹窗（同壳不同行为）。

## 3. 组件规范（工具箱）

规格点名形态即可；具体实现由 ⑥ 按项目视觉事实落地。

| 类别 | 规格用语 |
|------|----------|
| 基础 | 按钮主/次/线框/浅底/文字/纯链接、通栏整行、输入、列表区；**一行一主钮**；贴底/半屏仅一钮自动占满；列表单行与设置项分开（独立有缝） |
| 表单 | 开关、单选多选、下拉、轮盘；页根浅灰底 + 白底分组 |
| 章节列表 / 父子章节 | 触屏 **父子章节列表**（章/节导航，父章可收起子章）；桌面 **章节大纲** |
| 分类树 | 左多级树右图文；点节点换右区。**不是**章节列表、不是分类导航 |
| 反馈 | 对话框 + **半透明黑遮罩**、Toast、骨架、空态 |
| 展示 | 标签（含卡片角标）、头像/缩略、轮播、进步/进度、时间轴 |
| 功能区 | 宫格、双卡、通栏、一行两个、宫格+双卡；按 **`PT-MOBILE-FUNC`** 选型；**平铺、无圆角阴影卡片壳**；触屏跟正文同左右安全距 |
| 导航 | TabBar、返回顶栏、页内签；触屏页内签做成浅底/色块按钮组（不做下划线） |
| 悬浮胶囊 | 按共享 `PT-FLOAT` 选择的浮层图标组 | ② 写清功能、避让对象与反馈；位置和折叠阈值不在本文件另存 |

触屏搜索框：**仅左图标 + 输入**，无「搜索」文案、无右侧搜索按钮。

热区：可点控件语义 ≥44px；触屏不靠 hover 当唯一态。

## 4. 页面布局与适配

| 项 | ② / L 层级 |
|----|---------------|
| 滚动容器底与边 | 滚动容器纯滚动（外层透明、无额外内边距）；浅灰底 + 统一内边距；见 `reference/visual-rules.md` §1.3.4 |
| 滚动区页型选型 | 列表族 vs 内容/表单族；**字段列表 MP-012 = 列表族·无分页·多条按组**；见 `reference/visual-rules.md` §1.3.4 |
| 结构 | L0/L1 无滚动容器；L2 必有【滚动容器】，内部装 L3；详见 `reference/visual-rules.md` §1.3.4 |
| L2 下沉 vs 随滚 Banner | 下沉 → L2【下沉首屏】+ 沉浸式；随滚 → L3 普通模块内 Banner，不写 Hero 钉底 |
| 固定 vs 吸顶 | L1：滚动容器 **外**（搜索/筛选/返回/TabBar/贴底条）；L3 吸顶：容器 **内** sticky（写顶距） |
| 安全区 | 正文左右 **12**；标准顶栏左右 4；状态栏 28；底栏 48；overlay/cover 避让胶囊 |
| 弹性布局 | 「左图右文可伸缩；主文与底栏分开；树页左树右内容；时间轴左竖轨右**横卡文本**（无左图，正文可嵌小图）」 |
| 适配基准 | 不写死唯一稿宽 |

顶栏四选一（禁止混用）：① 16:9+slogan ② 16:9+返回标题 ③ 标准返回标题 ④ 两倍高度封面。**沉浸式**（L0）与 **下沉滚过**（L2【下沉首屏】）是两套概念——见 `reference/visual-rules.md` §1.3.4。

## 5. 交互与反馈

| 项 | ② |
|----|----|
| 手势 | 点按、滑动列表、半屏拖关闭（语义） |
| 按下 | 「按下有缩放/变暗」 |
| 加载/空/失败 | 舒适默认六项 |
| 成功/轻结果 | Toast（触屏居中半透明黑底） |
| 破坏性 | 确认框 |
| 动效 | 快/中/慢、滑入/淡入；禁止闪白 |

## 6. 文档基础信息

| 项 | 落点 |
|----|------|

| 修订 | 改根规范 → `iteration_notes`；改技能包 → 工具包版本号 |

## 写 §2.3 时的最小清单

1. 原则：本页主事 + 清晰/反馈一句  
2. 视觉：主次与图文比例（语义，无色值表）  
3. 组件：关键控件与状态  
4. 布局：顶栏形态、固定区、安全区  
5. 交互：加载/空/失败、按下、成功/失败分流  
6. 舒适默认六项（或「无」并说明）
