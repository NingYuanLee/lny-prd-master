# 桌面端设计词典（② 主责 · 与套件分工）

写桌面 `ui/PAGE-*.md` 前扫一眼。皮肤与 px 由 **⑥ `lny-prd-prototype` 套件 + `gold/`** 落地。与 [`reference-mobile-design.md`](reference-mobile-design.md) 并列；冲突时以本文件 + 共享 `PT-*` 为准。

## 分工（防误读）

| 板块 | ② 规格写什么 | ⑥ / 套件写什么 | 规格里不要写 |
|------|--------------|----------------|--------------|
| 页面布局 | D1 骨架 + 通栏/分栏形态（通栏/双列/三列/品字） | `md-layout--*` 金样 | 拿表单窄双列当页面分栏 |
| 表单栅格 | 几列、哪些跨列、分区节奏 | `md-d1__form` / `--cols-*` 与 gap | 字段贴死、无行距 |
| 列表四型 | 分页标准 / 分页树表 / 分组字段 / 只读树 择一 | `desktop-lists.html` | 一律硬套商品表 |
| 卡片列表 | 图文栅格、非强对齐列 | `md-d1--cards`；金样 `desktop-cards.html` | 塞进列表四型页签 |
| 操作列与列宽 | 操作个数与形态、列语义 | `md-col-actions` 按钮数定宽、`md-col-*`、`md-cell-stack` | 均分列、操作列被挤没 |
| 状态导览 | 页签 / 步骤 / 进步条 / 进度条谁切内容 | `md-tabs` / `md-stepper` / `md-advance` / `md-progress` | 各写一套互不相关规则 |
| 定位导航 | 分类钮 / 时间轴节点 / 章节大纲 | `md-locator` 族 | 与树组件混为一谈 |
| 树 | 不分页左树右内容，或表内父子嵌套行 | `md-tree` / `md-table--nest` | 用分类钮冒充树 |

## 1. 页面级布局（≠ 表单窄双列）

桌面标准壳（顶栏+侧栏+面包屑+内容区）里，**内容区默认通栏**；有规格时再左右/多栏。**禁止**把 D1-2 表单的「窄双列栅格」`md-d1__form`（`max-width` 约一栏半、字段两两并排）错套成页面分栏。

| 形态 | ② 怎么写 | ⑥ 金样 / 类 | 禁止 |
|------|----------|-------------|------|
| **标准通栏** | 「内容区一块铺满，不再左右切开」 | `md-layout md-layout--full`；金样 `gold/desktop-layout.html` 第一节 | 无分栏需求却硬拆双列 |
| 双列 | 「左右两栏；左职责 / 右职责；哪栏滚、哪栏钉」 | `md-layout md-layout--2col` | 用 `md-d1__form` 冒充两栏页面 |
| 三列 | 「左导航 / 中主区 / 右辅助」 | `md-layout--3col` | 三列均分塞满表单字段 |
| 品字形 | 「上通栏 + 下左右」或「上左右 + 下通栏」 | `md-layout--pin`（上 `--span`）。品字顶条 ≠ 整页标准通栏 | 强行套 D1-1 商品表壳 |
| 左树右内容 | 见 §5 树 | `md-d1--split` + `md-tree` | 与「分类定位」混用 |
| 左定位右长文 | 见 §4 定位导航 | `md-d1--split` + `md-locator` | 左侧做成可展开树 |

落盘口诀：**页面分栏用 `md-layout` / `md-split`；字段并排用 `md-d1__form`。二者不是同一件事。**

## 2. 表单栅格（D1-2）

| 规则 | ② 怎么写 | ⑥ 必守 |
|------|----------|--------|
| 默认双列 | 「桌面表单双列；长字段/多行/上传/分区标题跨两列」 | `md-d1__form`（默认 `--cols-2`）；`gap` 行距不得丢 |
| 单列 / 三列 | 规格点名时写「单列」或「三列」 | `--cols-1` / `--cols-3` |
| 行距 | 「字段上下有呼吸，禁止贴死」 | 表单栅格 **行距 ≥ 列距**；嵌套块用 `md-form-block` 且块内同样有 gap |
| 弹窗表单 | 「一行一项」 | `md-dialog__form` **单列**，禁止弹窗内再套页面双列 |
| 向导当前步 | 「当前步疏密与整页表单相同」 | `[data-step]` 必须自己吃双列 gap，禁止裸堆字段 |

常见翻车：把字段包进无 gap 的裸 `div`、或把整页 `md-d1__form` 塞进分栏左栏当「布局」。

金样：`gold/desktop-form.html`。

## 3. 列表四型、卡片与列宽 / 操作列

共享规则 **`PT-DESKTOP-LIST`** 是单一事实源；本表只补形态选型与精致化。选型金样：`gold/desktop-lists.html`。

### 3.1 四型 + 卡片

| 型 | 何时用 | ② 怎么写 | ⑥ |
|----|--------|----------|-----|
| **分页标准列表** | 筛+功能+分页维护主数据 | D1-1 全套：签/筛/功能/表/汇总分页 | `md-d1 md-d1--list`；落地金样 `desktop-list.html` |
| **分页树形列表** | 分页表里要看父子层级 | 「表内嵌套行 + 分页」 | `md-table--nest`；`desktop-lists` 第二签 / `desktop-tree-nest.html` |
| **不分页分组字段** | 记录按组展示字段名+值，不翻页 | 「分组字段展示，无分页」 | `md-group-list` + `md-desc`；不要套表壳分页 |
| **不分页树形展示** | 只看层级，无增删改 | 「只读树；可展开；禁止维护条」 | `md-tree` + `data-tree-edit="off"`。维护树另见 `desktop-split` |
| **卡片列表** | 条目图文重、非强对齐列 | 「桌面卡片列表；栅格/流式」 | `md-d1--cards` + `md-card`；金样 `desktop-cards.html`（不进四型页签） |

工作台嵌入短表仍可只用 `md-table`，不算四型。禁止：凡桌面有「一排数据」就整页套商品标准列表。

### 3.2 操作列宽度（按钮形态与数量）

| 规则 | 说明 |
|------|------|
| 定宽跟内容 | 操作列宽由 **直出控件个数与形态** 决定，禁止写死过窄导致挤没，也禁止一排文字钮撑爆 |
| 图标钮 | ≤2 个全直出；≥3 直出 1～2 +「更多」。列宽随 1/2/3 颗图标递增（套件按子节点数自动收） |
| 文字钮 | 仅非常规文案；列宽按文案加宽，优先考虑收进「更多」 |
| 右冻 | `md-col-actions` sticky 右冻；`min-width` 必须盖住全部直出钮，否则右冻看起来「失效」 |

### 3.3 列宽与多行单元格

| 问题 | 规则 |
|------|------|
| 长值溢出叠列 | 数据列 `overflow: hidden` + 省略；悬停看全文、点击复制（套件）。禁止裸撑破相邻列 |
| 一列多字段多行 | 用 **`md-cell-stack`**（主行 + 次行）；单元格允许换行、行高随内容、**行内上下有缝**，禁止两行字重叠 |
| 语义列宽 | 名称定宽；说明/备注吃剩余；金额/状态窄；勾选/操作定宽。见 `PT-DESKTOP-LIST` |

## 4. 状态导览（页签 · 步骤 · 进步条 · 进度条）

本质同类：**用「当前状态」控制展示哪一块内容**。② 写「状态导览」时点名形态；⑥ 对照同一金样族，不要各写互斥规则。

| 形态 | 状态含义 | 切什么 | ⑥ |
|------|----------|--------|-----|
| 页内签 `md-tabs` | 并列视图 | 整区面板（筛+表+分页） | 桌面 `--page` 下划线；金样 `desktop-list` |
| 数字步骤 `md-stepper` | 有序向导步 | 当前步表单 | 桌面数字可点跳步；`desktop-wizard` |
| 分段进步条 `md-advance` | 完成到第几段 | 视觉进度（可与步骤同步） | `setAdvance` |
| 无极进度条 `md-progress` | 连续百分比 | 上传/完整度 | `setProgress`；勿与分段互相冒充 |

金样合览：`gold/desktop-state-flow.html`（页签 + 步骤 + 进步/进度同页说明）。业务页按规格只取其一或组合，禁止整页搬样例。

## 5. 定位导航 vs 树

### 5.1 定位导航族（分类 · 时间轴 · 章节大纲）

共同点：节点/按钮 **可点** 时，控制 **右侧（或下方）滚到/高亮某一内容锚点**；一般 **不展开父子层级**（或层级仅展示、不承担筛选树职责）。

| 形态 | 左侧/轨 | 右侧/内容 | 金样 |
|------|---------|-----------|------|
| 分类按钮 | 平铺或分组分类钮 | 对应区块或列表 | `md-locator md-locator--cats`（可与大纲并存，不作本金样主构图） |
| 时间轴节点 | 左栏紧凑节点 + 时刻 | 右侧全文；点节点滚到锚点 | `desktop-timeline.html`（`md-timeline--nav`）。触屏才用竖轨右图文 |
| 章节大纲 | 左栏大纲条目 | 右侧长文锚点；点条目滚到锚点 | `desktop-locator.html`（`md-locator--outline`） |

桌面时间轴与章节大纲 **同构**：`md-d1--split`，左导航右全文。② 写清：点选后是 **定位滚动** 还是 **替换右区数据**。详情页右下「目录」同属定位族（`data-section`）。

### 5.2 树（维护 / 只读列表 / 表内嵌套）

| 型 | 说明 | ⑥ |
|----|------|-----|
| **不分页维护树** | 左树右内容；总控展开/收起/增根；节点增子/重命名/删除；拖到上/中/下分别＝同级紧前 / 末个子节点 / 同级紧后。末级可否增子按规格。点节点只换右区 | `md-d1--split` + `md-tree`；金样 `desktop-split.html` |
| **不分页只读树** | 仅展示层级，无增删改 | `data-tree-edit="off"`；金样 `desktop-lists.html` 第四签 |
| **表内嵌套行** | 分页列表里父子行缩进展开 | `md-table--nest` + `md-row--child`；`desktop-lists` 第二签 / `desktop-tree-nest.html` |

禁止：用 `md-tree` 金样去实现「顶部分类 Tab」；禁止用分类定位去冒充可展开组织树。

## 6. 与共享 PT 的关系

| ID | 本词典补充点 |
|----|----------------|
| `PT-DESKTOP-LIST` | 四型选型、卡片另页、操作列按钮数定宽、`md-cell-stack`、溢出不叠列 |
| `PT-DESKTOP-LAYOUT` | 通栏/双列/三列/品字；禁止表单窄双列冒充分栏 |
| `PT-STATE-FLOW` | 页签/步骤/进步/进度同族 |
| `PT-LOCATOR` | 分类/时间轴/大纲定位；与树分离 |
| `PT-DESKTOP-TREE` | 不分页树 vs 表内嵌套行 |

## 7. 写完自检（桌面）

- 左右分栏是否误写成 `md-d1__form` 窄双列？
- 表单字段是否上下贴死、或弹窗里套了双列？
- 操作列是否按真实钮数/形态定宽，右冻是否还能看见全部直出钮？
- 长字段是否溢出叠到邻列？多行单元格是否用 `md-cell-stack` 且行高够？
- 页签与进步条是否按「状态导览」同一套逻辑写，而不是两套互斥故事？
- 分类/大纲/时间轴是否与树拆开写清？
- 列表是否点名了四型之一，或单独点名了卡片列表？
