# 桌面端设计词典（② 主责 · 与套件分工）

写桌面 `ui/PAGE-*.md` 前扫一眼。皮肤与 px 由 **⑥ `lny-prd-prototype` 套件 + `gold/`** 落地。与 [`reference-mobile-design.md`](reference-mobile-design.md) 并列；冲突时以本文件 + 共享 `PT-*` 为准。

## 分工（防误读）

| 板块 | ② 规格写什么 | ⑥ / 套件写什么 | 规格里不要写 |
|------|--------------|----------------|--------------|
| 页面布局 | D1 骨架 + 通栏/分栏形态（通栏/均分双列/左定右填/左填右定/三列/品字） | `md-layout--*` 金样；夹具 `PAGE-AD-014` | 拿表单窄双列当页面分栏 |
| 表单栅格 | 几列、哪些跨列、分区节奏 | `md-d1__form` / `--cols-*` 与 gap | 字段贴死、无行距 |
| 列表六型 | 分页标准 / 分页树表 / 分组字段 / 只读树 / 无图卡片 / 有图卡片 择一 | `desktop-lists.html`（只对标列表区；筛/功能栏按规格） | 一律硬套商品表；从金样抄成业务页不要筛 |
| 操作列与列宽 | 操作个数与形态、列语义 | `md-col-actions` 按钮数定宽、`md-col-*`、`md-cell-stack` | 均分列、操作列被挤没 |
| 状态导览 | 页签 / 步骤 / 进步条 / 进度条谁切内容 | `md-tabs` / `md-stepper` / `md-advance` / `md-progress` | 各写一套互不相关规则 |
| 定位导航 | 分类钮 / 章节大纲（左可收缩或右悬浮） | `md-locator` 族；金样 `desktop-locator.html`；夹具 `PAGE-AD-013` | 与树、时间轴混为一谈 |
| 树 | 不分页左树右内容，或表内父子嵌套行 | `md-tree` / `md-table--nest` | 用分类钮冒充树 |

## 1. 页面级布局（≠ 表单窄双列）

桌面标准壳（顶栏+侧栏+面包屑+内容区）里，**内容区默认通栏**；有规格时再左右/多栏。**禁止**把 D1-2 表单的「窄双列栅格」`md-d1__form`（`max-width` 约一栏半、字段两两并排）错套成页面分栏。

| 形态 | ② 怎么写 | ⑥ 金样 / 类 | 禁止 |
|------|----------|-------------|------|
| **标准通栏** | 「内容区一块铺满，不再左右切开」 | `md-layout md-layout--full`；金样 `gold/desktop-layout.html` 第一节 | 无分栏需求却硬拆双列 |
| 双列 | 「左右两栏均分；左职责 / 右职责；哪栏滚、哪栏钉」 | `md-layout md-layout--2col` | 用 `md-d1__form` 冒充两栏页面 |
| 左定右填 | 「左侧定宽，右侧吃剩余」 | `md-layout--fix-left`（默认 240px，可 `--md-layout-aside`） | 用维护树 `md-d1--split` 冒充 |
| 左填右定 | 「右侧定宽，左侧吃剩余」 | `md-layout--fix-right` | 用表单窄双列冒充 |
| 三列 | 「左导航 / 中主区 / 右辅助」 | `md-layout--3col` | 三列均分塞满表单字段 |
| 品字形 | 「上通栏 + 下左右」或「上左右 + 下通栏」 | `md-layout--pin`（上 `--span`）。品字顶条 ≠ 整页标准通栏 | 强行套 D1-1 商品表壳 |
| 左树右内容 | 见 §5 树 | `md-d1--split` + `md-tree` | 与「分类定位」混用 |
| 章节大纲 | 见 §4 定位导航 | 左可收缩 / 右悬浮可收起 | 左侧做成可展开树 |

落盘口诀：**页面分栏用 `md-layout` / `md-split`；字段并排用 `md-d1__form`。二者不是同一件事。**

## 2. 表单栅格（D1-2）

| 规则 | ② 怎么写 | ⑥ 必守 |
|------|----------|--------|
| 默认双列 | 「桌面表单双列；长字段/多行/上传/分区标题跨两列」 | `md-d1__form`（默认 `--cols-2`）；`gap` 行距不得丢 |
| 单列 / 三列 | 规格点名时写「单列」或「三列」 | `--cols-1` / `--cols-3` |
| 行距 | 「字段上下有呼吸，禁止贴死」 | 表单栅格 **行距 ≥ 列距**；嵌套块用 `md-form-block` 且块内同样有 gap |
| 弹窗表单 | 「一行一项」 | `md-dialog__form` **单列**，禁止弹窗内再套页面双列 |
| 向导当前步 | 「当前步疏密与整页表单相同」 | `[data-step]` 必须自己吃双列 gap，禁止裸堆字段 |

常见翻车：把字段包进无 gap 的裸 `div`、或把整页 `md-d1__form` 塞进分栏左栏当「布局」。

金样：`gold/desktop-form.html`。

## 3. 列表六型与列宽 / 操作列

共享规则 **`PT-DESKTOP-LIST`** 是单一事实源；本表只补形态选型与精致化。金样：`gold/desktop-lists.html`（**只对标列表区**；筛区/功能栏按规格另加）。

### 3.1 六型选型

| 型 | 何时用 | ② 怎么写 | ⑥ |
|----|--------|----------|-----|
| **分页标准列表** | 筛+功能+分页维护主数据 | D1-1 全套：签/筛/功能/表/汇总分页 | `md-d1 md-d1--list`；金样第一签只画表+汇总分页 |
| **分页树形列表** | 分页表里要看父子层级 | 「表内嵌套行 + 分页」 | `md-table--nest`；子行缩进；展开收起 +/−；第二签 / `desktop-tree-nest.html` |
| **不分页分组字段** | 多条记录按组展示字段名+值，不翻页 | 「分组字段展示，无分页」 | `md-group-list`；白底轻阴影；记录间浅线左右内缩、不贴边；字段行不要再画分割线；不要套详情页单对象 `md-module` |
| **不分页树形展示** | 只看层级，无增删改 | 「只读树；可展开；禁止维护条」 | `md-tree` + `data-tree-edit="off"`。维护树另见 `desktop-split` |
| **无图卡片** | 条目非强对齐列、无封面 | 「无图卡片栅格」 | `md-card-grid` + `md-card--tile`，不要 `__media`；同一行等高，放不下换行 |
| **有图卡片** | 条目图文重 | 「有图卡片栅格」 | `md-card-grid` + `md-card--tile` + `__media`；同一行等高，放不下换行 |

工作台嵌入短表仍可只用 `md-table`，不算六型。禁止：凡桌面有「一排数据」就整页套商品标准列表。无图/有图不要混在同一栅格。

### 3.2 操作列宽度（按钮形态与数量）

| 规则 | 说明 |
|------|------|
| 定宽跟内容 | 操作列宽由 **直出按钮形态与数量** 决定：套件实测 `.md-actions` 内容宽后钉整列（表头与单元格同宽）。禁止写死过窄导致挤没，也禁止一排文字钮撑爆 |
| 图标钮 | ≤2 个全直出；≥3 直出 1～2 +「更多」。列宽随 1/2/3 颗图标递增（套件按形态+数量自动收） |
| 文字钮 | 仅非常规文案；列宽按文案加宽，优先考虑收进「更多」 |
| 右冻 | `md-col-actions` sticky 右冻；`min-width` 必须盖住全部直出钮，否则右冻看起来「失效」 |

### 3.3 列宽与多行单元格

| 问题 | 规则 |
|------|------|
| 长值溢出叠列 | 数据列 `overflow: hidden` + 省略；悬停看全文、点击复制（套件）。禁止裸撑破相邻列 |
| 一列多字段多行 | 用 **`md-cell-stack`**（主行 + 次行）；单元格允许换行、行高随内容、**行内上下有缝**，禁止两行字重叠 |
| 语义列宽 | 名称定宽；说明/备注吃剩余；金额/状态窄；勾选/操作定宽。见 `PT-DESKTOP-LIST` |

## 4. 状态导览（页签 · 步骤 · 进步条 · 进度条）

本质同类：**用「当前状态」控制展示哪一块内容**。② 写「状态导览」时点名形态；⑥ 对照同一金样族，不要各写互斥规则。

| 形态 | 状态含义 | 切什么 | ⑥ |
|------|----------|--------|-----|
| 页内签 `md-tabs` | 并列视图 | 整区面板（筛+表+分页） | 桌面 `--page` 下划线；业务列表整区切换。金样 `desktop-lists` 六型签只切列表形态，不是库存筛签 |
| 数字步骤 `md-stepper` | 有序向导步 | 当前步表单 | 桌面数字可点跳步；`desktop-wizard` |
| 分段进步条 `md-advance` | 完成到第几段 | 视觉进度（可与步骤同步） | `setAdvance` |
| 无极进度条 `md-progress` | 连续百分比 | 上传/完整度 | `setProgress`；勿与分段互相冒充 |

金样合览：`gold/desktop-state-flow.html`（页签 + 步骤 + 进步/进度同页说明）。业务页按规格只取其一或组合，禁止整页搬样例。

## 5. 定位导航 vs 树

### 5.1 定位导航族（分类 · 章节大纲）

共同点：按钮 **可点** 时，控制正文 **滚到/高亮某一内容锚点**；一般 **不展开父子层级**（或层级仅展示、不承担筛选树职责）。

| 形态 | 怎么摆 | 内容 | 金样 |
|------|--------|------|------|
| 分类按钮 | 平铺或分组分类钮 | 对应区块或列表 | `md-locator md-locator--cats`（可与大纲并存，不作本金样主构图） |
| 章节大纲 · 左 | 大纲占左栏，**可整栏收缩** | 右侧长文；点条目滚锚点；滚正文时高亮联动 | `desktop-locator.html` 第一签（`md-split--outline`）；夹具 `PAGE-AD-013` |
| 章节大纲 · 右悬浮 | 大纲悬浮在右侧，**可收成细条** | 正文通栏；点条目滚锚点；滚正文时高亮联动 | `desktop-locator.html` 第二签（`md-locator-float`）；夹具 `PAGE-AD-013` |

② 点名用哪一种大纲，并写清：点选后是 **定位滚动** 还是 **替换右区数据**。定位滚动时滚正文，大纲当前章高亮跟着走。详情页右下「目录」同属定位族（`data-section`），不是常驻悬浮大纲。桌面时间轴 **不是** 本族分栏，见 `desktop-timeline.html`（通栏竖轨右图文）。

### 5.2 树（维护 / 只读列表 / 表内嵌套）

| 型 | 说明 | ⑥ |
|----|------|-----|
| **不分页维护树** | 左树右内容；总控展开/收起/增根；节点增子/重命名/删除；拖到上/中/下分别＝同级紧前 / 末个子节点 / 同级紧后。末级可否增子按规格。点节点只换右区 | `md-d1--split` + `md-tree`；金样 `desktop-split.html`；夹具 `PAGE-AD-005` |
| **不分页只读树** | 仅展示层级，无增删改 | `data-tree-edit="off"`；金样 `desktop-lists.html` 第四签 |
| **表内嵌套行** | 分页列表里父子行缩进展开；展开收起用 +/− | `md-table--nest` + `md-row--child`；`desktop-lists` 第二签 / `desktop-tree-nest.html` |

禁止：用 `md-tree` 金样去实现「顶部分类 Tab」；禁止用分类定位去冒充可展开组织树。

## 6. 与共享 PT 的关系

| ID | 本词典补充点 |
|----|----------------|
| `PT-DESKTOP-LIST` | 六型选型、操作列按钮数定宽、`md-cell-stack`、溢出不叠列 |
| `PT-DESKTOP-LAYOUT` | 通栏/均分双列/左定右填/左填右定/三列/品字；禁止表单窄双列冒充分栏 |
| `PT-STATE-FLOW` | 页签/步骤/进步/进度同族 |
| `PT-LOCATOR` | 分类/大纲定位（左可收缩或右悬浮可收起）；与树分离 |
| `PT-DESKTOP-TREE` | 不分页树 vs 表内嵌套行 |

## 7. 写完自检（桌面）

- 左右分栏是否误写成 `md-d1__form` 窄双列？
- 表单字段是否上下贴死、或弹窗里套了双列？
- 操作列是否按真实钮数/形态定宽，右冻是否还能看见全部直出钮？
- 长字段是否溢出叠到邻列？多行单元格是否用 `md-cell-stack` 且行高够？
- 页签与进步条是否按「状态导览」同一套逻辑写，而不是两套互斥故事？
- 分类/大纲是否与树、时间轴拆开写清？大纲是否点名了左侧可收缩或右侧悬浮？
- 列表是否点名了六型之一？
