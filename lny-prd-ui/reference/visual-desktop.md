# 桌面端视觉规则（按需读取）

仅在操控形态为桌面端时读取。根据 PAGE 页型选择对应章节，不读取移动端规则。

- 明确 D0、D1-1、D1-2 或 D1-3 骨架。
- 面包屑、主操作、内容区和操作列保持稳定对齐。
- 列表使用语义列宽、冻结策略和合理密度。
- 表单保持整页节奏，不用列表骨架冒充表单。
- 键盘 Tab 顺序合理，焦点可见，主按钮可回车提交。

复杂页型和具体规则见 [`reference-desktop-design.md`](../reference-desktop-design.md) 与 [`visual-rules.md`](visual-rules.md)。
