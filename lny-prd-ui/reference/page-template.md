### 2.3 交互体验设计（必填，移动/桌面都写）

> 按 [`ui-manifest-template.md`](ui-manifest-template.md) **§1.7**（未另给规范则用 **§1.7.0**）。写语义不写 CSS。删掉本节后⑥只会画出线框 → 未完成。

- **观感与舒适**：{首屏主次；一屏几件事；固定区 vs 滚动；图文比例。无例外则写「按默认体验规范」}
- **向导进度（有序向导 / 引导分步页必填）**：所选一种导览须**一眼看懂共 {N} 步**；仅数字步骤可点跳步；分段/无极只展示、靠上一步/下一步；禁止写多种导览并列
- **加载 / 空 / 失败**：{骨架；空态插图与引导；失败可重试。无则写无并说明}
- **键盘与焦点**：{桌面 Tab/回车/焦点可见；触屏不靠 hover。无则写无}
- **首次进入**：{没数据/没权限时第一眼。无则写无首次引导}
- **动效与过渡**：{必须过渡的开闭/轮播/签切换；允许瞬切的；用快/中/慢或「过渡滑入」}
- **复杂交互效果（有则逐项）**：{除一次直接点击外，逐项写“触发 → 可见过程/过渡 → 结果状态 → 取消/失败/禁用（适用时）”；归属 COMP 则引用对应状态矩阵}
- **微反馈**：{按下；提交中；成功；失败}
- **收纳与浮层**：{默认露出什么；折叠/半屏方向/弹窗/确认/Toast 各管什么；为何不新开页}
