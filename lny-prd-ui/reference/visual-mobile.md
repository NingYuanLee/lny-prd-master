# 移动端视觉规则（按需读取）

仅在操控形态为移动端时读取。根据 PAGE 页型选择对应章节，不读取桌面端规则。

- 明确沉浸式或标准顶栏。
- 明确唯一滚动容器，固定区置于滚动容器外。
- 首屏突出一个主任务，次要内容进入折叠、半屏或更多。
- 图片比例、卡片形态和底部操作区必须服务于页面任务。
- 触屏交互不依赖 hover，按下、提交中、成功和失败都要有可见反馈。

复杂页型和具体规则见 [`reference-mobile-design.md`](../reference-mobile-design.md) 与 [`visual-rules.md`](visual-rules.md)。
