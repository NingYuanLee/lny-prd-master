## 1. 阅读说明与事实边界

本文件只维护 UI 框架、页面分组注册、页面地址注册、局部自定义 UI 组件索引与项目级全局视觉约定。

- 页面地址只表示页面文件或前端路由映射，不表示用户路径、跳转条件或业务流程。
- 用户路径、画像策略、权限、合规、审核、可见性与业务状态归 `main_spec.md` / `feature_spec.md` / `feature/FEATURE-*.md`。
- 字段、必填性、默认值、枚举、读写、接口用途与触发时机归 `api_spec.md` / `api/API-*.md` / `api/EXT-*.md`。
