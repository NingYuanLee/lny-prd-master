# 基础模型视觉基线

本基线用于让普通模型稳定产出清晰、有层次、可继续修改的界面。

## 生成前

1. 确定页面唯一主任务和首屏视觉锚点。
2. 确定信息层级、内容密度、组件表现和状态语言。
3. 同一终端沿用同一套色彩语义、边界语言、按钮层级和间距节奏。
4. 优先使用项目真实素材、品牌事实和已有页面语言。
5. 没有视觉事实时，选择一套克制且有领域线索的方向，并写入 PAGE §2.4。

## 生成中

- 不使用“顶部标题 + 三张等宽卡片 + 大量留白”作为默认首页。
- 不把所有内容都做成卡片，不把所有操作都做成彩色按钮。
- 页面必须有主次，次要信息进入分组、折叠、半屏或辅助文本。
- 列表、表单、详情、工作台使用不同骨架，不能互相套用。
- 状态、空态、失败态保持同一视觉语言，并提供清晰恢复动作。
- 每个页面最多保留一个主要签名元素，避免装饰压过任务。

## 生成后

至少检查一次真实渲染结果：首屏主次、文字层级、内容密度、横向溢出、图片比例、移动端滚动、桌面端对齐、空态和失败态。发现明显问题先修复，再报告原型完成。Q-P 仍是用户可选择的正式门禁。
