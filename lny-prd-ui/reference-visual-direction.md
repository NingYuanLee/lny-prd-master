# PAGE 视觉方向契约

视觉方向是 UI 规格的一部分，负责把产品事实转成可实现、可复核的视觉判断。它不写 CSS、像素值或组件库类名。

## 必填判断

- **气质与领域语汇**：用 3～5 个词说明页面希望传达的感觉，并指出来自业务的视觉线索。
- **视觉锚点**：指出首屏最重要的一个视觉焦点，以及用户第二眼看到的内容。
- **色彩语义**：说明主色、强调色、背景层、边界和风险状态分别承担什么语义。
- **层级与节奏**：说明标题、正文、辅助信息的层级，首屏密度和内容节奏。
- **组件表现**：说明列表、卡片、表单、标签、按钮、导航和浮层的整体策略。
- **状态表现**：说明加载、空、失败、禁用、选中、成功状态如何保持同一语言。
- **素材策略**：说明真实图片、插图、图标或纯色占位的使用方式。
- **响应式重点**：分别指出移动端和桌面端必须保留的视觉重点与可收纳内容。
- **签名元素**：指定一个服务产品语义、可复用、可记忆的视觉元素。

禁止使用“现代、简洁、好看”作为唯一结论。已有设计稿、品牌规范或真实素材时优先提取其事实。没有时先在 PAGE 形成方向，再由原型统一实现。
