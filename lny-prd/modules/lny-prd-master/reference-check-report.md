# 统一检查报告格式

Q-S、Q-P、事实一致性和自动决策走查统一使用以下短报告结构。检查工具可以输出 JSON，Agent 对话只回报表格。

| 字段 | 内容 |
|---|---|
| 检查对象 | 版本、PAGE、Feature、API 或全局 |
| 检查类型 | Q-S / Q-P / FACT / DECISION / HOST |
| 状态 | 通过 / 通过但待后续门禁 / 失败 / 跳过 |
| 发现 | 只列影响结果的问题，带文件和位置 |
| 责任步骤 | ② / ③ / ④ / ⑤ / ⑥ / ⑧ / ⑨ / ⑩ |
| 下一路由 | 当前完成 / 定向返修 / 请求产品决策 / 等待工具环境 |
| 用户动作 | 无 / 提供事实 / 确认范围 / 选择安装环境 |

“通过但待后续门禁”用于自动决策走查已经完成字段和引用检查，但 Q-S/Q-P 尚未完成的情况。禁止只写“检查通过”而隐藏后续门禁。
