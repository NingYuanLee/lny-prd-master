# 页型职责与跨步骤不变量

② UI、⑤ Page、⑥ Prototype 在处理页面前均 Read 本文件。这里是页型名称、编号映射和跨步骤不变量的单一事实源；各技能自己的速查表只维护该步骤专属规则。

## 三步职责

| 步骤 | 事实来源 | 用途 | 禁止 |
|------|----------|------|------|
| ② UI | 业务目标、默认体验规范、共享页型 | 决定 L/D 结构、视觉层级、交互与 §2.3 | 写实现类名；把样例形态当业务需求 |
| ⑤ Page | `ui/PAGE` §2.3、API、Feature | 用 ASCII 表达分区顺序并形成单页 PRD | 把 ASCII 当视觉稿；让 ⑥ 画空盒子 |
| ⑥ Prototype | `pages_prd`、`ui/PAGE` §2.3、项目既有视觉事实 | 按规格实现页面，满足 ②⑤ 的结构与交互契约 | 编造规格；整页搬入规格外功能 |

ASCII 只定分区顺序；业务功能始终以规格为准。页面视觉以**项目自身事实**为准（PRD 正文、`ui/` 规格、项目既有设计稿/品牌 CSS/真实素材）；没有这些事实时按 PRD 自行设计。

## 跨步骤不变量

②⑤⑥⑦ 共享页面职责、操作结果和状态语义。用户指定的形式、项目已确认的设计规范和平台要求随规格传递。技能示例中的位置、尺寸、材料、数量与动效只供设计时取舍。

| ID | 规则 |
|----|------|
| `PT-MOBILE-LIST` | 呈现本页规定的记录、字段和操作，清楚表达操作属于哪条记录。按需提供筛选和结果反馈；长值、小屏和数据变化时仍可读可操作。 |
| `PT-MOBILE-FUNC` | 入口名称与目标一一对应，主要任务易于发现，次要入口在小屏仍可达。由设计者结合任务优先级、标签和可用空间决定分组与构图。 |
| `PT-GROUP-FIELDS` | **列表族 · 无分页 · 多条记录按组（字段列表）**：只读字段名+字段值；组间浅线左右内缩、不贴边，不在字段之间再画分割线。触屏 MP-012 与桌面 D1-1 **不分页分组字段** / AD-012 同属本页型。与 MP-003 图文详情、MP-002 横卡列表、可编辑表单分离。详情页内单组字段排版仅作参考，**不是** MP-012 页型。 |
| `PT-DESKTOP-LIST` | 按规格支持查询、比较、选择、批量或逐项操作以及需要的分页。长值可识别，选区与操作对象明确，滚动或翻页后状态符合规格。 |
| `PT-DESKTOP-LAYOUT` | 标明主要任务、内容间关系与窄屏优先级。根据比较、联动或独立阅读的需要选择空间分配。 |
| `PT-STATE-FLOW` | 说明当前步骤、完成条件及允许的前进、返回和跳步。并列切换与有序流程按业务语义区分。 |
| `PT-LOCATOR` | 分类按钮、章节大纲（及详情目录）同属定位导航：可点时滚到锚点。**滚动内容区时大纲当前章高亮联动**。章节大纲两种：① 左侧占栏可收缩；② 右侧悬浮可收起。详情右下「目录」同属本族。与树分离。触屏 **MP-013 分类导航**（左一级分组 + 右分组横卡）亦属本族；**不是** MP-008 多级树。触屏另增 **父子章节列表**（父章 + 缩进子章垂直列表，**父章可展开/收起**；可跳转/滚锚点；**不是**维护树、**不是**横卡；MP-015）。左栏大纲子项按二级层级展示（对标桌面 outline）。桌面时间轴不是本族分栏，与触屏同为竖轨右**横卡文本**（无左图，正文可内嵌多小图）。 |
| `PT-DESKTOP-TREE` | 树分两种：① 不分页左树右内容；② 分页列表内父子嵌套行。触屏 **MP-008 分类树**为左多级树右**图文介绍**（点节点换右区，不滚动联动）；桌面 AD-005 为维护树+右区列表。不分页树默认带维护交互：总控全部展开/收起与新增根节点；节点可增子、重命名、删除；拖到节点**上**=同级紧前、**中**=成为其最后一个子节点、**下**=同级紧后。末级可否增子由规格决定。只读树须显式声明为只读，不得提供节点增删改。禁止用分类定位冒充树。 |
| `PT-FLOAT` | 按任务选择是否悬浮。持续可用的操作可发现、可触达，避开系统控件，并保证正文与其他操作可访问。 |
| `PT-DENSITY` | 默认态按项目数据或业务情境展示有代表性的记录；核对明确规定的数量、边界和空态。套件类名与视觉密度不决定业务条数。 |

## 树 vs 章节列表选型

**单一事实源**：②⑤⑥ 遇到「可展开层级列表」时必须先按本表分流，**禁止**用树画章节目录，**禁止**用父子章节列表画分类/组织树。

| 维度 | 树（层级数据） | 父子章节列表（章/节导航） |
|------|-----------------|-----------------------------------|
| **业务语义** | 层级**数据**的浏览或维护：商品分类、组织/权限、表内嵌套 | **章/节/大纲**导航：课程目录、帮助文档目录、阅读跳转 |
| **页型 ID** | `PT-DESKTOP-TREE`；触屏 **MP-008**；桌面 **AD-005** | `PT-LOCATOR` 触屏专形；**MP-015** |
| **典型布局** | **分栏**：左树 + 右内容/表单/图文介绍 | **整页垂直列表**（或模块内一块列表）；无左右分栏 |
| **层级深度** | **任意多级** | **固定两级**：父章 + 子章 |
| **展开控件** | 每节点一个展开/收起控件；维护树另有全部展开/收起的总控 | 每组父章行可**展开/收起该组子章** |
| **点父/节点后** | **换右区**内容（介绍、表单、列表）；**不**滚正文联动 | **跳转或滚锚点**到正文章节；可高亮当前章 |
| **维护能力** | 可增子/重命名/删除/拖拽（维护树）；只读树仅展示 | **只读导航**；无节点增删改 |

**三步决策（按顺序问）**

1. **是不是章/节/大纲，且要点进去读？** → 触屏用**整页父子章节列表**；桌面用**大纲**（左占栏或右悬浮，AD-013），**不是**树。
2. **是不是分类/组织/权限等层级数据，点节点换右区或要维护？** → 用**树**（分栏左树，或表内父子嵌套行），**不是**父子章节列表。
3. **是不是左一级分组 + 右横卡 + 滚正文联动？** → 用**分类定位导航**（MP-013），**既不是树也不是父子章节列表**。

**常见误套（禁止）**

| 错误 | 正确 |
|------|------|
| 课程目录页画成分栏左树右正文 | 触屏父子章节列表整页展示 |
| 商品分类维护画成父子章节列表 | 桌面左树 + 右区表单的分栏结构 |
| 章节目录画成左树右正文分栏 | 章节列表整页，或桌面大纲 |
| 分类导航（左分组右横卡）用树或章节列表 | 分类定位导航 + 分栏（MP-013） |

## 步骤向导语义（②⑤⑥ checklist）

凡业务页具备 **步骤向导 / 有序分步 / 多步提交** 语义（**不限** MP-005 / AD-003 编号）：

| 步骤 | 强制 |
|------|------|
| ② `ui/PAGE` | 定义当前步骤的识别方式、已知总步数和可用操作。 |
| ⑤ `pages_prd` | 记录每步完成条件、校验与返回后的数据状态。 |
| ⑥ `prototypes` | 验证真实操作路径、错误恢复和各处进度信息一致。 |
