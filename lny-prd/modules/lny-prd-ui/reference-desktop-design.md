# 桌面端设计词典（② 主责）

写桌面 `ui/PAGE-*.md` 前扫一眼。视觉呈现（色板、字号、圆角、间距、素材）由 **⑥** 按项目自身设计事实落地：项目既有视觉规范/品牌 CSS/真实图片素材优先；项目未给时按 PRD 自行设计。与 [`reference-mobile-design.md`](reference-mobile-design.md) 并列；冲突时以本文件 + 共享 `PT-*` 为准。

## 分工（防误读）

| 板块 | ② 规格写什么 | 规格里不要写 |
|------|--------------|--------------|
| 页面布局 | D1 骨架 + 通栏/分栏形态（通栏/均分双列/左定右填/左填右定/三列/品字） | 拿表单窄双列当页面分栏 |
| 表单栅格 | 几列、哪些跨列、分区节奏 | 字段贴死、无行距 |
| 列表六型 | 分页标准 / 分页树表 / 分组字段 / 只读树 / **分页无图卡片** / **分页有图卡片** 择一 | 一律硬套商品表 |
| 操作列与列宽 | 操作个数与形态、列语义 | 均分列、操作列被挤没 |
| 状态导览 | 页签 / 步骤 / 进步条 / 进度条谁切内容 | 各写一套互不相关规则 |
| 定位导航 | 分类钮 / 章节大纲（左可收缩或右悬浮） | 与树、时间轴混为一谈 |
| 树 | 不分页左树右内容，或表内父子嵌套行 | 用分类钮冒充树 |

---

## 1. 页面级布局（≠ 表单窄双列）

桌面标准壳（顶栏+侧栏+面包屑+内容区）里，**内容区默认通栏**；有规格时再左右/多栏。**禁止**把 D1-2 表单的字段窄双列栅格错套成页面左右分栏。

| 形态 | ② 怎么写 | 禁止 |
|------|----------|------|
| **标准通栏** | 「内容区一块铺满，不再左右切开」 | 无分栏需求却硬拆双列 |
| 双列 | 「左右两栏均分；左职责 / 右职责；哪栏滚、哪栏钉」 | 用表单窄双列冒充两栏页面 |
| 左定右填 | 「左侧定宽，右侧吃剩余」 | 用维护树分栏冒充 |
| 左填右定 | 「右侧定宽，左侧吃剩余」 | 用表单窄双列冒充 |
| 三列 | 「左导航 / 中主区 / 右辅助」 | 三列均分塞满表单字段 |
| 品字形 | 「上通栏 + 下左右」或「上左右 + 下通栏」 | 强行套 D1-1 商品表壳 |
| 左树右内容 | 见 §5 树 | 与「分类定位」混用 |
| 章节大纲 | 见 §4 定位导航 | 左侧做成可展开树 |

落盘口诀：**页面分栏与字段并排是同一件事吗？不是**——页面分栏说栏职责，字段并排说表单栅格。二者不得互相冒充。

## 2. 表单栅格（D1-2）

| 规则 | ② 怎么写 |
|------|----------|
| 通栏宽度 | 「表单吃满内容区；不限表单最大宽；字段最小宽约 180px」 |
| 默认双列 | 「桌面表单双列；长字段/多行/上传/分区标题跨列」 |
| 1 / 2 / 3 / 4 列 | 规格点名时写列数；块内可再分列 |
| 高级下拉 | 多选 / 搜索 / 树形叶节点单选 / 树形多选 |
| 多图上传 | 表单内缩略略小 |
| 行距 | 「字段上下有呼吸，禁止贴死」；栅格 **行距 ≥ 列距**；嵌套块内同样有间距 |
| 弹窗表单 | 「一行一项」；**单列**，禁止弹窗内再套页面双列 |
| 向导当前步 | 「当前步疏密与整页表单相同」，禁止裸堆字段 |

常见翻车：把字段包进无间距的裸容器、或把整页表单栅格塞进分栏左栏当「布局」。

## 3. 列表六型与列宽 / 操作列

共享规则 **`PT-DESKTOP-LIST`** 是单一事实源；本表只补形态选型与精致化。

### 3.1 六型选型

| 型 | 何时用 | ② 怎么写 |
|----|--------|----------|
| **分页标准列表** | 筛+功能+分页维护主数据 | D1-1 全套：签/筛/功能/表/汇总分页 |
| **分页树形列表** | 分页表里要看父子层级 | 「表内嵌套行 + 分页」；子行缩进；展开收起 |
| **不分页分组字段** | 多条记录按组展示字段名+值，不翻页 | 「分组字段展示，无分页」；白底轻阴影；记录间浅线左右内缩、不贴边；字段行不要再画分割线；不要套详情页单对象写法 |
| **不分页树形展示** | 只看层级，无增删改 | 「只读树；可展开；禁止维护条」 |
| **分页无图卡片列表** | 条目非强对齐列、无封面；带底栏统计分页 | 「分页无图卡片栅格 + 汇总分页」；卡片右上角可放开关，右下角可放按钮 |
| **分页有图卡片列表** | 条目图文重；带底栏统计分页 | 同上 + 图片位 |

工作台嵌入短表仍可只用表格，不算六型。禁止：凡桌面有「一排数据」就整页套商品标准列表。无图/有图不要混在同一栅格。

### 3.2 操作列宽度（按钮形态与数量）

| 规则 | 说明 |
|------|------|
| 定宽跟内容 | 操作列宽由 **直出按钮形态与数量** 决定：表头与单元格同宽。禁止写死过窄导致挤没，也禁止一排文字钮撑爆 |
| 图标钮 | ≤2 个全直出；≥3 直出 1～2 +「更多」。列宽随 1/2/3 颗图标递增 |
| 文字钮 | 仅非常规文案；列宽按文案加宽，优先考虑收进「更多」 |
| 右冻 | 操作列固定在表右；最小宽必须盖住全部直出钮，否则右冻看起来「失效」 |
| 行内开关 | 标准列表用开关列；无图卡片右上角亦可直接放开关 |

### 3.3 列宽与多行单元格

| 问题 | 规则 |
|------|------|
| 长值溢出叠列 | 数据列溢出省略；悬停看全文、点击复制。禁止裸撑破相邻列 |
| 一列多字段多行 | 用 **多行栈**（主行 + 次行）；单元格允许换行、行高随内容、**行内上下有缝**，禁止两行字重叠 |
| 语义列宽 | 名称定宽；说明/备注吃剩余；金额/状态窄；勾选/操作定宽。见 `PT-DESKTOP-LIST` |

## 4. 状态导览（页签 · 步骤 · 进步条 · 进度条）

本质同类：**用「当前状态」控制展示哪一块内容**。② 写「状态导览」时点名形态。

| 形态 | 状态含义 | 切什么 | 交互 |
|------|----------|--------|------|
| 页内签 | 并列视图 | 整区面板（筛+表+分页） | 签可点 |
| 数字步骤 | 有序向导步 | 当前步表单 | **可点数字跳步**；上一步/下一步联动 |
| 分段进步条 | 完成到第几段 | 当前步表单（向导时） | **只展示**；不可点击切换；靠上一步/下一步 |
| 无极进度条 | 连续百分比 | 当前步表单或上传态 | **只展示**；不可点击切换 |

**有序向导**：按 `PT-STATE-FLOW` 体现当前步骤与完成条件，返回或继续后的提示保持一致。

## 5. 定位导航 vs 树

### 5.1 定位导航族（分类 · 章节大纲）

共同点：按钮 **可点** 时，控制正文 **滚到/高亮某一内容锚点**；一般 **不展开父子层级**（或层级仅展示、不承担筛选树职责）。

| 形态 | 怎么摆 | 内容 |
|------|--------|------|
| 分类按钮 | 平铺或分组分类钮 | 对应区块或列表 |
| 章节大纲 · 左 | 大纲占左栏，**可收成点线轨** | 右侧长文；点条目滚锚点；滚正文时当前点高亮 |
| 章节大纲 · 右悬浮 | 大纲悬浮在右侧，**收起后变点线轨** | 正文通栏；点条目滚锚点；滚正文时当前点高亮 |

② 点名用哪一种大纲，并写清：点选后是 **定位滚动** 还是 **替换右区数据**。定位滚动时滚正文，大纲当前章高亮跟着走。详情页右下「目录」同属定位族，不是常驻悬浮大纲。桌面时间轴 **不是** 本族分栏，与触屏同为竖轨右**横卡文本**（无左图，正文可内嵌多小图）。

触屏 **章节目录整页** 用父子章节列表（PAGE-MP-015），**不是** 分类树；与分类树、分类导航的选型对照见 [`reference-page-types.md`](../lny-prd-master/reference-page-types.md) **「树 vs 章节列表选型」**。

### 5.2 树（维护 / 只读列表 / 表内嵌套）

| 型 | 说明 |
|----|------|
| **不分页维护树** | 左树右内容；总控展开/收起/增根；节点增子/重命名/删除；拖到上/中/下分别＝同级紧前 / 末个子节点 / 同级紧后。末级可否增子按规格。点节点只换右区 |
| **不分页只读树** | 仅展示层级，无增删改 |
| **表内嵌套行** | 分页列表里父子行缩进展开；展开收起用 +/− |

禁止：用分类定位冒充可展开组织树。

## 6. 与共享 PT 的关系

| ID | 本词典补充点 |
|----|----------------|
| `PT-DESKTOP-LIST` | 六型选型、操作列按钮数定宽、多行栈、溢出不叠列 |
| `PT-DESKTOP-LAYOUT` | 通栏/均分双列/左定右填/左填右定/三列/品字；禁止表单窄双列冒充分栏 |
| `PT-STATE-FLOW` | 页签/步骤/进步/进度同族 |
| `PT-LOCATOR` | 分类/大纲定位（左可收缩或右悬浮可收起）；与树分离 |
| `PT-DESKTOP-TREE` | 不分页树 vs 表内嵌套行 |

## 7. 写完自检（桌面）

- 左右分栏是否误写成表单窄双列？
- 表单字段是否上下贴死、或弹窗里套了双列？
- 操作列是否按真实钮数/形态定宽，右冻是否还能看见全部直出钮？
- 长字段是否溢出叠到邻列？多行单元格是否用多行栈且行高够？
- 页签与进步条是否按「状态导览」同一套逻辑写，而不是两套互斥故事？
- 分类/大纲是否与树、时间轴拆开写清？大纲是否点名了左侧可收缩或右侧悬浮？
- 列表是否点名了六型之一？
