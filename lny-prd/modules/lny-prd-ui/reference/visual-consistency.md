# 同类页面视觉参考协议

这份协议把项目级视觉档案转成原型实现时可以复用的参考。它适用于同一终端的两个及以上页面，也适用于首页、列表、详情、表单、工作台等需要共享品牌语言的页面族。页面任务、项目事实和设计判断优先，参考内容不限制页面探索。

共享关系按三层维护。视觉档案提供项目级参考，`COMP-*` 只统一契约完全相同的跨页组件结构、交互和状态表现，`PAGE-*` 负责页面组合和页面特有视觉锚点。已有 `COMP-*` 时，只有契约匹配才复用，不能把近似页面强行归并。

本参考只约束项目明确要求共享的事实。它不规定业务页面必须采用某套皮肤、某种卡片、某组颜色或某种页面布局。壳层和总入口的固定样式与交互由原型模块单独维护。

## 进入实现前

1. 项目已有 `ui/visual/visual-profile.md`、`ui/visual/tokens.json` 或 `ui/visual/assets-manifest.md` 时读取并继承其中的事实。缺少时直接依据 PRD、页面任务和素材设计，不要求先创建模板。
2. 只有需要跨页复用设计判断时，才在 `prototypes/.design-decisions/visual-lock.md` 记录共享事实。它是可更新的设计记录，不是冻结视觉的审批文件。
3. 只有多个页面确实共享主题令牌时，才生成 `prototypes/{终端}/assets/project-theme.css`。页面可以使用项目主题，也可以为页面族或单页建立自己的可读令牌和样式。

`visual-lock.md` 可按以下骨架记录，内容必须是当前项目已经采用的事实或明确的默认假设。

```markdown
# 视觉锁定

## 适用范围
- 终端：MP / PC / AD
- 页面族：首页、列表、详情、表单、工作台

## 共享事实
- 色彩语义：
- 字体层级：
- 间距节奏：
- 边界与圆角：
- 阴影层次：
- 按钮层级：
- 状态语言：
- 图标与素材：

## 可局部变化
- 页面任务允许改变的内容：
- 必须保持不变的基础语言：
```

如果生成 `project-theme.css`，它至少要把 `tokens.json` 中的品牌色、背景、表面、正文、辅助文本、边框、成功、警告、危险、字体和四级间距映射为 CSS 自定义属性。页面可以通过 `var(...)` 使用这些属性，也可以在页面有明确设计理由时建立自己的令牌。

## 页面实现参考

- 页面按自己的任务选择视觉结构、色彩、字体、间距、圆角、边框、阴影和动效。已有主题令牌时可以复用，也可以在有明确页面理由时扩展或覆盖。
- 同一页型或同一业务模块优先复用可用的组件行为和结构。页面可以在不破坏任务和状态的前提下发展独立的视觉表达。
- PAGE 引用的 `COMP-*` 必须沿用该组件的结构层级、状态名称、按下态、成功态、失败态和过渡表现。组件只允许按自身规格声明的范围做局部变化。
- 同一 `COMP-*` 在多个页面出现时，原型优先复用它的结构、交互和状态语义。视觉表现可以按页面任务变化，组件规格无法表达新的交互状态时再更新状态矩阵。
- `ui/PAGE-*.md` 的 §2.4 可以声明页面特有的视觉锚点、素材和整体风格，不要求把页面风格压回项目级令牌。
- 跨终端可以有响应式差异，也可以有适合终端和业务场景的视觉差异。品牌事实和可访问性要求优先于形式统一。

## 交付前验收

- 并排查看同类页面，确认共享的品牌事实、组件行为和状态语义没有被意外破坏。
- 检查页面特有装饰是否影响主任务、可读性和操作反馈。视觉差异本身不构成问题。
