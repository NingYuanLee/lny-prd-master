# 发布学习与迭代回流

本模块由总控按需调用，覆盖原型之后和发布之后的产品学习。它不要求用户先提供完整指标体系，缺少数据时记录待采集项并继续整理已有反馈。总控规则见 [`../lny-prd-master/SKILL.md`](../lny-prd-master/SKILL.md)。

## 输入

- 发布结果、用户反馈、客服记录、实验结果和业务数据
- 当前 `product_workspace.md`、`evidence_log.md`、`learning_log.md`
- 当前版本的交付范围、成功标准、Feature AC 和迭代台账

## 输出

- 更新 `learning_log.md`，记录发布或实验、观察指标/反馈、结论和下一步
- 将新证据同步到 `evidence_log.md`
- 对已证实的产品事实按影响范围回流 `main_spec.md`、Feature、UI、API、Page 或版本台账
- 需要新版本时交由迭代模块创建版本，不在本模块直接建版本

## 执行规则

1. 先对照原成功标准和关键假设，区分结果、信号和意见。
2. 不把单次反馈或无基线数据直接写成普遍结论。
3. 判断结论属于保留、调整、扩大、缩小、暂停或继续验证。
4. 计算受影响对象，交总控选择最小返修路径。
5. 只有用户明确批准或迭代规则满足时，才把学习结论写入正式批准范围。

## 收尾

回报观察结果、结论置信度、仍需验证的风险和建议的下一动作。需要改规格或原型时，交总控按影响范围自动推进。
