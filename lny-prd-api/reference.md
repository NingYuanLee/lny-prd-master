## 1. 阅读说明与 PRD 边界

- 本文 **仅** 维护 **接口需求**（要什么能力、关联页面、关键业务字段与规则）。
- **不写**：域名、path、HTTP 方法、JSON 示例、响应 code、技术框架选型、第三方协议细节、**DDL/表名**。
- **鉴权**：业务接口默认 **由公司统一框架鉴权**（见 `lny-prd-master` →「框架内置能力」）。
- **定位**：PRD API 描述 **页面/组件视图数据语义**（可对齐页级 mock），不是 OpenAPI。
- **明细**：单接口 **`api/API-*.md`**；第三方 **`api/EXT-*.md`**。

## 3. 响应形态约定

### 3.1 基础对象

返回单个业务对象或操作结果（如详情、提交、状态变更）。

## 立项落盘与 `api/` 目录初始化

**`/lny-prd-master` 立项时**：创建空目录 **`api/`**，按上文 **「api_spec.md 模板」** 生成根目录 **`api_spec.md`**（索引骨架）。

**`/lny-prd-api` 续跑时**：

1. 若 **`api_spec.md` 不存在**：按 **「api_spec.md 模板」** 在根目录创建；同步创建 **`api/`**（若不存在）。
2. 若 **`api/` 不存在**：创建空目录；旧版单体 `api_spec.md` §5 大段须 **迁移** 至 `api/API-*.md` 后改维护索引模式。
3. 新增 **`API-*`**：在 **`api_spec.md` §4** 增索引行 → 按 **「单 API 模板」** 创建 **`api/API-{终端}-{序号}.md`**。
4. 新增 **`EXT-*`**：在 **§2** 增清单行 → 按 **「单 EXT 模板」** 创建 **`api/EXT-{序号}.md`**。
5. **禁止**在 `api/` 存放原型、UI、Feature 正文。

## 单 API 模板（`api/API-*.md`）

> 一个接口一个文件；文件名与 `api_spec.md` §4 索引表「明细路径」一致。

## 单 EXT 模板（`api/EXT-*.md`）

> 承接 `api_spec.md` §2 第三方清单。一个第三方接口一个文件。

**填写约束**（估点因子，均 **必填**；**人工 / AI 职责见下**）：

| 字段 | 取值 | 谁定 |
|------|------|------|
| 交互方向 | `单向请求` / `含异步回调` / `双向对账或补偿` | AI 可据业务场景推断；**不确定则停笔询问人工**，**禁止臆造** |
| 业务敏感度 | `普通` / `交易履约` / `资金或合规` | 同上 |
| 联调门槛 | `文档自测即可` / `需预约联调` / `强依赖对方排期或人工` / `文档未知需研发调研` | **必须由调用本技能的人工提供**；输入未给则 **先问后写**，**禁止 AI 自填** |

### EXT 估点因子门禁（写 EXT 前必守）

1. **联调门槛**：新建/修改任一 `EXT-*` 前，输入（YAML 或对话）中须已有该枚举；缺失 → **立即向人工索取**，未答复前 **不落盘** 该 EXT（可先写 §2 清单占位行以外的其它 API 工作）。
2. **交互方向 / 业务敏感度**：可从场景、触发与回调说明推断；证据不足或两可 → **向人工确认**，不得凭「常见做法」默认填写。
3. 旧字段 `对接复杂度`（低/中/高）**停写**；存量仅有旧值时 sp 可兼容计分，新开/改 EXT **须**写上表三因子。建议填关联 FEATURE。不写协议、签名、回调 URL、SDK 名。
